# Anseong Foundation

기존 안성제철 프로젝트에서 선택한5개 기반 유틸리티와 기존 테스트. Unity6000.3 계열에서 사용합니다.

상위 저장소의 docs/source-manifest.json에 원본 커밋·경로·해시가 있습니다. 소스 본문은 원문 그대로이며 새 공개 라이선스를 부여하지 않았습니다. 외부 에셋은 포함하지 않습니다.

VR+PC 역할, 네트워크 연결, 씬, 입력 바인딩, 메카 리그는 포함하지 않습니다. 기존 Anseong.Runtime와 동시에 가져오면 같은 타입이 중복됩니다. 테스트 실행은 상위 docs/validation/README.md를 참조하세요.
