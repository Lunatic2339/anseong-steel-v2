# Lightweight industrial concrete ground

Apply/replace IndustrialGround_Shared.mat on ContinuousLandSurface and IndustrialApron_BaseMaterialOnly. One1024x1024 compressed mipmapped albedo texture, shared material, worldXZ mapping(8m repeat) so no UV rebuild needed. Subtle6m expansion joints and45m dust variation are procedural arithmetic, no extra texture samplers. No normal/parallax/displacement maps, decals, realtime reflection, added ground meshes, colliders or scripts. Shader uses main light/shadows and fog. Texture swap, tint, repeat scale and joint/dust strength are material properties. Roads, sea, sand, terrain hills unchanged. VR performance not measured.

Texture produced with built-in image generation: seamless top-down neutral grey steelworks yard concrete, fine aggregate, faint rubber/dust wear, low contrast, no objects or baked shadows. Source image resized by Unity importer to1024, no image-processing edits.
