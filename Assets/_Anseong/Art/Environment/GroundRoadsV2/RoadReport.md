# 지상 도로망과 건물 정렬

도로는 GroundRoadNetwork 독립 오브젝트이며 바닥 재질과 분리. 주요 도로 왕복4차로14m(방향당2), 보조/진입로 왕복2차로7m(방향당1). 지면 Y0 기준 표면 Y0.035~0.047m. 교통/운전 시스템은 없음.

## 정렬된 건물

주요 왕복4차로 중심선 구간 216 / 왕복2차로 진입로 141 / 정렬 건물 0 / 보존된 비건물 414. 기본바닥·로봇 변경 없음. 기존 고가 구조는 배관으로 이름을 명확히 함. 곡선의 접선 방향에 맞춰 정렬하되 다른 시설과 간섭하면 진입로 연결 대상에서 제외함. VR/차량 주행 검증 미실시.
