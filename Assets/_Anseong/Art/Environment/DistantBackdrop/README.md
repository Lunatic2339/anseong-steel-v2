# Distant mountains and cloudy sky

Procedural panoramic skybox: layered distant blue-grey ridgelines, atmospheric horizon and scattered white clouds. No mountain meshes, cloud geometry or source photograph pasted into the scene. Shared stereo-compatible sky shader; no runtime scripts. Fog is scene RenderSettings, not a ground material edit. Sea remains unbuilt. Skyline is decorative, cannot be approached. Current exposure/fog are first-pass; verify on headset.
