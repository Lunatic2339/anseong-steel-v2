# Distant mountain terrain

Replaces the procedural mountain/cloud skybox with three actual terrain meshes behind the industrial area. Front edges approx3.2/5.1/7km away; 20km range width. Irregular eroded ridge and foothill profiles, per-layer atmospheric color and scene fog. 57600 triangles total, no colliders/physics. Clear procedural sky only; previous illustrated mountains/clouds are unassigned. Existing gameplay layout and sea opening preserved. Target camera far clip18km. VR headset validation pending.
