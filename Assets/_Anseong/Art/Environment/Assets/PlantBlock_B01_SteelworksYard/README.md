# B01 제강동 및 강재 적치 구역

PlantBlock_B01_SteelworksYard.prefab을 씬에 배치합니다. 부지는 160 × 140m입니다.
제강동, 굴뚝 3기, 운송 트럭 1대, 강재 묶음 4개, 가로등 3개를 포함합니다.
38m 회차부는 16.08m 트럭의 기하학적 회전 범위로 확인했습니다. 차량 물리 주행 테스트는 포함하지 않습니다.

제강동과 굴뚝은 Painter에서 내보낸 1024×1024 텍스처 두 장을 사용합니다. RGB는 색상, 알파는 광택입니다.
굴뚝 3기는 텍스처를 공유하며 원본 파괴 스크립트·물리 구성은 유지합니다.
바닥은 A01의 콘크리트 텍스처를 재사용합니다.
