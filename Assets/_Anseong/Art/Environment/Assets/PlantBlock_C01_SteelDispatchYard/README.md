# C01 강재 창고 및 출하 구역

PlantBlock_C01_SteelDispatchYard.prefab을 씬에 배치합니다. 부지는 140 × 100m입니다.
창고와 철강 트럭의 상차 공간, 강재 3열, 별도 고철 덤프트럭 대기 구역, 가로등 4개를 포함합니다.
Ground_OptionalPreviewOnly는 독립된 미리보기 바닥입니다. 통합맵에서는 이 오브젝트만 끌 수 있습니다.
창고에 Painter 텍스처 1024×1024 한 장을 사용합니다. RGB는 색, 알파는 광택입니다. 원본 창고 프리팹과 재질은 변경하지 않습니다.
판넬 접힘 코드는 원본 메시의 UV를 보간해 새 텍스처를 유지합니다.
