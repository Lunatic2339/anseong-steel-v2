# StreetLight — 산업단지 도로용 가로등

StreetLight.prefab을 씬에 배치. Scale=1, 바닥Y=0. 높이12m, 뻗는 방향+Z.
65m 로봇 높이의 약1/5.4. 회색 테이퍼 금속 기둥, 단일 암, LED 등기구, 하부 점검함.
다수 배치용 단일 공유 메시·재질3개·텍스처0개·상자 충돌체1개.
Rigidbody·런타임 스크립트·파괴 기능 없음.
실제 Light 컴포넌트는 없으며 렌즈 재질만 옅은 발광. 주변 바닥을 직접 비추지는 않음.
야간 조명이 필요하면 배치 완료 후 일부만 조명 추가/베이크를 검토할 것.
StreetLight.asset, 세 재질, 모든.meta를 프리팹과 함께 유지.
시험 씬: Sandbox_StreetLight.unity. Unity6000.3.26f1 / URP.
외부 모델/텍스처 없이 직접 절차 생성. 실제 VR 성능은 전체 씬에서 확인 필요.
