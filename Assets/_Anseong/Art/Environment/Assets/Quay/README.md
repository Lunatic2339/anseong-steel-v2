# Quay — 20m 직선 안벽 모듈

Quay_20m.prefab: 길이20m(Z), 상부 작업면 폭10m(-X), 벽체 높이6m(Y0~-6).
피벗: 바다쪽 안벽 모서리의 지면 높이. +X바다, -X육지, +Z길이.
끝면Z±10m. 다음 모듈의 중심을 Z방향으로20m씩 이동하면 이어짐. Scale1 권장.

기본 Sandbox_Yunju에 맞추려면 X112.5/Y0를 기준으로 배치, 수면Y-3.
같은 자리에 기존 Quay_Edge_X112.5 임시 벽이 있으면 겹치는 구간을 교체/비활성화해야 함.
이 에셋 생성 작업에서는 기존 기본맵을 변경하지 않음. 전체 해안에 자동 배치하지 않음.

수직 콘크리트 벽체·상부 작업면·코핑·수면 아래 어두운 색·시공 이음·노란 경계 표식.
선박 접안용 외형 모듈이며 테트라포드는 이 전면에 놓지 않고 별도 외곽 호안에 배치.
계선주와 고무 방충재는 별도 에셋으로 추가할 자리만 남겨둠.
재질5개, 단일 공유 메시, 텍스처0개, 상자 충돌체2개. Rigidbody/런타임 스크립트/파괴 없음.
벽체6m는 게임 배경 치수이며 실제 항만 설계 수심이나 구조 성능을 의미하지 않음.
미리보기 Sandbox_Quay.unity는3개를 이어60m 구간으로 표시.
