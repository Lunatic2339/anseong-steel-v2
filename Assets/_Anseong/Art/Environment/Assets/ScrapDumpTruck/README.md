# ScrapDumpTruck — 고철 적재 덤프트럭

배치 파일: ScrapDumpTruck.prefab. Scale=1, 바닥Y=0, 앞 방향+Z.
노란 작업용 캐빈과 높은 덤프 적재함, 녹슨 철판·철골·파이프 적재물.
도로용 대형 덤프트럭을 참고한 배경용 원본 모델. 특정 제조사 차량 복제 아님.

반복 배치용 단일 공유 메시, 공유 재질4개, 텍스처0개, 상자 충돌체1개.
적재물도 메시 하나에 병합. 주행·적재함 작동·파괴·Rigidbody·런타임 스크립트 없음.
프리팹을 복제하면 메시/재질을 공유하므로 복제마다 모델 파일을 따로 만들지 않는다.
다른 재질과 .asset, .meta를 프리팹과 함께 유지.
Unity6000.3.26f1 / URP. 실제 VR 성능은 전체 씬에서 확인 필요.
Editor/는 에셋 생성 도구이며 실행 빌드에는 포함되지 않음.

Unity 측정: 길이9.10m, 높이3.73m, 미러 포함 폭3.06m. 삼각형2700.
