# Container yard equipment

Implemented static original models: 3 rail-mounted gantry cranes (32/26/46m span, approx29m height), trolley/hoist ropes/20ft spreader/cab/ladder/guardrails/travel bogies; ground rails; 3 terminal tractor + chassis units; 2 reach stackers for low-level transfer (not seven-tier stacking); control booth; 3 electrical cabinets; 8 concrete barriers; reused 3 streetlights. Single shared mesh per prefab and four shared materials. Model dimensions approximate visual design, not engineering specification. No operating animation/physics or VR performance validation.

Optional future equipment: ship-to-shore crane if dedicated container berth is added, weighbridge, reefer socket racks only for refrigerated cargo, fire equipment/signage, maintenance shelter. Existing harbor cranes serve the steel berth separately.

Sources: https://rikoncranes.com/en/port-cranes/rtg-a-rtg/ (high stack handling); https://www.liebherr.com/en-au/maritime-cranes/products/port-equipment/rubber-tyre-gantry-cranes-4881362 (yard handling layout). This scene uses custom rail-mounted wide-span gantries, not an exact manufacturer RTG replica.
