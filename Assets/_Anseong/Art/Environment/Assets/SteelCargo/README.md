# SteelCargo — 철강 야적물 세트

SteelCoil.prefab: 가로 방향 구멍의 철강 코일1개와 목재 받침/고정띠.
SteelSlabStack.prefab: 길이6m 슬래브4장과 목재 받침/고정띠.
SteelBeamBundle.prefab: 길이6.5m H형강8개 묶음과 목재 받침/고정띠.
SteelCargo_Group.prefab: 위 적재물을 묶은 배치 예시. 개별 에셋은 따로 배치 가능.

Scale1, 바닥Y0, 단위m. 건물·트럭과 같은 스케일이며65m 로봇 대비 작은 야적물.
각 종류당 단일 공유 메시, 네 재질 공유, 텍스처0개, 상자 충돌체1개.
Rigidbody/런타임 스크립트/파괴/적재 작동 없음. 실제 하중/결속 설계를 검증한 모델 아님.
프리팹을 복제하면 같은 메시와 재질을 공유. 다량 배치의 실제 성능은 전체 씬에서 확인 필요.
.asset/재질/.meta를 프리팹과 함께 유지. Unity6000.3.26f1/URP.
미리보기: Sandbox_SteelCargo.unity. 외부 모델/텍스처 없이 절차 생성.
