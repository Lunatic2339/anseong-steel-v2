# 12 대본 → 할 일 나누기 (초안)

> `10_game_scenario.md` 대본을 **누가 무엇을 언제까지 만들어 오면 선우가 합쳐 게임이 되는지**로 바꾼 표. 대본이 확정되면 이 표대로 `07_milestones.md`(코드 지시서)와 `docs/members/<이름>/`(팀원 지시서)를 고친다.
> 원칙: 코드는 먼저 **자리(도형·글자·빈 소리)**로 끝까지 돌게 만들고, 팀원 결과물이 오면 자리에 갈아 끼운다(마일스톤 = 프로토타입). 그래서 팀원 결과물마다 **넣을 자리 이름**을 정해 둔다.

## 3. 코드 지시서 묶음 (07 M4 고칠 안)

1. **판 흐름**: 장면 0~10 순서, 장면마다 다음으로 넘어가는 조건, 패배·재기동.
2. **기체 점검**: 1-1~1-5(철판, 공 막기, 무기 장착, 출격).
3. **무기**: 검·방패(방패 양쪽 막기), 스캐너·포, 자동 전환, 상실 두 번.
4. **드론**: 은폐 드론(사격), 달려드는 드론, 해킹 드론. 셋이 같은 드론 코드.
5. **HUD**: 오른쪽에만·왼쪽에만 보이는 표시, 사령관 글자, 결과판.
6. **맵 연출**: 크레인 코일, 컨베이어 다리, 사일로(위치 이동·흔들림만).
