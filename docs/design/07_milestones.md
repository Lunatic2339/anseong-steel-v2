# 07 마일스톤 범위 (게임 완성 기준)

**이 표의 마일스톤을 모두 끝내면 12/11 전시 게임이 완성되도록 짠 목록이다.** 2026-11-11 다시 짰다: M4~M7 밑바탕(`feat/m4-m7-skeleton`)이 들어갔고, 유료 AI 도구 5개(`13_ai_tools.md`)로 아트·소리를 팀원이 직접 만든다.

- **마일스톤 = 프로토타입**(선우 11/04). 게임은 도형·글자·빈 소리로 먼저 끝까지 돌고, 팀원 결과물은 정해진 이름으로 칸에 **갈아 끼운다**. 코드에 아트 경로를 박지 않는다.
- 보스 완전히 새 동작은 만들지 않는다(대본 확정 사항 6). Cascadeur는 지금 클립 다듬기 + 지금 클립을 바꾼 변형(돌진·무릎·밀려남)까지(팀 회의에서 확정).
- 1인 양팔은 혼자 테스트하는 개발용. 완료 기준은 2인 빌드.
- 완료 기준은 헤드셋으로 사람이 확인한 것만 친다. M3부터는 에디터가 아니라 빌드로.
- 날짜에 (제안)이 붙은 것은 팀 회의에서 정할 것.
