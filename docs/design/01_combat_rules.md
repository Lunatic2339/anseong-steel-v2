# 01 전투 규칙과 초기 수치

규칙은 확정(MASTER_GDD 기준). 수치는 기존 통합 씬에서 쓰던 값을 출발점으로 한 **제안값**이며, 모두 Inspector에서 바꿀 수 있어야 한다. 실기 CSV로 조정한다.

## 입력

| 손 | 입력 | 의미 |
|---|---|---|
| 담당 팔 컨트롤러 | 위치·회전 | 로봇 팔 IK 목표 |
| 담당 팔 컨트롤러 | 그립 유지 | 공격 의도. 그립 없이도 팔은 움직이지만 피해 0 |
| 담당 팔 컨트롤러 | 트리거 | 부스트(마지막 훅 명중 후에만 의미) |
| 반대 손 컨트롤러 | 스틱 | 협동 이동·회피 |

1인 양팔 모드에서는 양손이 각각 담당 팔이고, 이동은 두 스틱을 한 사람이 함께 민다.

## 공격

| 규칙 | 내용 | 초기값 |
|---|---|---|
| 공격 인정 | 그립 유지 + 궤적 분류 + 실제 주먹 접촉. 한 동작의 여러 접촉은 한 번만 | – |
| 구조물 접촉 | 주변 구조물에 팔이 닿아 부서져도 **공격으로 치지 않는다**(헛침 아님, 연계 유지) | – |
| 잽 | 직선으로 뻗음 | 좌우폭/전진 ≤ 0.55, 직진도 ≥ 0.86 |
| 훅 | 바깥에서 안쪽으로 휘두름 | 바깥 준비 ≥ 10cm, 안쪽 스윕 ≥ 22cm, 호/현 ≥ 1.02 |
| 재장전 | 친 뒤 손이 중립 근처로 돌아와야 다음 공격 | 반경 12cm, 0.15초 유지 |
| 추적 유실 | 추적이 끊기면 그 손의 공격 무효. 복구 후 그립을 한 번 놓아야 다시 공격 | – |
| 피해(보스 HP 대비) | 잽 / 훅 / 부스트 추가 | 3% / 5% / +6% |

판정 순서: 입력 유효 → 공격 의도(그립) → 궤적 분류 → 주먹 접촉 → 피해 확정(1회) → 연계·부스트 갱신.

## 잽–잽–훅 연계

- 잽(A팔) → 잽(B팔) → 훅(A팔). A는 어느 쪽이든 된다. **안내는 오른손 시작**이 기본.
- 각 단계는 실제 명중해야 진행. 다음 명중까지 제한 **2.4초**. 같은 팔 연속 잽 간격 ≥ 0.15초.
- 연계 종료: 헛침, 차례 아닌 사람의 공격, 시간 초과, 직접 피해. 이미 준 피해는 유지.
- 올바른 가드는 연계를 유지하지만 시간은 계속 흐른다.
- 단순 팔 움직임·가드 동작은 차례 위반으로 세지 않는다.
- 동시 펀치 협동 기술은 없다.

## 부스트

- 연계 **마지막 훅이 명중한 뒤**에만 기회가 생긴다. 사전 차지가 아니다. 단독 훅에는 없다.
- 그립 유지 + 트리거 추가 입력. 입력창 **0.45초**, 슬로우 연출 0.3초(보스 애니메이션 속도 0.35, `Time.timeScale`은 건드리지 않음).
- 성공: 추가 피해 1회 + 팔꿈치 부스터 + 보스 밀려남 + 외골격 저항 해제.
- 실패: 일반 훅 피해만 남는다. 그립을 놓으면 기회 취소.
- 두 조종사가 같은 성공/실패를 본다(서버 승인 결과만 연출).

## 가드와 회피

| 위협 | 대응 | 예고 | 성공 | 실패 |
|---|---|---|---|---|
| 일반 공격 | 들어오는 쪽 담당 팔 가드 | 1.2초 | 피해 0, 연계 유지 | 피해, 연계 종료 |
| 강공격 | 양팔 가드 | 1.8초 | 피해 0 | 한 팔만이면 피해 감소 없는 실패 |
| 가드 불가 | 같은 좌우 방향 협동 회피 | 2.0초 | 피해 0, 긴 반격 기회 | 피해 |

- **가드 판정(새로 설계)**: 주먹이 가드 영역(보정한 가드 위치 ±25cm, 얼굴 앞) 안 + 전완이 수직에서 40° 이내. 추적 유효해야 함. 화면 자세와 판정은 따로 확인한다.
- 회피: 명중 0.6초 전부터의 입력만 인정. 미리 옆에 서 있던 절대 위치는 불인정.
- 반격 기회: 보스 공격 종료 후 기본 1.5초, 가드·회피 성공 시 3.0초.

## 이동

- 두 사람 보조 스틱이 같은 방향(크기 ≥ 0.5, 방향 차이 25° 이내)일 때만 입력 인정. 한 명이 놓으면 정지. 방향은 로봇 정면 기준.
- 전투 중: 앞 = 근접 거리까지 정해진 접근, 뒤 = 사거리 밖 후퇴, 좌/우 = 회피 이동(약 0.4초 + 비네팅). 자유 이동 없음.
- 로봇 몸은 보스가 정면에서 ±20° 넘게 벗어날 때만 초당 30° 이하로 돌린다.

## 보스

| 기술 | 등장 | 요구 대응 | 비고 |
|---|---|---|---|
| 좌/우 단발 펀치 | 1페이즈~ | 해당 팔 가드 | 공격 쪽을 실제로 좌/우 구분(기존 코드는 오른팔 고정 버그) |
| 좌우 연타 | 2페이즈~ | 번갈아 해당 팔 가드 | 이전 프레임과 잇는 sweep 판정 |
| 두 손 내려찍기 | 2페이즈~ | 양팔 가드 | 맨손 클립 필요 |
| 가드 불가 돌진 | 3페이즈~ | 협동 회피 | |
| 무릎 꿇기 | HP 10% | 필살기 대기 | |

## 필살기

두 사람이 담당 팔을 정면으로 뻗고(팔 펴짐 ≥ 85%) 그립+트리거 유지 → 1.5초 충전(양쪽이 0.5초 이내 시작) → 광선 3초 유지. 중간에 한 명이 놓으면 충전 리셋. 성공 시 종료 연출.

## 외골격 피드백

| 사건 | 출력 |
|---|---|
| 일반 팔 움직임 | 약한 상시 저항(선택) |
| 명중 | 짧은 저항 120ms |
| 가드 접촉 | 강한 저항 300ms |
| 부스트 | 저항 해제 500ms |
| 연결 끊김·종료 | 즉시 0 |

컨트롤러 진동은 별도 경로. 같은 프레임 우선순위: 피격 > 부스트 > 연계 성공 > 명중 > 가드, 컨트롤러별 최소 간격 0.09초.
