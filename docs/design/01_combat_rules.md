# 01 전투 규칙과 초기 수치

규칙은 확정(MASTER_GDD 기준). 수치는 기존 통합 씬에서 쓰던 값을 출발점으로 한 **제안값**이며, 모두 Inspector에서 바꿀 수 있어야 한다. 실기 CSV로 조정한다.

## 입력

| 손 | 입력 | 의미 |
|---|---|---|
| 담당 팔 컨트롤러 | 위치·회전 | 로봇 팔 IK 목표 |
| 담당 팔 컨트롤러 | 그립 유지 | 공격 의도. 그립 없이도 팔은 움직이지만 피해 0 |
| 담당 팔 컨트롤러 | 트리거 | 부스트(마지막 훅 명중 후에만 의미) |
| 반대 손 컨트롤러 | 스틱 | 협동 이동·회피 |

1인 양팔 모드에서는 양손이 각각 담당 팔이고, 이동은 두 스틱을 한 사람이 함께 민다.

## 공격

| 규칙 | 내용 | 초기값 |
|---|---|---|
| 공격 인정 | 그립 유지 + 궤적 분류 + **공격 보정**(선우 10/18): 휘두르는 도중 종류가 인식되고 보스 부위가 보정 범위·방향 안이면 로봇 주먹을 보스 쪽으로 끌어당겨 명중. 보정을 끄면 실제 주먹 접촉만 인정. 한 동작은 한 번만 명중 | 보정 사거리 = 로봇 팔 길이 × 1.4, 정면 좌우 40°, 끌림 0.15초, 되돌림 0.25초 |
| 구조물 접촉 | 주변 구조물에 팔이 닿아 부서져도 **공격으로 치지 않는다**(헛침 아님, 연계 유지) | – |
| 잽 | 직선으로 뻗음 | 좌우폭/전진 ≤ 0.55, 직진도 ≥ 0.80 (10/18 제안: 1차 헤드셋에서 잽이 0.86~0.99라 기준선에서 떨어짐, 처음 0.86) |
| 훅 | 바깥에서 안쪽으로 휘두름. 잽 조건도 맞으면 훅이 먼저 | 바깥 준비 ≥ 0cm (10/18 제안: 넓은 가드는 더 빼지 않음, 처음 10cm), 안쪽 스윕 ≥ 17cm, 호/현 ≥ 1.01 (10/25 헤드셋: 훅이 빡빡해 처음 22cm·1.02에서 완화), 앞부분과 뒷부분 진행 방향이 25° 이상 꺾임(10/25: 곧은 대각선 펀치가 훅으로 잡혀 추가) |
| 어퍼컷 (제안, 선우 10/17) | 아래에서 위로 올려침. 연계(잽–잽–훅)에는 들어가지 않는 단독 기술. 연계 중에 맞혀도 연계는 유지(토글로 끊게 할 수 있음, M1-05 제안) | 가장 낮은 곳에서 올린 높이 ≥ 18cm, 올린 높이 ≥ 전진 거리, 좌우폭 ≤ 올린 높이 × 0.6 |
| 위아래 거름 | 가드 올리기·내리기는 펀치가 아님 | 위아래 폭 ≤ 0.85 × (전진 거리와 좌우폭 중 큰 쪽) (10/25 0.7 → 0.85, 10/18 제안: 크게 도는 훅이 걸러져서, 처음은 전진 거리만) |
| 판정 시점 | 종류는 사람 손으로 정하지만, 결과는 로봇 주먹이 따라올 때 낸다(팔 반응 시간을 올려도 로봇 주먹보다 판정이 먼저 나지 않게) | 로봇 주먹 목표가 손 목표에 팔 길이 8% 안으로 오거나, 가장 멀리 간 뒤 돌아오거나, 최대 0.8초 (10/25 헤드셋 보고) |
| 재장전 | 친 뒤 손을 조금 거둬들이면(가장 멀리 뻗은 곳에서 친 반대 방향으로) 그 자리에서 다음 공격. 거둬들이지 않아도 잠깐 멈추면 준비. 펀치 모양은 그 펀치를 시작한 자리 기준으로 잰다. 예전 방식(보정한 가드 자리로 돌아와야)도 조절 메뉴에서 고를 수 있다 | 10cm 거둬들임 또는 0.4초 멈춤, 펀치 사이 최소 0.25초 (10/25 선우 승인: 가드까지 돌아와야 하면 연타가 끊기고 돌아오는 자리가 어긋나면 못 셌다). 가드 방식: 좌우·위아래 25cm, 앞 10cm, 0.15초 |
| 추적 유실 | 추적이 끊기면 그 손의 공격 무효. 복구 후 그립을 한 번 놓아야 다시 공격 | – |
| 피해(보스 HP 대비) | 잽 / 훅 / 어퍼컷(제안) / 부스트 추가 | 3% / 5% / 4% / +6% |

판정 순서: 입력 유효 → 공격 의도(그립) → 궤적 분류(휘두르는 도중 중간 판정) → 공격 보정 또는 주먹 접촉 → 피해 확정(1회) → 연계·부스트 갱신.

헛침 = 그립을 쥐고 종류가 인식된 공격이 명중 없이 끝남. 펀치 기록 CSV의 명중 열: 1 = 명중, 0 = 헛침, 빈칸 = 공격 아님.

## 잽–잽–훅 연계

- 잽(A팔) → 잽(B팔) → 훅(A팔). A는 어느 쪽이든 된다. **안내는 오른손 시작**이 기본.
- 각 단계는 실제 명중해야 진행. 다음 명중까지 제한 **2.4초**. 같은 팔 연속 잽 간격 ≥ 0.15초.
- 연계 종료: 헛침, 차례 아닌 사람의 공격, 시간 초과, 직접 피해. 이미 준 피해는 유지.
- 올바른 가드는 연계를 유지하지만 시간은 계속 흐른다.
- 단순 팔 움직임·가드 동작은 차례 위반으로 세지 않는다.
- 동시 펀치 협동 기술은 없다.

## 부스트

- 연계 **마지막 훅이 명중한 뒤**에만 기회가 생긴다. 사전 차지가 아니다. 단독 훅에는 없다.
- 그립 유지 + 트리거 추가 입력. 입력창 **0.45초**, 슬로우 연출 0.3초(보스 애니메이션 속도 0.35, `Time.timeScale`은 건드리지 않음).
- 성공: 추가 피해 1회 + 팔꿈치 부스터 + 보스 밀려남 + 외골격 저항 해제.
- 실패: 일반 훅 피해만 남는다. 그립을 놓으면 기회 취소.
- 두 조종사가 같은 성공/실패를 본다(서버 승인 결과만 연출).

## 가드와 회피

| 위협 | 대응 | 예고 | 성공 | 실패 |
|---|---|---|---|---|
| 일반 공격 | 들어오는 쪽 담당 팔 가드 | 1.2초 | 피해 0, 연계 유지 | 피해, 연계 종료 |
| 강공격 | 양팔 가드 | 1.8초 | 피해 0 | 한 팔만이면 피해 감소 없는 실패 |
| 가드 불가 | 같은 좌우 방향 협동 회피 | 2.0초 | 피해 0, 긴 반격 기회 | 피해 |

- **가드 판정(새로 설계)**: 주먹이 가드 영역(보정한 가드 위치 ±25cm, 얼굴 앞) 안 + 전완이 수직에서 40° 이내. 추적 유효해야 함. 화면 자세와 판정은 따로 확인한다.
- 회피: 명중 0.6초 전부터의 입력만 인정. 미리 옆에 서 있던 절대 위치는 불인정.
- 반격 기회: 보스 공격 종료 후 기본 1.5초, 가드·회피 성공 시 3.0초.

## 이동

- 두 사람 보조 스틱이 같은 방향(크기 ≥ 0.5, 방향 차이 25° 이내)일 때만 입력 인정. 한 명이 놓으면 정지. 방향은 로봇 정면 기준.
- 전투 중: 앞 = 근접 거리까지 정해진 접근, 뒤 = 사거리 밖 후퇴, 좌/우 = 회피 이동(약 0.4초 + 비네팅). 자유 이동 없음.
- 로봇 몸은 보스가 정면에서 ±20° 넘게 벗어날 때만 초당 30° 이하로 돌린다.

## 필살기

두 사람이 담당 팔을 정면으로 뻗고(팔 펴짐 ≥ 85%) **컨트롤러의 모든 버튼**(그립·트리거·A/B 또는 X/Y, 메뉴·시스템 버튼 제외)을 누른 채 유지 → 1.5초 충전(양쪽이 0.5초 이내 시작) → 광선 3초 유지. 중간에 한 명이 놓으면 충전 리셋. 성공 시 종료 연출.

## 외골격 피드백

| 사건 | 출력 |
|---|---|
| 일반 팔 움직임 | 저항 없음(끈이 느슨해 자유롭게 움직임) |
| 보스 공격 예고 시작, 펀치 궤적 인식 | 준비(끈을 미리 약하게 감아 둠) |
| 명중 | 짧은 저항 120ms |
| 가드 접촉 | 강한 저항 300ms |
| 부스트 | 즉시 해제(순간 가벼워짐) |
| 연결 끊김·종료 | 즉시 0 |

힘 방향은 팔을 **펼 때 막는 쪽**이다. 명령 형식은 `02_architecture.md` "외골격 시리얼 프로토콜".

컨트롤러 진동은 별도 경로. 같은 프레임 우선순위: 피격 > 부스트 > 연계 성공 > 명중 > 가드, 컨트롤러별 최소 간격 0.09초.
