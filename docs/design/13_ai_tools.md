# 13 유료 AI 도구 5개: 누가 무엇을 만드나

> 2026-11-11 선우가 결제한 도구 5개(Higgsfield, Cascadeur, Meshy, ElevenLabs, Suno)를 팀원에게 나눈 표. 학교에 낸 **구입 계획서·활용 계획서(11/07)**의 용도와 맞췄다(ChatGPT·Claude도 같은 계획서에 있어 함께 적음). 계획서 원본에는 연락처가 있어 레포에 올리지 않는다. 사람별 단계는 `docs/members/<이름>/AI_도구_*.md`. 일정은 `07_milestones.md`.

왜 이렇게 나눴나
- **한 도구 한 사람**: 계정 하나를 여러 명이 동시에 쓰면 크레딧이 엉키고, 약관상 계정 공유가 안 될 수도 있다. 다른 사람 몫은 담당에게 단톡방으로 요청한다(예: 윤주 맵 소품 → 성재 Meshy). 예외는 Higgsfield·ChatGPT: Higgsfield는 이미지 11/18까지 성재, 영상은 11/19부터 유진이라 **쓰는 때가 겹치지 않는다**. ChatGPT는 고건이 주로, 성재는 텍스처 몇 장만.
- 컨셉 이미지는 Meshy에 넣을 사람이 직접 만든다(선우 11/11): 이미지 → 3D를 한 사람이 바로 고쳐 가며 돌릴 수 있다.
- 유진 = 보스 동작·영상, 성재 = 물건 모양부터 모델까지(컨셉 이미지 → Meshy → Blender 원점 정리), 윤주 = 소리 전부(S-01을 이어서. 웹에서 글자만 치면 되는 도구라 초보도 됨).
- 고건은 12/10까지 외골격이 빠듯해서 만드는 도구 대신 ChatGPT(회로·펌웨어 질문)만.

## 3. 모두 지킬 것

1. **출처 한 줄**: 결과물마다 그 폴더의 `SOURCES.md`(드라이브면 `SOURCES` 문서)에 `파일 이름 / 도구 / 플랜 / 만든 날 / 만든 사람 / 프롬프트(입력 문장)`. 프롬프트를 남겨야 다시 만들 수 있다.
2. **다른 작품 이름 금지**: 프롬프트에 실제 게임·애니·영화·회사 이름("○○ 스타일")을 쓰지 않는다. 비슷하게 나오면 저작권 문제가 되고 우리 게임 것이 아니게 된다. 모양을 말로 설명한다.
3. **같은 그림체**: 아래 "스타일 한 줄"을 모든 프롬프트 앞에 붙인다(팀 회의에서 고쳐도 됨).
4. **이름 규칙 = 칸 이름**: 아래 4번 표의 파일 이름을 그대로 쓴다. 이름이 맞으면 코드 담당이 메뉴만 돌려 들어간다.
5. **용량**: 레포 파일 하나 50MB 이하. 영상 원본·.blend·후보는 드라이브에만.
6. **보스는 기계**: 생물 같은 포효·근육·피 금지(대본 확정 사항). 빛·금속·증기 없는 기계음.
7. **헤드셋 확인 전엔 완료 아님**: 넣은 뒤 선우가 헤드셋으로 보고 "됨/다시"를 단톡방에.

## 5. 코드 쪽에 필요한 칸 (M4 기능 동결 11/19 전에)

AI 결과물 때문에 새로 생기는 코드는 "칸"뿐이다. `07_milestones.md` M4-08.
- 보스 클립 메뉴가 **FBX 원본도** 읽게(지금은 `.anim`만 읽음).
- 배경음악 표: 장면 → BGM(오프닝·전투·맨손·엔딩), 바뀔 때 페이드. 비면 무음.
- 영상 칸: 조종석 앞 큰 판에 `VideoPlayer`. 대기 중 `Video_Lobby` 반복, 판 시작 때 `Video_Opening`, 승리 뒤 `Video_Ending`(두 PC가 같은 때 시작, 둘 다 누르면 건너뛰기). 비면 바로 다음 장면. VR이라 화면 전체가 아니라 **조종석 안 화면**으로 보여 준다(멀미 없게).
- 무기·드론·보스 무기 프리팹 칸은 이미 있음(`PlayerWeaponVisuals`, `BossWeaponSet` 에셋 + `BossWeaponVisuals`, `DroneDirector`). 보스 포·검·방패 칸이 비면 우리 무기 프리팹을 빌려 `borrowedMaterial`(비면 보스 색)로 칠함(밑바탕 733af20). **철판 표적 칸은 없음**(`CheckupDirector`는 재질만) → 프리팹 칸 추가.
- 사령관 대사 소리 칸은 이미 있음(`VO_Commander_NN` 이름으로 찾음).
- 효과 표 에셋(`Art/VFX/CombatEffects.asset`) 칸은 이미 있음. 이펙트 재료 영상(`VFX_*.mp4`)은 코드 담당이 **8×8 그림 묶음(플립북 png)**으로 바꿔 파티클(Texture Sheet Animation, 더하기 섞기)에 붙인다. 변환은 Claude가 명령 하나(ffmpeg)로 한다.

## 6. 팀 회의에서 정할 것 (11/12 제안)

1. 계정을 어떻게 나눠 줄지(로그인 정보 전달 방법, 동시 접속 금지). **비밀번호는 레포·문서에 절대 적지 않는다.**
2. 도구별 크레딧을 사람마다 얼마나 쓸지(한 달 크레딧 ÷ 남은 주).
3. 스타일 한 줄(위 3번) 확정, 보스·우리 색이 04 재질 슬롯과 맞는지.
4. Cascadeur 범위: 활용 계획서에는 "기존에 없는 모션 생성"으로 적었고, 선우 11/06 규칙은 "특수 모션 자제". 둘을 맞춘 제안 = **다듬기 + 지금 클립을 바꾼 변형(돌진·무릎·밀려남)**, 완전히 새 동작은 안 함.
5. Meshy로 "로봇"까지 만들지: 계획서엔 로봇 모델링도 있음. 로봇 몸을 새로 만들면 뼈가 바뀌어 동작이 다 깨지므로, 로봇에는 **붙이는 부품(무기·장갑 조각)만** 제안.
6. 사령관 목소리: 계획서대로 ElevenLabs로 할지, 팀원 녹음으로 할지. 제안: ElevenLabs(34줄을 하루에 만들고 문구가 바뀌어도 다시 만들기 쉬움).
7. 대기 화면 영상을 부스 모니터(헤드셋 밖)에도 틀지.
