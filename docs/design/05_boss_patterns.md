# 05 보스 패턴 (제안값)

보스가 **언제, 어떤 공격을, 얼마나 자주·세게** 하는지 정한 표다. 공격 종류와 대응은 `01_combat_rules.md`에서 확정됐고, 이 문서는 그 빈칸(순서·간격·피해·타이밍)을 Claude가 제안값으로 채운 것이다. 유진이 클립을 보며 다듬고(D-01), 수치는 모두 Inspector에서 바꿀 수 있게 만든다. 최종 조정은 M6 외부인 테스트 기록으로 한다.

## 보스 한 번의 공격 흐름

```
쉬는 중(가드 자세) → 예고(준비 동작 + 경고음) → 명중 순간 → 회복 → 빈틈(반격 기회) → 쉬는 중 …
```

- **보스는 빈틈과 경직 중에만 피해를 받는다.** 쉬는 중·예고 중에 친 펀치는 막힘(피해 0, 막힘 효과음, 연계 차례는 그대로). "막고 → 빈틈에 반격"이라는 리듬을 배우게 하기 위해서다.
- 빈틈이 끝나도 **연계가 이어지는 중이면** 보스는 연계가 끝날 때까지(최대 2.4초) 다음 공격을 시작하지 않는다. 잽–잽–훅–부스트를 끝까지 성공시키는 맛을 지키기 위해서다.
- 중간발표 빌드(10/30)에는 보스 공격이 없다. 보스는 항상 빈틈 상태로 서 있고, 맞으면 경직한다.

## 기술표

시간은 초, 피해는 조종사 로봇 HP(100) 대비 %. "명중 순간"과 "끝"은 클립을 보고 유진이 채운다(빈칸이면 Claude가 측정).

| 기술 | 페이즈 | 클립 | 예고 | 명중 순간 | 끝 | 대응 | 실패 피해 | 성공 시 |
|---|---|---|---|---|---|---|---|---|
| 왼손 펀치 | 1~ | `Boss_PunchLeft` | 1.2 | | | 왼팔 가드 | 6 | 빈틈 3.0 |
| 오른손 펀치 | 1~ | `Punch` | 1.2 | | | 오른팔 가드 | 6 | 빈틈 3.0 |
| 좌우 연타 | 2~ | `AlternatingCombo` | 1.2 (첫 타), 이후 타 간격 0.7 | | | 들어오는 쪽 팔을 번갈아 가드, 4타 | 타당 4 | 4타 모두 막으면 빈틈 3.0, 아니면 1.5 |
| 두 손 내려찍기 | 2~ | `Boss_SlamBoth` | 1.8 | | | 양팔 가드(한 팔만이면 실패) | 12 | 보스 경직 0.8 + 빈틈 3.0 |
| 가드 불가 돌진 | 3~ | `Boss_Charge` | 2.0 | | | 둘이 같은 방향 회피(명중 0.6초 전부터 입력) | 15 | 보스 헛돌진 후 휘청 + 빈틈 3.0 |

- 대응에 실패해도 빈틈은 기본 1.5초 생긴다(`01_combat_rules.md`).
- 예고 신호는 세 가지로 구분: 일반 = 짧은 경고음 + 해당 팔 발광, 강 = 낮은 경고음 + 두 팔 발광, 가드 불가 = 사이렌 + 몸 전체 붉은 발광.

## 페이즈별 순서

| 페이즈 | 첫 공격 | 이후 고르는 비율 | 쉬는 시간 | 규칙 |
|---|---|---|---|---|
| 1 (100→60%) | 오른손 펀치 | 왼손 50 · 오른손 50 | 2.5~3.5 | 같은 손 3번 연속 금지 |
| 2 (60→25%) | 두 손 내려찍기 | 단발 펀치 50 · 좌우 연타 25 · 내려찍기 25 | 2.0~3.0 | 페이즈 시작 후 3번 안에 좌우 연타를 한 번 보여줌. 내려찍기 연속 금지 |
| 3 (25→10%) | 돌진 | 단발 펀치 35 · 좌우 연타 20 · 내려찍기 20 · 돌진 25 | 1.5~2.5 | 돌진은 3번에 1번까지. 강공격(내려찍기·돌진) 연속 금지 |

- **새 기술은 페이즈 첫 공격으로 먼저 보여준다.** 사령관 음성으로 대응법을 한 번 알려준다(예: "두 팔로 막아라!").
- 무작위는 시드를 정할 수 있게 만든다(테스트 재현용).

## 페이즈 전환

1. 보스 HP가 경계(60%, 25%, 10%)에 닿으면 **그 아래로 내려가지 않는다**(한 번의 큰 연계로 페이즈를 건너뛰지 않게).
2. 진행 중인 공격이 끝나면 보스가 뒤로 물러나며 포효(약 2초, 이때는 무적).
3. 사령관 음성 + HUD로 새 페이즈 알림 → 다음 공격은 새 기술.
4. 페이즈 시작 때 조종사 로봇 HP가 60% 미만이면 60%로 회복(관객 대부분이 완주하도록).

## 보스가 맞았을 때

| 상황 | 보스 반응 |
|---|---|
| 잽 명중 | 효과(불꽃·소리)만, 동작 끊김 없음 |
| 훅 명중 | 짧은 경직(`Stagger` 앞부분 약 0.6초) |
| 부스트 명중 | 크게 밀려남(`Boss_Knockback`), 뒤로 약 10m. 다시 걸어와서(`Walk`) 다음 공격 |
| 내려찍기 양팔 가드 성공 | 경직 0.8초 |
| 돌진 회피 성공 | 헛돌진 후 휘청(`Stagger`) |

## 거리

- 보스는 **근접 거리** 안에서만 공격한다. 밖이면 걸어서(`Walk`) 다가온다. 조종사가 후퇴하면 보스가 따라오므로 잠깐 쉬는 효과가 있다.
- 근접 거리 수치는 M2에서 로봇 팔 길이를 재서 정한다(Claude).

## 끝: 무릎 → 필살기 → 쓰러짐

1. HP 10%: 진행 중인 공격이 끝나면 `Boss_Kneel` 재생 후 무릎 꿇은 채 유지. 공격하지 않는다.
2. 사령관 음성 "둘이 함께 팔을 뻗어라!" → 필살기(`01_combat_rules.md` "필살기"). 시간 제한 없음. 20초 동안 성공하지 못하면 다시 안내.
3. 성공: 광선 3초 → `Death` → 결과 화면.

## 조종사 로봇

- HP 100. 패배하면 "기체 재기동" 연출 후 그 페이즈 처음부터 1회 재시작, 두 번째 패배면 결과 화면(`00_plan.md`).
- 예상 시간: 공격 한 바퀴(쉬기 + 예고 + 회복 + 빈틈) 약 6~8초. 초보 2인이 한 바퀴에 평균 5% 정도 깎으면 보스전 약 2.5~3분 + 전환·필살기. 길거나 짧으면 쉬는 시간과 피해량으로 맞춘다.

## 구현 메모 (Claude)

- 기술 하나 = 데이터 에셋 하나(`BossAttackDefinition`: 클립, 예고, 명중 순간, 끝, 대응, 피해, 성공 시 빈틈). 기존 레포 `BossAttackDefinition.cs`·`BossCombatController.cs`의 준비→공격→회복 흐름을 참고(`03_reuse_from_old_repo.md`).
- 패턴 고르기는 MonoBehaviour와 분리한 순수 클래스 + EditMode 테스트(비율, 연속 금지, 첫 공격, 시드 재현).
- 서버만 계산하고 "기술 + 시작 틱"을 복제한다(`02_architecture.md`).
