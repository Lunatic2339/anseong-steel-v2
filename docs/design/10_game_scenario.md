# 10 한 판 시나리오 (v3 초안, 선우 확정 대기)

**한 판 진행의 기준 문서.** 플레이어 기술, 보스 기술, 페이즈 구성, 연출을 한곳에 모았다. 대사는 `11_commander_lines.md`. 확정되면 `00_plan`·`01`·`05`·`07`을 맞춘다.

## 원칙

- **모든 판단은 재미 기준(선우 11/07).** 기본은 근접전이고, **사격은 중간에 끼어드는 패턴**이다(드론이 날아오거나 보스가 물러나 쏠 때). 총만 쏘는 페이즈는 없다.
- **무기가 하나씩 부서진다(선우 11/06의 총 → 검·방패 → 맨손 순서).** 1페이즈 끝에 총, 2페이즈 끝에 검·방패가 부서진다. 페이즈마다 할 수 있는 게 줄어서 위기감이 커진다.
- **팔마다 역할이 다르다(선우 11/07: "둘이 같은 총을 쏘는 건 좌우 분담이 아니다").** 왼팔 = 방패 / 포, 오른팔 = 검 / 스캐너. 근접에서는 오른쪽이 주 공격, 사격에서는 왼쪽이 주 공격이라 둘 다 주인공 순간이 있다.
- **좌우 분담 기준(선우 10/30): "혼자 두 손으로 할 수 있으면 의미 없다."** 각자 HUD에 자기 팔 센서가 본 것만 뜨고(눈 수), 양쪽에 서로 다른 판단이 동시에 오고(뇌 수), 한쪽이 막히면 다른 쪽이 구한다(해킹).
- **보스 새 동작 없음(선우 11/06).** 지금 클립(좌/우 펀치, 연타, 내려찍기, 돌진, 포효, 걷기, 휘청, 밀려남, 무릎, 쓰러짐)을 자르고·빠르게·이어 붙여 쓴다. 드론·포탄·해킹 장치는 단순 도형.
- **맵 구조물은 페이즈마다 한 번**, E-01 배치도에 있는 자리만(양옆 크레인·컨베이어 다리, 보스 뒤 사일로).
- **2인 전용 설계(선우 11/07).** 1인 양팔 모드는 혼자 테스트하는 개발 도구일 뿐이다(교차 정보는 개발 토글로 양쪽 다 보여 줌). 헤드셋 중 키보드 없음.
- `[결정]` = 선우가 정할 것. 수치는 제안값, 헤드셋으로 바꾼다.

## 이야기

보스는 기계를 해킹해 집어삼키는 기계다. 드론을 부하로 부린다. 그래서 제철소 작업 로봇을 전투용으로 바꾸면서 **중앙 컴퓨터를 빼고 팔마다 센서·조종석을 따로 달았다(망 분리).** 각 조종사 HUD에는 자기 팔 센서가 본 것만 뜬다. 두 팔을 잇는 건 조종사 둘의 목소리뿐이다. 목소리는 외부 관제 하나. `[결정]`

## 플레이어 기술

막기는 모든 무기에서 같다(든 팔을 얼굴 앞에 세우기, 지금 가드 판정). 이동·회피도 같다(두 스틱 같은 방향).

| 무기 | 기술 | 조작 | 효과 (보스 HP 대비) |
|---|---|---|---|
| **근접: 왼 방패 · 오른 검** (1·2페이즈) `[결정: 고정]` | 베기 / 방패 밀치기 | 검 = 훅 인식, 방패 = 잽 인식, 그립 유지 | 3% / 2% |
| | 연계 | 베기(오) → 밀치기(왼) → 큰 베기(오) → 트리거 부스트 | 큰 베기 5% + 부스트 6% |
| | 튕기기 → 반대 팔 반격 | 명중 0.2초 전 안에 정확히 막기 | **반대 팔만** 2초 동안 피해 2배 |
| | X자 막기 | 방패와 검을 얼굴 앞에서 엇갈림 | 내려찍기 피해 0 + 보스 휘청 |
| | 드론 쳐내기 (2페이즈) | 가까이 온 드론을 베기·밀치기로 침 | 드론 격추 |
| **사격: 왼 포 · 오른 스캐너** (1페이즈 사격 패턴 때만, 자동 전환) | 표적 지정 (오른) | 스캐너 레이저를 드론·약점에 **1초 계속 비춤** → 지정. 떼면 풀림 | 지정된 것에 왼팔 조준이 붙음 |
| | 충전 포격 (왼) | 그립 쥐고 팔을 버텨 1.5초 충전(외골격 저항) → 트리거, 반동으로 팔이 튕김 | 지정된 드론 격추 / 지정된 보스 약점 6%. 지정 없으면 빗나감 |
| | 요격 (오른) | 트리거로 짧은 기관포 | 날아오는 포탄을 떨굼 |
| | 크레인 떨어뜨리기 (구조물) | 보스가 크레인 아래 → 스캐너가 고리 지정 → 포가 쏨 | 강철 코일: 6% + 휘청. 1페이즈에 한 번 |
| **맨손** (3페이즈) | 잽·훅·어퍼컷, 잽–잽–훅–부스트 | 지금 그대로 | 3% / 5% / 4% / +6% |
| | 휘청 중 어퍼컷 | 보스 휘청 중에 어퍼컷 | 보스가 들림(밀려남 클립): 8% |
| | 사일로 처박기 (구조물) | 3페이즈 첫 부스트 성공 | 보스가 뒤 사일로에 처박힘(무너짐은 M5, 그전엔 흔들림만) |
| | 해킹 장치 떼기 | 동료 팔에 붙은 드론을 그립으로 잡고 뒤로 1초 당김 | 동료 팔 복구 |

무기 전환은 버튼 없이 자동이다: 사격 패턴이 시작되면 관제 "사격 모드!" + 철컥 소리와 함께 방패가 포로, 검이 스캐너로 바뀌고(모델 켜고 끄기), 패턴이 끝나면 돌아온다.

## 사격 패턴 (1페이즈에 2~3번, 각 20~30초)

| 패턴 | 보스 | 무엇이 오나 | 둘이 할 일 |
|---|---|---|---|
| 드론 편대 | 뒤로 물러나 포효 | 드론 6기가 좌우에서 2~3기씩 다가옴. 로봇에 닿으면 자폭(막으면 피해 절반) | 관측수가 지정 → 포수가 격추. **어느 쪽 드론이 먼저 닿을지는 반대쪽 HUD에만**. 포수 충전 중엔 막으면 충전이 풀려서 "막을까, 요격해 줄까"를 말로 정함 |
| 원거리 포격 | 물러나서 주먹 포탄(펀치 클립 + 탄)·연속 포탄(연타 클립 + 탄 4발) | 좌우에서 포탄 | 관측수가 요격하거나 그쪽 팔이 막음. 그사이 관측수는 보스 약점(움직이는 발광점)을 찾아 지정, 포수가 쏨 |

첫 사격 패턴은 드론 편대이고 처음 2기는 느리게 와서 연습이 된다. 1페이즈 마지막 사격 패턴 도중에 보스가 돌진해 전환한다.

## 연출 규칙 (VR)

- **시점은 늘 머리를 따른다.** 카메라를 빼앗지 않는다. 연출 중 팔 입력은 무시, 보스 무적, 2인은 서버 시작 틱으로 같이 본다.
- 연출 = 지금 클립 + 흔들림 + 0.3초 이하 페이드 + 소리 + 관제 대사. 무기 전환·파손은 모델 켜고 끄기(+ M5에 불꽃).
- 구조물 장면은 미리 정한 자리에서만(보스가 그 자리로 가면 표시). 부서지는 조각은 M5.
