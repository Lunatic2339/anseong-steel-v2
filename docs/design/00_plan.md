# 00 기획 요약

원본: 「안성제철 최종 기획안」(총괄 채팅 문서, 2026-10-16). 컨셉 원문은 ChatGPT가 정리한 `MASTER_GDD.md`이며, 전투 규칙은 그 문서를 그대로 따른다. 이 파일은 개발에 필요한 부분만 옮긴 것이다. 충돌하면 총괄 채팅의 최신 결정이 우선한다.

## 시연 범위 (2026-12-11)

| 구분 | 내용 |
|---|---|
| 반드시 | 기체 점검(조작 학습) → 출격 → 맨손 보스전 3페이즈 → 합동 필살기 → 결과·재시작. 2인 LAN 협동, 잽–잽–훅·부스트, 한팔·양팔 가드, 협동 회피·접근·후퇴, 최소 HUD, 효과음, 컨트롤러 진동 |
| 반드시(대체 가능) | 외골격 저항 피드백. 고장 나도 컨트롤러 진동만으로 끝까지 돌아가야 함 |
| 반드시(안전장치) | 1인 양팔 모드. 네트워크 실패 시 이 모드로 시연 |

| 제외 | 미사일·드론, 콕핏 렌더텍스처 중계 화면, 자유 이동, 무한 모드·점수판, 도시 전체 파괴·실시간 쪼개기 |

## 한 판의 흐름 (5분 이상, 최대 10분 내외)

1. 착용 전 안내(운영자, 30초): 담당 팔, 그립 = 공격 유지, 트리거 = 부스트, 반대 손 스틱 = 이동.
2. 기체 점검(60~90초): 담당 팔 들기 → 편한 가드에서 그립(가드 기준 저장) → 정면으로 끝까지 뻗고 그립(도달 거리 저장) → 그립 유지하고 훈련 표적 치기 → 양팔 가드로 준비 완료.
3. 출격(자동 연출 10초).
4. 보스전 3페이즈 — 누적형: 플레이어 기술은 끝까지 같고 보스 기술만 늘어난다.

| 페이즈 | 보스 HP | 새 보스 기술 | 조종사가 익히는 것 |
|---|---|---|---|
| 1 | 100 → 60% | 좌/우 단발 펀치(일반) | 해당 팔 가드, 빈틈에 잽–잽–훅, 명중 후 부스트 |
| 2 | 60 → 25% | + 두 손 내려찍기(강), 좌우 연타 | 양팔 가드, 연타를 번갈아 막기 |
| 3 | 25 → 10% | + 가드 불가 돌진 | 같은 방향 협동 회피, 회피 성공 후 긴 반격 |

5. 합동 필살기(15초): 보스 HP 10%에서 보스가 무릎 꿇음 → 두 사람이 담당 팔을 정면으로 뻗고 **컨트롤러의 모든 버튼**(그립·트리거·A/B 또는 X/Y)을 누른 채 유지 → 1.5초 충전 → 가슴 광선 3초.
6. 결과(15초) → 운영자 재시작. 이전 판의 상태가 하나도 남지 않아야 한다.

패배: 로봇 HP 0 → "기체 재기동" 연출 후 해당 페이즈 처음부터 1회 재시작. 두 번째 패배면 결과 화면.

### 지시서를 쓸 때 꼭 넣을 것 (선우 결정·아이디어)

- **M1-05 공격 보정(10/18)**: 잽·훅·어퍼컷 종류만 맞게 인식되면 주먹이 보스에 안 닿아도 보스 쪽으로 끌어당겨 맞힌다(에임 어시스트). 01의 "실제 주먹 접촉"을 "종류 인식 + 보정 범위·방향 안"으로 바꾸고 Inspector 토글. 끌어당기려면 휘두르는 도중 중간 판정이 필요(M1-04 분류기는 동작 끝에 결과를 냄).
- **M2 HUD 또는 M4 튜토리얼·시연 안내: 초보자 안내(10/18)**
  - 추천 펀치 경로 3D 화살표: 보정한 가드 위치에서 시작(잽 직선, 훅 바깥→안 곡선, 어퍼컷 아래→위). 분류 기준값(`PunchClassifierSettings`)으로 그려 기준을 바꾸면 같이 바뀌게. 연계 중엔 다음 차례(팔·종류)만.
  - 막힐 때: 같은 실패 이유(`PunchReason`)가 몇 번 이어지면 화살표 + 한 줄 힌트(예: "바깥으로 더 빼고 휘두르세요").
  - 버튼 안내: 눌러야 할 버튼(그립·트리거 등)을 컨트롤러 그림에 강조해 실제 손 위치에 띄움. 컨트롤러 그림·모델은 아트 요청 필요(없으면 도형+글자).
  - 출발점: 개발용 헤드셋 안 안내판 `Runtime/UI/TestGuidePanel.cs`(M1-04, 보정 단계 안내·펀치 결과).
