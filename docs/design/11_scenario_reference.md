# 11 한 판 대본 참고표 (v3 초안)

`10_game_scenario.md`(장면 순서 대본)의 수치·목록만 모은 표. 대본과 다르면 대본이 우선. 수치는 제안값.

## 플레이어 기술

막기는 모든 무기에서 같다(든 팔을 얼굴 앞에 세우기, 지금 가드 판정). 이동·회피도 같다(두 스틱 같은 방향).

| 무기 | 기술 | 조작 | 효과 (보스 HP 대비) |
|---|---|---|---|
| 근접: 왼 방패 · 오른 검 (1·2페이즈) | 베기 / 방패 밀치기 | 검 = 훅 인식, 방패 = 잽 인식, 그립 유지 | 3% / 2% |
| | 연계 | 베기(오) → 밀치기(왼) → 큰 베기(오) → 트리거 부스트 | 큰 베기 5% + 부스트 6% |
| | 튕기기 | 명중 0.2초 전 안에 정확히 막기 | 반대 팔만 2초 동안 피해 2배 |
| | X자 막기 | 방패·검을 얼굴 앞에서 엇갈림 | 내려찍기 피해 0 + 보스 휘청 |
| | 드론 쳐내기 (2페이즈) | 가까이 온 드론을 베기·밀치기 | 격추 |
| 사격: 왼 포 · 오른 스캐너 (1페이즈 사격 패턴, 자동 전환) | 지정 (오른) | 레이저를 1초 계속 비춤, 떼면 풀림 | 왼팔 조준이 붙음 |
| | 충전 포격 (왼) | 그립 쥐고 1.5초 충전 → 트리거, 반동 | 드론 격추 / 약점 6% |
| | 요격 (오른) | 트리거로 짧은 기관포 | 포탄 떨굼 |
| | 크레인 코일 | 오른 지정 → 왼 발사 | 6% + 휘청, 1페이즈 한 번 |
| 맨손 (3페이즈) | 잽·훅·어퍼컷, 잽–잽–훅–부스트 | 지금 그대로 | 3% / 5% / 4% / +6% |
| | 휘청 중 어퍼컷 | 보스 휘청 중 어퍼컷 | 8%, 보스 들림 |
| | 사일로 처박기 | 3페이즈 첫 부스트 | 보스 휘청 |
| | 해킹 드론 떼기 | 동료 팔의 드론을 그립으로 잡고 1초 당김 | 동료 팔 복구 |

## 보스 기술 (새 클립 0개)

| 기술 | 클립 | 예고 | 대응 | 실패 피해 | 첫 등장 | 좌우 분담 |
|---|---|---|---|---|---|---|
| 좌/우 펀치 | 좌·우 펀치 | 1.2 | 그쪽 팔 막기 | 6 | 1 | 오는 쪽은 반대쪽 HUD에만 |
| 두 손 내려찍기 | 내려찍기 | 1.8 | X자 막기 | 12 | 1 | – |
| 드론 띄우기 | 뒤로 걷기 + 포효 | – | 쏨(1) / 쳐냄(2) | 드론당 4 | 1 | 먼저 닿을 쪽은 반대쪽 HUD에만 |
| 주먹 포탄 · 연속 포탄 | 펀치·연타 클립 + 탄 | 1.2 | 요격(1) / 막기(2·3) | 6 / 발당 4 | 1 | 교차 예고 |
| 가짜 펀치 | 펀치 앞부분 → 반대 펀치 | 1.2 | 진짜 쪽만 막기 | 8 | 2 | 가짜 표시는 반대쪽 HUD에만 |
| 무작위 연타 | 좌·우 펀치 1.4배속 4번 | 1.2, 이후 0.7 | 들어오는 쪽 막기 | 타당 4 | 2 | 순서 무작위, 교차 예고 |
| 돌진 | 돌진 | 2.0 | 같은 쪽 회피 | 15 | 2 | 방향은 한쪽 HUD에만, 피하면 컨베이어 다리에 박혀 휘청 4초 |
| 가슴 포격 | 포효 + 충전 구 + 광선 | 2.0 | 같은 쪽 회피 | 15 | 2 | 방향은 한쪽 HUD에만 |
| 해킹 드론 | 펀치를 막을 때 드론이 붙음 | – | 동료가 떼어 줌 | 0 | 3 | 붙은 팔 2배 느림 + HUD 잡음 |
| 무릎 | 무릎 | – | 필살기 | – | 10% | – |

막으면 빈틈 3.0초, 못 막아도 1.5초. 같은 손 3번 연속 금지, 막을 수 없는 기술 연속 금지, 해킹은 한 번에 한 팔. 페이즈 경계에서 HP가 멈춘다.

## 관제 대사 번호

지금 코드(`CommanderLines.cs`) 1~16 중 1·3·7·10은 문구가 바뀌고, 4·11·12·14·15는 안 쓴다. 17~38은 새로. 문구는 대본 각 장면에 있다.

## 만들 것과 순서

| 무엇 | 코드 | 아트 |
|---|---|---|
| 검·방패(인식 재사용, 튕기기, X자) | 작음 | 검·방패(처음엔 도형) |
| 교차 HUD | 작음 | 윤주 HUD 시안에 "상대에게 알려 줄 것" 표시 |
| 근접 보스 패턴(가짜·무작위 연타·돌진·가슴 포격) | 중간, 클립 재사용 | 광선은 필살기 것 재사용 |
| 사격 모드(자동 전환·지정·충전·반동·요격) + 드론·포탄 | 큼 | 포·스캐너(원통 + 레이저 선), 드론·포탄(도형) |
| 구조물 3장면(크레인 코일, 컨베이어 다리, 사일로) | 중간 | 맵에 있는 것, 코일은 원통 |
| 해킹 드론 | 중간 | 드론 도형 재사용 |

순서: 검·방패 → 교차 HUD → 근접 보스 패턴 → 사격 모드·드론 → 구조물 → 해킹. 뒤로 갈수록 빠져도 흐름은 돈다.
