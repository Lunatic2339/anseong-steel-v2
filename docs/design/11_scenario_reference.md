# 11 한 판 대본 참고표 (v4 초안)

`10_game_scenario.md`(장면 순서 대본)의 수치·목록만 모은 표. 대본과 다르면 대본이 우선. 수치는 제안값.

## 플레이어 조작 (세 가지 + 이동)

| 조작 | 어떻게 | 1페이즈 근접 (왼 방패·오른 검) | 사격 (왼 스캐너·오른 포) | 2페이즈 (방패·검) | 3페이즈 (맨손) |
|---|---|---|---|---|---|
| 막기 | 왼팔을 얼굴 앞 왼쪽 또는 오른쪽에(지금 가드 판정 + 좌·우 칸) | 왼 방패로 양쪽 막기, 내려찍기만 양팔 | 드론 막기(피해 절반) | 같음 | 왼 팔뚝으로 양쪽, 내려찍기만 양팔 |
| 치기 | 그립 쥐고 휘두름(잽·훅 인식, 무기 중엔 어느 쪽이든 인정) | 번갈아 세 번 = 연계 | 왼: 레이저로 훑어 숨은 드론 드러내기(3초) | 같음 + 드론 쳐내기 | 잽–잽–훅 = 연계, 동료 팔 드론 잡아 당기기 |
| 트리거 | 검지 | 연계 뒤 부스트 | 오른: 드러난 드론에 발사(반동) | 부스트 | 부스트 |
| 이동 | 두 스틱 같은 쪽 | **포탄 막으며 접근** | – | **돌진 피하기** | 돌진 피하기 |

피해(보스 HP 대비): 무기 치기 3% · 연계 셋째 5% · 부스트 +6% · 사격으로 크레인 코일 6% · 맨손 잽 3% · 훅 5%. 드론 격추는 피해 0(대신 안 맞음).

## 만들 것과 순서

| 무엇 | 코드 | 아트 |
|---|---|---|
| 검·방패(치기 인식 재사용, 번갈아 연계) | 작음 | 검·방패(처음엔 도형) |
| 교차 HUD(반대쪽에만 띄우기) | 작음 | 윤주 HUD 시안 |
| 점검 표적·막기 연습 공 | 작음 | 도형 |
| 돌진 회피 + 컨베이어 다리 | 중간 | 맵에 있는 것 |
| 사격 패턴(자동 전환·훑어 드러내기·발사·반동) + 은폐 드론 | 중간 | 스캐너·포(원통 + 레이저 선), 드론(도형, 숨을 땐 반투명) |
| 크레인 코일·사일로 | 작음 | 맵에 있는 것, 코일은 원통 |
| 해킹 드론 | 중간 | 드론 도형 재사용 |

순서: 검·방패 → 교차 HUD → 점검 → 돌진 → 사격 패턴 → 구조물 → 해킹. 뒤로 갈수록 빠져도 흐름은 돈다.
