# AI 쓰는 법 (Claude / ChatGPT)

[← 처음 안내(README)](../README.md)

AI는 **반복 작업, 스크립트, 표 정리, 초안**에 강하고, 화면을 직접 못 보므로 **눈으로 보고 다듬는 일, 최종 판단**은 약합니다. 할 일마다 무엇을 맡길지는 자기 폴더의 `AI_활용.md`에 있습니다.

## 가. Claude 데스크톱 앱의 Code 탭(Claude Code)을 쓰는 사람

레포 폴더를 직접 읽고 고칠 수 있어서 가장 편합니다(Code 탭은 Claude 유료 요금제에서 쓸 수 있음).

1. Claude 데스크톱 앱 → 위쪽 **Code** 탭 → 환경 **Local** → **Select folder**로 받은 레포 폴더.
2. 모드는 처음엔 **Plan**(계획만 하고 아무것도 안 고침).
3. 첫 마디 (복사해서 이름만 바꾸기):

```
git pull 하고 README.md와 docs/members/<내 이름>/README.md 읽어줘.
내가 지금 할 일과 나에게 온 요청을 쉬운 말로 정리해줘. 아직 아무것도 고치지 마.
```

4. 레포 규칙(`CLAUDE.md`)은 Claude가 알아서 읽습니다. 따로 설명할 필요 없습니다.
5. 작업 전: "내 브랜치로 바꾸고 develop 최신 내용 받아줘"(처음 한 번은 "`yujin` 브랜치 만들어줘"). 파일을 고치게 할 때만 모드를 **Accept edits**로 바꾸고 "계획대로 진행해". 끝나면 "커밋하고 푸시해줘" → 팀 단톡방에 `[올림]`.

## 나. ChatGPT나 Claude 일반 채팅을 쓰는 사람

레포 파일을 직접 못 읽으므로 **내 파일 내용을 붙여 넣고** 시작합니다.

1. 브라우저에서 지금 하는 일의 파일(예: `docs/members/윤주/S-01_효과음.md`)과 처음 화면(`docs/members/<이름>/README.md`)을 열고, 각각 오른쪽 위 복사 버튼(Copy raw file)으로 전체 복사. 일 하나에 파일 하나씩만 붙이면 AI가 덜 헷갈립니다.
2. 새 대화에 아래 문구 + 붙여 넣기:

```
나는 5인 캡스톤 VR 게임 "안성제철" 팀에서 ___(예: 보스 애니메이션) 담당이야. 코드는 안 써.
아래는 내 지시서야. 이걸 기준으로 도와줘.
규칙: 1) 모델 뼈 이름·개수, 크기(m), 정면 방향은 바꾸면 안 돼. 2) Unity 버전은 6000.3.26f1, 프로젝트 설정은 안 바꿔.
3) 메뉴 이름이 확실하지 않으면 확실하지 않다고 말해줘. 4) 처음 하는 사람 기준으로 단계별로 알려줘.
--- 내 지시서 ---
(붙여 넣기)
```

3. 지시서가 바뀌면(바뀐 기록 확인) 새 대화를 열고 다시 붙여 넣습니다. 예전 대화는 옛 내용을 기억하고 있어서 틀린 답을 할 수 있습니다.
4. 만든 결과(스크립트, 표, 파일)는 [README의 7번](../README.md#7-결과물-넘기기-둘-중-편한-쪽)대로 넘깁니다. 일반 채팅은 레포에 직접 올리지 못합니다.

## 어떤 AI든 공통

- AI가 알려 준 메뉴가 화면에 없으면 헤매지 말고 **화면 캡처를 붙여** 다시 묻습니다(버전 차이로 틀리는 일이 흔함).
- Blender·Unity 스크립트를 돌리기 **전에 파일을 새 번호로 저장**합니다(`robot_v03.blend` → `robot_v04.blend`). 이상하면 이전 파일로 돌아가면 됩니다.
- AI가 만든 모델·이미지·소리는 그 서비스의 이용 조건(전시에 써도 되는지)을 확인하고 출처를 적습니다. 모르겠으면 팀 단톡방에.
- "프로젝트 설정을 바꿔라", "패키지를 설치해라", "뼈 이름을 바꿔라"는 답이 나오면 따르지 말고 팀 단톡방에 먼저 올립니다.
- 결정(색, 클립 고르기, 배치)은 AI 답을 참고만 하고 **사람이 보고 정합니다.** 큰 결정은 팀 회의에서 정할 것.
