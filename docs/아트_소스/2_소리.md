## 가공 (선우·Claude, Audacity 무료)

**묵직하게 만드는 법** (메카 기준):
1. **피치 낮추기**: Effect → Pitch and Tempo → *Change Speed* −30~−50%(길어지고 낮아짐). 사람 크기 소리가 거대해진다. 펀치 명중·걸음·보스 소리 전부.
2. **겹치기**: "쾅(위)" + "저음 붐(아래)" + "파편(꼬리)" 세 겹. 예: 드럼통 망치 + 저음 킥 + 철 부스러기. Audacity에서 트랙 3개 → Mix and Render.
3. **시작을 또렷하게**: 앞 무음을 0으로 자르고 첫 10ms는 그대로. 꼬리는 Fade Out.
4. **크기 맞추기**: Effect → Volume and Compression → *Normalize* −1 dB. 효과음 모노.
5. **루프**(`AMB_`·`SFX_TorsoTurn`·`SFX_BeamFire`): 끝과 처음을 0.5초 겹쳐 Crossfade, Unity에서 Loop 체크.
6. **무전기 효과**(사령관 대사): Filter Curve EQ로 300 Hz 아래·3 kHz 위 깎기 + Distortion 약하게 + 앞에 `SFX_RadioClick`.

Unity 임포트: 효과음 Force To Mono, Load Type *Decompress On Load*. 30초 넘는 배경음은 *Streaming*.
