## 항목별

### M2 · 보스 V13 빠진 발 (유진+성재)
- 찾는 게 아니라 고치는 것. Blender에서 **멀쩡한 발을 복제 → X축 대칭(Mirror) → 반대쪽 발 뼈에 웨이트 다시 묶기**가 가장 빠르다. 웨이트는 Data Transfer 모디파이어로 반대 발에서 가져오고, 버텍스 그룹 이름을 `Left`↔`Right`로 바꾼다.
- 고친 뒤 04 성능 한도 검사: **Anseong → Sandbox → Report Robot Stats**.
- 끼우는 곳: `Robot Art Settings` → Boss Model → **Anseong → Setup → Build Player Robot Prefab**.

### M3 · 표면 반복 디테일 (성재·유진, A-03)
- ambientCG 검색어: `Metal Plates`, `Diamond Plate`, `Painted Metal`, `Rust`, `Scratches`. **2K-JPG** 받기(Color·NormalGL·Roughness 정도만 씀).
- Unity: URP Lit 재질의 **Detail Inputs**에 Detail Map(회색조)·Detail Normal 넣고 타일링 8~20. 65m 로봇이라 타일이 작으면 장난감처럼 보인다 → 패널 한 칸이 사람 키 1~2m로 보이게.
- 넣는 곳: `Art/Robot/Detail/` + `SOURCES.md`.

### M5 · 조종석 계기판 소품 (성재가 필요하면)
- Quaternius Sci-Fi Essentials Kit의 화면·콘솔 조각, Kenney Space Kit. 조종석 몸체는 성재가 만들고 소품만 얹는다.
- 조종석 원점·크기 기준은 04 "아트를 바꿔 끼우는 방법" 표.

### M6 · 상대 조종사 (담당 없음 → 선우 후보)
옆 조종석의 상대가 보이는 것. 팔은 네트워크 자세로 IK, 몸은 앉은 자세.

| 후보 | 장점 | 주의 |
|---|---|---|
| **Mixamo 캐릭터**(X Bot·Y Bot, 군인·조종사 옷 캐릭터) | 뼈가 우리 로봇과 같은 Mixamo → 앉은 클립·IK 코드 그대로 | 공개 레포면 원본을 못 올림(0_라이선스) |
| Quaternius CC0 사람 캐릭터 | 공개 레포 됨 | 뼈 이름이 Mixamo와 다르면 Mixamo에 올려 자동 리깅 다시 |
| 헬멧 쓴 상반신만(직접) | 가볍고 얼굴 안 보여도 됨 | 만들 사람 필요 |

- 조종석 안이 어두우면 실루엣만 보여도 된다. 그래서 **헬멧·조종복 실루엣 + 손**이 제일 중요. 얼굴은 바이저로 가린다.
- 받기: Mixamo → Characters에서 고르고 **FBX for Unity, T-pose, With Skin**. 앉은 클립은 [3_애니메이션.md](3_애니메이션.md) A4.
- 넣는 곳: `Art/Pilot/` + `SOURCES.md`. `Robot Art Settings`에 칸이 아직 없으므로 코드 세션이 칸을 추가한다(`Editor/NetworkSessionMenu.cs`가 만드는 상대 조종사 표시).

### M7 · 훈련 표적 (M4)
- 처음엔 코드가 만드는 원판·상자로 시작(프로토타입). 진짜는 Quaternius Sci-Fi Essentials의 표적·드론, 또는 Kenney 모델을 크게 키운 것.
- 로봇 주먹보다 두세 배 큰 크기(넣어 보고 맞춤).

### M8 · VFX 소스 (유진, 11/12)
- **Kenney Particle Pack**(CC0): 불꽃·연기·섬광 텍스처 묶음. 명중 불꽃·부스터 불꽃 기본으로 충분.
- 필살기 광선·충전: 텍스처 1~2장 + Unity 파티클·라인으로 직접. 예고 발광 3종은 재질 Emission 색(일반 노랑, 강 주황, 막기 불가 빨강)으로.
- 기체 손상: 조종석 붉은 경보 조명은 VFX가 아니라 재질 Emission 깜빡임(코드). 소스 필요 없음.
- 성능: 파티클 재질은 2~3개로 묶기(Kenney 텍스처를 한 장 아틀라스로).

### M9·M10 · HUD 아이콘과 한글 폰트
- 아이콘: 윤주 시안(11/12). 참고 소스 Kenney **Game Icons**·**UI Pack (Sci-Fi)**(CC0).
- 폰트: TextMeshPro는 기본 폰트에 한글이 없다. **Noto Sans KR** 또는 **Pretendard**(둘 다 SIL OFL, 무료·재배포 가능, 크레딧 권장).
  - Unity: **Window → TextMeshPro → Font Asset Creator** → Character Set: Custom Characters에 대사·안내 글자만 넣거나, 한글 2,350자 목록 → Atlas 4096. 동적(Dynamic) 폰트 에셋으로 해도 된다.
  - 넣는 곳: `Art/UI/Fonts/` + `SOURCES.md`([크레딧]).

### M11 · 부서지는 구조물 (유진, 11/12 회의 결과에 따라)
- 원본 후보는 [4_맵_에셋.md](4_맵_에셋.md) E6. 조각은 Blender **Cell Fracture**(04 "부서지는 구조물" 기준).
