# 라이선스 · 공개 레포에 넣어도 되나

[← 목록](README.md) · 11/04 확인

우리 레포 `Lunatic2339/anseong-steel-v2`는 **공개**다. 레포에 파일을 올리면 누구나 원본 파일을 받아 갈 수 있다. 그래서 "게임 안에 넣어 쓰는 건 되지만 원본 파일을 그대로 나눠 주면 안 되는" 소스가 문제가 된다. 전시(비상업 캡스톤)에 쓰는 것 자체는 아래 소스 대부분이 허용한다.

## 세 종류

| 종류 | 예 | 공개 레포 | 할 일 |
|---|---|---|---|
| **바로 됨** | CC0(Kenney, Quaternius, Poly Haven, ambientCG, freesound CC0), 팀이 직접 만든 것 | 됨 | `SOURCES.md`에 한 줄 |
| **크레딧 필요** | CC BY 4.0(Sketchfab 일부, freesound CC BY), OFL 폰트 | 됨 | `SOURCES.md` + 결과 화면이나 시연 안내판에 만든 사람 이름 |
| **게임 안에서만 됨** | Mixamo, Unity Asset Store, Sonniss GDC 번들, Pixabay(손대지 않은 원본) | **원본 파일을 올리면 안 됨** | 아래 "결정할 것" |
| 안 됨 | 유튜브·게임·영화에서 뽑은 것, 출처 모르는 것, "재배포 금지" 표시된 것 | 안 됨 | 쓰지 않는다 |

확인한 내용(11/04):
- **Mixamo**: 상업·비상업 모두 무료. 단 "캐릭터·애니메이션 원본 파일을 배포하는 것"만 금지이고, 팀원끼리 공유는 된다. 원본 파일을 무료로 나눠 주는 것도 금지라고 적혀 있다. ([Adobe 커뮤니티 Mixamo FAQ](https://community.adobe.com/questions-696/mixamo-faq-licensing-royalties-ownership-eula-and-tos-589400))
- **Sonniss GDC 번들**: 상업 사용·표기 없음. 게임 등에 넣은 상태로만 재배포 가능, 소리 하나씩 따로 배포 금지.
- **Pixabay**: 표기 없음. 손대지 않은 원본을 "단독으로" 배포하는 것은 금지(가공해서 작품에 넣으면 됨). ([Pixabay 라이선스 요약](https://pixabay.com/service/license/))
- **Unity Asset Store**: 레포를 같이 쓰는 팀원 사용은 되지만, 공개 레포에 원본을 올리는 건 배포에 해당한다.

## ⚠️ 결정할 것: 레포를 비공개로 바꿀지

**지금도 레포에 Mixamo 애니메이션 원본 FBX(`Art/Robot/Animation/Source/Idle·Punch·Stagger·Walk.fbx`)가 공개로 올라가 있다.** 앞으로 유진 클립(A-01 우선 2)도 같은 식으로 들어온다.

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **가 (추천)** | 레포를 비공개로 바꾼다 (GitHub → Settings → Danger Zone → Change visibility) | Mixamo·Asset Store·Sonniss 모두 팀 안 공유라 문제 없음. 소스 선택 폭이 가장 넓음 | 팀원 5명을 Collaborator로 초대해야 함(무료 계정도 됨). 포트폴리오로 공개하려면 전시 후 CC0만 남겨 다시 공개 |
| 나 | 공개 유지, CC0·CC BY만 쓴다 | 설정 그대로 | Mixamo FBX는 레포에서 빼고 드라이브로 옮겨야 함(파이프라인이 파일 이름으로 찾으므로 각자 PC에 따로 넣어야 함). Asset Store·Sonniss 못 씀 |

비공개로 바꿔도 Claude 세션은 그대로 쓸 수 있다(Claude GitHub 앱 권한은 레포 단위). 결정은 **선우 또는 팀 회의**. 정하기 전까지는 **CC0·CC BY만 받는다**.

## AI로 만든 소스

- 로봇 원본은 Tripo AI, 윤주 맵은 OpenAI Codex 절차 생성이다. AI 툴은 **요금제마다 결과물 라이선스가 다르다**(무료판은 공개·표기 조건이 붙는 경우가 있음). 쓰기 전에 그 툴의 현재 약관 페이지를 캡처해 `SOURCES.md`에 붙인다.
- AI 음성(TTS)도 같다. 전시 사용이 허용되는지 확인한다.

## SOURCES.md 적는 법

받은 파일과 같은 분야 폴더의 `SOURCES.md`에 한 줄. 이미 있는 곳: `Art/Environment/SOURCES.md`. 없으면 처음 넣는 사람이 만든다(`Audio/SOURCES.md`, `Art/Robot/Detail/SOURCES.md`, `Art/Pilot/SOURCES.md`, `Art/UI/SOURCES.md`).

```
| 파일/폴더 | 사이트 | 원래 이름 | 만든 사람 | 라이선스 | 주소 |
| SFX/SFX_PunchHit_01.wav | freesound | Heavy anvil hit | (아이디) | CC0 | https://freesound.org/... |
```

크레딧이 필요한 줄(CC BY, OFL)은 맨 앞에 `[크레딧]`을 붙인다. 마지막에 이 줄들만 모아 결과 화면·안내판 크레딧을 만든다.
