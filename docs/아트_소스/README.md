## 우선순위 (선우가 아트로 돌 때)

1. **레포 비공개 전환**(선우 11/04 결정, 0_라이선스.md). 끝나면 Mixamo·Asset Store·Sonniss도 쓸 수 있다.
2. **소리 파일 위치 확인**(S1). 소리는 넣기만 하면 바로 효과가 크다(메뉴 한 번).
3. 담당 없는 것: 상대 조종사(M6), 한글 폰트(M10), 하늘(E2), 표적(M7).
4. 나머지는 팀원 마감(11/12·11/19)에 맞춰 받아서 끼운다.

## 고치는 법
- 소스를 받거나 담당이 정해지면 "지금" 칸을 고친다. 끝난 줄은 지우지 말고 날짜를 적는다.
- 새로 필요한 소스가 생기면 해당 분야 파일과 이 표에 한 줄씩.
