## 묵직하게 다듬기 (A6, 선우·Claude, M5)

Mixamo 클립은 사람 크기·사람 속도다. 65m 메카처럼 보이려면:
1. **고르는 기준**: 빠르고 경쾌한 것보다 "무거운 사람"(mutant, zombie, heavy, tired 들어간 것)이 메카에 가깝다. 같은 동작이면 Mixamo 슬라이더 *Overdrive*를 낮추고 *Character Arm-Space*를 넓게.
2. **속도**: 클립 전체를 늦추기보다 **예고(준비) 구간만 길게, 때리는 순간은 그대로**. 전체를 늦추면 물속처럼 보인다. 예고 시간은 기술 에셋(`Data/Boss/`)에서.
3. **골반 흔들림**: 걷기·돌진 클립의 골반 위아래·앞뒤 흔들림을 줄인다(Blender에서 Hips 곡선 감쇠, 또는 In Place). 큰 몸이 통통 튀면 가벼워 보인다.
4. **구간 자르기**: FBX Inspector → Animation → 클립 Start·End. 앞뒤 대기 프레임을 잘라 예고 시간과 맞춘다.
5. 손가락 곡선은 버린다(주먹 고정, 04).

## 확인할 것 (사람)
- 새 클립마다 보스가 제자리에서 미끄러지지 않는지(In Place), 팔이 몸통을 파고들지 않는지.
- 돌진·포효·무릎이 멀리서(약 40m) 봐도 무슨 동작인지 읽히는지.
