# 완성까지 남은 것 (마일스톤별)

마일스톤은 **프로토타입 제작**이다(선우 11/04). 뼈대를 먼저 빨리 깔고, 아트·소리·HUD가 갖춰지는 대로 갈아 끼워 완성한다. 이 폴더는 프로토타입이 끝난 마일스톤마다 "완성하려면 아직 갖춰져야 하는 것"을 적는 살아 있는 목록이다.

| 파일 | 마일스톤 | 상태 (11/04) |
|---|---|---|
| [M1.md](M1.md) | 1인 양팔 (팔·펀치·가드·보정) | 프로토타입 끝, develop 병합 |
| [M2.md](M2.md) | 1인 보스전 (보스 공격·막기·페이즈·필살기) | 01~05 병합, 06 보스 클립 확인 중 |
| [M3.md](M3.md) | 2인 협동 (접속·동기화·이동·외골격·빌드 2대) | 01 병합, 02~05 브랜치·PR, 2대 확인 남음 |
| [팀원별_받을_것.md](팀원별_받을_것.md) | 위 목록을 사람·날짜순으로 다시 묶은 것 | |

## 파일마다 같은 네 칸
1. **임시 → 교체**: 지금 임시인 것, 진짜는 무엇, 누가·언제, 끼우는 곳(에셋·설정 칸·메뉴).
2. **헤드셋 확인 남음**: 프로토타입이라 대충 넘긴 것 중 전시 전에 한 번은 봐야 하는 것.
3. **나중에 다듬을 값·느낌**: 돌아가지만 수치·모양을 맞춰야 하는 것.
4. **결정 대기 / 문서 고칠 것**.

## 고치는 법
- 마일스톤 프로토타입이 끝나면 그 마일스톤 스레드가 `M<번호>.md`를 새로 만들고 위 표에 한 줄 넣는다.
- 교체가 끝나면 그 줄을 지우지 말고 맨 아래 "끝난 것"으로 옮겨 날짜·PR을 적는다.
- 새 임시가 생기면(지시서 결과 칸의 "남은 문제") 같은 커밋에서 여기에도 한 줄.
- 끼우는 곳의 기본 원칙: 아트는 `Robot Art Settings` 칸, 소리는 `Audio/` 파일 이름 + `CombatCues.asset`, 수치는 조절 메뉴(오른손 B)나 기술 에셋. 경로를 코드에 적지 않으므로 대부분 **파일을 넣고 메뉴를 다시 돌리면** 바뀐다.
