# 빌드 2대로 실행하기 (M3-05)

PC-A = 호스트 + 왼팔 조종사, PC-B = 클라이언트 + 오른팔 조종사. 직결, 포트 7777. 같은 빌드끼리만 붙는다.
1인 양팔(한 PC가 두 팔)은 시연 당일 대체용이라 같은 빌드로 항상 확인해 둔다.

> 프로토타입 절차서. 시연 전(M6)에 실제 장소 기준으로 다시 고친다.

## 1. 준비물
- PC 2대, 각각 Quest 3 + Link 케이블(또는 Air Link). 헤드셋 화면은 PC가 그린다.
- 두 PC가 **같은 공유기·스위치**에 연결(가능하면 유선). 학교·공용 와이파이는 PC끼리 막혀 있을 수 있다.
- USB 메모리나 공유 폴더(빌드 복사용).
- 외골격을 쓰면 각 PC에 자기 ESP32를 USB로. 없어도 게임은 끝까지 돈다.

## 2. 빌드 만들기 (선우 PC, 한 번)
1. `develop`(또는 시험할 브랜치) pull → Unity에서 `error CS` 없는지 확인.
2. `Main.unity` 열기 → **Anseong → Setup → Build M1 Main** → Ctrl+S. (Build Profiles 씬 목록 맨 앞에 Main, 그다음 맵이 들어간다.)
3. **File → Build Profiles** → Windows 선택.
   - 기록(펀치·가드 CSV, Console 기록)이 필요하면 **Development Build** 체크. 시연용 최종 빌드는 끈다.
4. **Build** → 프로젝트 안 `Builds/<날짜>` 폴더(git 무시됨)를 고른다.
5. 만들어진 폴더 **통째로** PC-B에 복사한다. `AnseongSteel.exe`만 복사하면 안 된다.

두 PC는 반드시 **같은 빌드 폴더**를 쓴다. 다르면 PC-B 화면에 "두 PC의 게임 빌드가 다릅니다"가 뜨고 거절된다.

## 3. 바로가기 만들기 (각 PC, 한 번)
`AnseongSteel.exe` 우클릭 → 바로 가기 만들기 → 바로가기 우클릭 → 속성 → **대상** 끝에 한 칸 띄우고 붙인다.

| PC | 대상 끝에 붙일 것 |
|---|---|
| PC-A | `-mode host` |
| PC-B | `-mode client -ip 192.168.0.10` (PC-A의 IP로 바꿈) |
| 1인 양팔 | `-mode solo` |
| 외골격(M3-04 병합 뒤) | `-exoLeft COM3` / `-exoRight COM4` (장치 관리자 → 포트에서 번호 확인) |

인자 없이 실행하면 모니터에 **운영자 시작 화면**이 뜬다(1·2·3으로 모드, IP 칸, Enter 시작). 마지막 모드·IP는 그 PC가 기억한다.

**PC-A의 IP 알기:** 시작 화면에서 "호스트"를 고르면 화면에 나온다. 또는 PC-A cmd에서 `ipconfig` → "IPv4 주소".

## 4. 처음 한 번: 방화벽
PC-A에서 처음 실행하면 Windows 방화벽 창이 뜬다 → **개인 네트워크 허용**.
- 창이 안 떴는데 PC-B가 못 붙으면: 설정 → 네트워크 → 지금 연결의 **네트워크 프로필을 "개인"**으로. 그래도 안 되면 방화벽 → "앱 허용"에서 AnseongSteel의 개인·공용 둘 다 체크.

## 5. 실행 순서
1. 두 PC 모두 Quest Link를 켜고 헤드셋에 Link 화면이 보이게 한다.
2. **PC-A** 바로가기 실행 → 모니터 왼쪽 위 상태 줄 "호스트(PC-A, 왼팔) · 조종사 1/2".
3. **PC-B** 바로가기 실행 → 5초 안에 붙으면 두 PC 상태 줄 "조종사 2/2".
4. 각자 헤드셋을 쓰고 보정(정면 뻗기 → 가드). 보정은 PC마다 따로.
5. 판 시작. 판 재시작은 **두 스틱을 함께 1초 누르기** 또는 오른손 B 메뉴 **판 → 판 재시작**(어느 PC에서 해도 된다).
6. 끝낼 때는 PC-B 먼저, PC-A 나중.

헤드셋 쓴 사람은 키보드를 건드리지 않는다. 모드 바꾸기·재접속은 모니터 앞 운영자가 상태 줄의 **다시 고르기**로.

## 6. 1인 양팔 확인 (같은 빌드)
PC 한 대에서 `-mode solo` 바로가기 → 한 사람이 두 팔로 페이즈 1을 끝까지. 다른 PC 접속은 거절된다(정상).

## 7. 안 될 때
| 보이는 것 | 할 것 |
|---|---|
| PC-B "… 찾는 중" 뒤 실패 | IP 오타 확인, 두 PC가 같은 공유기인지, PC-A 방화벽(4번), PC-A가 먼저 켜져 있는지 |
| "두 PC의 게임 빌드가 다릅니다" | PC-A 빌드 폴더를 PC-B에 다시 통째로 복사 |
| "이미 조종사 2명" | 다른 PC나 같은 PC에서 빌드가 하나 더 켜져 있음 → 끄기 |
| "상대 PC가 1인 양팔 모드" | PC-A를 `-mode host`로 다시 실행 |
| PC-B "호스트와 연결이 끊겼습니다" | PC-A가 꺼졌거나 네트워크 끊김 → PC-A 켜고 PC-B에서 다시 고르기 → 시작 |
| 헤드셋이 까맣다 / 모니터에만 나온다 | Link를 먼저 켠 뒤 실행. Meta Quest Link 앱 → 설정 → 일반 → OpenXR 런타임을 Meta Quest Link로 |
| 상대 팔이 안 움직인다 | M3-02(상대 팔·머리 보이기)가 빌드에 들어갔는지 확인 |

## 8. 기록 보기 (Development Build만)
각 PC의 `%USERPROFILE%\AppData\LocalLow\AnseongSteel\AnseongSteel\logs\`
- `session_*.txt`: Console 전부(접속·거절·`[Move]` 등), `strikes_*.csv`, `guard_*.csv`, `tuning.txt`(한 단계 위 폴더).
- 문제가 생기면 두 PC의 `session_*.txt`를 같이 올리면 Claude가 본다.
