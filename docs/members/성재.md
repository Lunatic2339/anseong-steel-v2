## AI 활용 안내

**모두 공통**

- **Claude에게 맡기면 좋은 것**: 같은 일을 여러 번 반복하는 작업(스크립트), 표·목록 정리, 초안 쓰기. Claude는 화면을 직접 못 보므로 **모양을 빚거나 눈으로 다듬는 일은 약합니다.** 그런 일은 사람이 합니다.
- **3D 생성 AI**(우리 로봇을 만든 Tripo 같은 것)는 **소품 초안**용입니다. 나온 모델은 Blender에서 다듬어야 하고, 뼈대가 있는 모델(로봇·보스)에는 쓰지 않습니다.
- AI로 만든 파일도 출처를 적습니다: `SOURCES.md`(또는 드라이브 `SOURCES`)에 `파일 이름 / AI 생성 / 서비스 이름 / 날짜 / 그 서비스의 이용 조건(전시에 써도 되는지)`. 이용 조건을 모르면 쓰기 전에 팀 단톡방에 올려 같이 봅니다.
- 요청하는 곳: 자기 Claude가 있으면 직접, 없으면 아래 예시 문구를 **팀 단톡방**에 그대로 올리면 코드 담당(선우)의 Claude 세션이 만듭니다.
- Claude가 알려 준 메뉴 이름이 화면에 없으면(버전 차이로 틀릴 수 있음) 찾느라 헤매지 말고 화면 캡처를 보내 다시 묻습니다.
- 스크립트는 **실행 전에 파일을 새 번호로 저장**하고 돌립니다. 결과가 이상하면 이전 번호 파일로 돌아가면 됩니다.

## H-02 ② PC-B 세팅 · ③ 두 PC 연결 (10/22까지)

PC-B를 PC-A(선우 PC)와 **완전히 같은 상태**로 만드는 것이 목표입니다. 프로젝트 설정이나 패키지는 **절대 바꾸지 마세요**. 문제가 생기면 고치려 하지 말고 화면을 찍어 팀 단톡방에 올리면 됩니다.

### ②-1 사양 기록 (5분)

1. `Ctrl + Shift + Esc` → 작업 관리자 → **성능** 탭.
2. CPU 이름, 메모리(GB), GPU 이름을 캡처해 팀 단톡방에 올리기.
3. **팀 회의에서 정할 것**: 이 사양으로 VR이 돌아가는지. GPU가 약하면 다른 PC를 PC-B로 써야 할 수 있습니다.

### ②-2 Unity 설치 (30분~1시간)

1. Unity Hub를 설치하고 Unity 계정으로 로그인.
2. 브라우저에서 Unity 다운로드 아카이브("Unity download archive"로 검색) → **6000.3.26f1**을 찾아 옆의 Unity Hub 버튼 클릭 → Hub에서 설치가 시작됨.
3. 모듈 선택 화면에서는 **아무것도 추가하지 않아도 됩니다**(Windows용 실행은 기본 포함). 버전 번호가 한 글자라도 다르면 안 됩니다.

### ②-3 Quest Link 앱 (15분)

1. Meta 공식 사이트에서 **Meta Quest Link** PC 앱 설치, 헤드셋과 같은 Meta 계정으로 로그인.
2. 앱 → **설정 → 일반** → OpenXR 런타임 항목에서 **Meta Quest Link를 활성화로 설정**.
3. 헤드셋을 케이블로 연결(케이블이 아직 없으면 Air Link) → 헤드셋 빠른 설정에서 **Link** 켜기 → 헤드셋에 어두운 Link 화면이 뜨면 성공.

### ②-4 레포 받기 (20분 + Unity 첫 열기 10~30분)

1. GitHub 초대 메일을 **수락**.
2. **GitHub Desktop** 설치 → 로그인 → File → Clone repository → URL 탭에 `https://github.com/Lunatic2339/anseong-steel-v2.git` → 저장 위치는 경로에 한글이 없는 곳(예: `C:\Projects\`).
3. Unity Hub → Projects → **Add → Add project from disk** → 받은 폴더 선택 → 열기. 처음은 오래 걸립니다.
4. 열리면 아래 Project 창에서 `Assets/_Anseong/Scenes/Main` 더블클릭.

### ②-5 헤드셋 확인 (10분)

1. Link가 켜진 상태에서 Unity 위쪽 ▶(Play) 클릭.
2. 헤드셋을 쓰고 확인:
   - [ ] 고개를 돌리면 시야가 따라온다
   - [ ] 양손의 초록 큐브가 컨트롤러 손잡이를 따라온다
   - [ ] 화면이 끊기거나 떨리지 않는다
3. Unity 아래 Console 창에 빨간 오류가 있으면 캡처.

### ③ 두 PC 랜 연결 (30분, 선우와 같이)

1. 두 PC를 랜선으로 허브(또는 공유기)에 꼽기.
2. 각 PC에서 네트워크 프로필을 **개인(Private)으로**: 설정 → 네트워크 및 인터넷 → 이더넷 → 네트워크 프로필 유형 → 개인.
3. 허브만 쓰면 IP를 직접 지정(공유기를 쓰면 이 단계는 건너뜀): 이더넷 → IP 할당 편집 → 수동 → IPv4 켜기 → PC-A `192.168.10.1`, PC-B `192.168.10.2`, 서브넷 `255.255.255.0`, 나머지 빈칸.
4. 명령 프롬프트에서 `ipconfig`로 각자 IP 확인 → PC-B에서 `ping 192.168.10.1`, PC-A에서 `ping 192.168.10.2`.
5. ping이 안 되면 Windows 방화벽이 막고 있는 것입니다: Windows 보안 → 방화벽 및 네트워크 보호 → 고급 설정 → 인바운드 규칙 → "파일 및 프린터 공유(에코 요청 - ICMPv4-In)"을 사용으로.
6. Unity를 처음 Play할 때 방화벽 창이 뜨면 **개인·공용 모두 허용**.

### ④ 멀티플레이 검증 (선우와 같이, 같은 기숙사에서)

2인 네트워크 코드가 준비되면 성재님과 선우가 기숙사에서 PC-A·PC-B를 나란히 놓고 각자 헤드셋을 쓰고 시험합니다. 성재님은 **오른쪽 조종사(PC-B)** 자리를 맡습니다. 코드는 선우가 준비하고, 성재님은 플레이하면서 느낀 점을 말해 주면 됩니다. 날짜·횟수는 팀 회의에서 정합니다.

매번 확인할 것:

- [ ] PC-B가 PC-A에 접속됨(세 번 연속)
- [ ] 내 팔은 손을 바로 따라옴, 상대 팔은 끊김 없이 부드럽게 움직임
- [ ] 두 사람이 스틱을 같은 방향으로 밀 때만 로봇이 이동
- [ ] 잽–잽–훅 연계에서 차례가 맞게 넘어감
- [ ] 보스 동작·HP가 두 화면에서 같음
- [ ] 랜선을 뽑았다 다시 꼽아도 게임이 멈추지 않음

끝나면 "어색했던 순간"을 한 줄씩 적어 둡니다(예: "훅 때 상대 팔이 잠깐 멈춤"). 화면 녹화가 있으면 더 좋습니다.

## A-02 Blender 로봇 메시 정리 (10/23 ~ 11/05)

지금 로봇은 렌더러 291개·재질 124개라 무겁고, 텍스처를 빼면 비누처럼 둥글게 보입니다. 목표는 **렌더러 8개 이하, 재질 6개, 각진 모서리**입니다. 삼각형 수(약 5.9만)는 줄일 필요가 없습니다.

**절대 바꾸면 안 되는 것** (바꾸면 코드가 깨집니다)

- 뼈 이름·개수·계층(`mixamorig:` 로 시작하는 뼈 전부, `_End`로 끝나는 뼈 포함)
- 팔 길이 비율, 로봇 크기, 정면 방향
- 원래 UV(첫 번째 UV)
- 레포의 원본 `BossUpdatedCompatible.fbx`(복사본에서만 작업)

### 0단계 (10/23): 준비와 왕복 시험 — 가장 중요

며칠 작업한 뒤에 "내보내기 설정이 틀려서 모두 다시"가 되지 않도록, **아무것도 안 바꾼 채 읽었다 내보내는 시험**을 먼저 합니다.

1. **팀 회의에서 정할 것**: 쓰는 Blender 버전(4.1 이상 권장. 아래 메뉴 이름은 4.1+ 기준).
2. 레포의 `Assets/_Anseong/Art/Robot/Source/` 폴더 통째(FBX + `Textures` 폴더)를 **레포 밖** 작업 폴더로 복사(예: `C:\Work\robot\`).
3. Blender 새 파일 → 기본 큐브·카메라·라이트 삭제 → File → Import → FBX → 복사한 `BossUpdatedCompatible.fbx`. 옵션은 기본값, 단 **Automatic Bone Orientation과 Ignore Leaf Bones는 둔 채**로.
4. 텍스처가 분홍색이면 File → External Data → Find Missing Files → `Textures` 폴더 지정.
5. 바로 `robot_v01_import.blend`로 저장(버전별로 번호를 올려 저장. .blend는 드라이브에 보관하고 레포에 넣지 않음).
6. 아무것도 바꾸지 않고 아래 **내보내기 설정표**대로 `Robot_roundtrip_test.fbx`를 내보내 Unity 담당(선우)에게 전달.
7. Unity 담당(선우)이 Unity에서 뼈 이름·개수, Armature 스케일 1, 높이 약 1.056m, Idle 재생을 검사해 **"설정 통과"라고** 답하면 1단계로. 틀린 곳이 있으면 설정을 고쳐 다시.

**내보내기 설정표** (File → Export → FBX, 왕복 시험과 최종본 모두 똑같이)

| 항목 | 값 |
|---|---|
| Limit to | Selected Objects (Armature와 메시를 선택한 뒤 내보내기) |
| Object Types | **Armature, Mesh만** (Camera·Light·Empty 끄기) |
| Transform | Scale 1.00, Forward -Z, Up Y (기본값). Apply Transform 끔 |
| Geometry | Smoothing: Normals Only(기본값) |
| Armature | **Add Leaf Bones 끔** (켜면 뼈가 늘어나 검사 실패) |
| Bake Animation | 끔 (애니메이션은 따로 있음) |
| 나머지 | 기본값. 바꾼 것이 있으면 캡처를 함께 보내기 |

### 1단계 (10/24~25): 병합

1. Object Mode에서 Select 메뉴 → **Select All by Type → Mesh**(메시 291개만 선택, Armature는 제외).
2. `Ctrl + J`로 합치기. 단, 머리 부품(Head·Head_end 뼈에 붙은 조각, 지금 11개)은 먼저 그들끼리만 합쳐 Robot_Head 하나로 따로 남깁니다. 조종석이 로봇 머리 안에 있어서 게임에서 자기 로봇 머리만 숨겨야 하기 때문입니다. 11개 부품 이름은 팀 단톡방에 올려 드립니다. 나머지는 하나로 합쳐도 됩니다(머리 포함 전체 최대 8개).
3. 확인: 합친 메시의 모디파이어에 Armature가 **하나** 있고, Object Data 탭 → Vertex Groups에 `mixamorig:` 이름이 여러 개 있음.
4. 포즈 시험: Armature 선택 → Pose Mode → 상완 뼈(LeftArm)를 R로 돌려 보기 → 팔 메시가 따라오면 성공 → Pose → Clear Transform → All로 되돌리기.
5. `robot_v02_joined.blend`로 저장.

### 2단계 (10/26~27): 각진 모서리

1. 메시 선택 → Object 메뉴 → **Shade Auto Smooth** → 모디파이어에 Smooth by Angle이 생김.
2. Angle을 30°, 35°, 45°로 바꿔 가며 비교(Solid 보기에서 판 경계가 또렷하고 둥근 부분은 매끄러운 값). 세 값의 캡처를 팀 단톡방에 올리고 같이 고르기.
3. 더 날카로워야 할 곳만 Edit Mode에서 모서리 선택 → Edge → Mark Sharp.
4. **적용 순서 주의**: Smooth by Angle을 모디파이어 맨 위로(▼ → Move to First) 옮긴 뒤 ▼ → Apply. Armature 모디파이어는 **적용하지 않고 남김**.
5. (선택, 마지막 수단) 면이 울퉁불퉁한 부위만 Decimate(Planar). 쓴 뒤 포즈 시험으로 찢어짐 확인. 하기 전에 팀 단톡방에 알리기.
6. `robot_v03_sharp.blend` 저장.

### 3단계 (10/28): 비교용 굽기 — 원래 재질이 붙어 있을 때

나중에 표면 방식 3안을 비교하려면 텍스처 2장이 필요합니다. **재질을 바꾸기 전에** 해야 합니다.

1. Object Data 탭 → UV Maps → **+** → 이름 `UV_Bake`. 이 줄을 선택(편집 대상)하되, 카메라 아이콘(렌더용)은 원래 UV에 그대로.
2. Edit Mode → 전체 선택(A) → UV → Smart UV Project(Island Margin 0.02).
3. 렌더 엔진을 Cycles로. Image Editor에서 새 이미지 2개: `Robot_v026_AO` 2048, `Robot_v026_Atlas` 4096(Alpha 끔).
4. 굽기는 **모든 재질에** 대상 이미지 노드가 선택돼 있어야 합니다. 재질이 124개라 손으로는 오래 걸리므로, **팀 단톡방에 "굽기용 Blender 스크립트"를 요청**하세요. Claude가 모든 재질에 노드를 넣고 굽기까지 하는 스크립트를 만들어 드립니다(Scripting 탭에 붙여넣고 실행).
5. 직접 한다면: Bake Type **Ambient Occlusion**, Margin 16px → AO 이미지 / Bake Type **Diffuse**, Contributions에서 Direct·Indirect 끄고 Color만 → Atlas 이미지.
6. 각 이미지를 Image → Save As로 PNG 저장. `robot_v04_baked.blend` 저장.

### 4단계 (10/29~11/01): 재질 6개로 다시 배정

| 슬롯 이름 (정확히 이 이름) | 어디에 |
|---|---|
| `ArmorMain` | 큰 장갑판(가슴·어깨·허벅지 큰 판) |
| `ArmorAccent` | 포인트 장갑(줄무늬·작은 색 있는 판) |
| `Metal` | 관절·프레임·피스톤 |
| `Dark` | 안쪽 기계·틈·그림자 부분 (애매하면 여기) |
| `Glow` | 빛나는 곳(눈·라인) |
| `Trim` | 테두리·장식 |

1. 재질 패널에서 위 6개 재질을 새로 만들기(색은 구분만 되게 아무 색).
2. Edit Mode에서 원래 재질 슬롯을 고르고 **Select**(그 재질 면이 선택됨) → 새 슬롯 고르고 **Assign**. 124개 반복.
3. 헷갈리면 원래 색을 기준으로: 흰색·밝은 큰 판 → ArmorMain, 파랑·빨강 포인트 → ArmorAccent, 회색 금속 → Metal, 검은 안쪽 → Dark.
4. 끝나면 재질 패널 ▼ → **Remove Unused Slots** → 슬롯이 6개만 남았는지 확인.
5. 앞·옆·뒤 캡처 3장을 팀 단톡방에(슬롯별로 색이 다르게 보이는 상태). `robot_v05_slots.blend` 저장.

### 5단계 (11/02~03): 내보내기와 전달

1. Armature + 메시만 선택 → 위 내보내기 설정표 그대로 → `Robot_v026_clean.fbx`.
2. 드라이브 폴더 `안성제철_로봇정리`에 FBX + `Robot_v026_AO.png` + `Robot_v026_Atlas.png` + 최신 .blend를 올리고 팀 단톡방에 링크.
3. Unity 담당(선우)이 뼈 검사·비교 화면으로 확인 → 고칠 것이 있으면 11/05까지 반영.
4. 중간 버전은 레포에 넣지 않습니다(내보낼 때마다 약 20MB씩 쌓임). 통과한 버전만 선우가 넣습니다.
