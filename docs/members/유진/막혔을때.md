# 유진 — 막혔을 때

[← 유진 처음으로](../README.md)

| 증상 | 해결 |
|---|---|
| Mixamo에서 원하는 동작이 안 나옴 | 검색어를 바꿔 보기(예: slam → smash, stomp, ground punch). 비슷한 것을 2개 받아 두고 표에 적기 |
| 왼손 버전이 없음 | 오른손만 받고 "왼손 없음"이라고 적기. 좌우 뒤집기는 코드 담당이 처리 |
| 미리보기에서 팔이 몸을 뚫음 | Character Arm-Space를 조금 올리기. 우리 로봇은 기본 캐릭터보다 어깨가 넓어서 게임 안에서는 달라 보일 수 있음 |
| 파일이 너무 큼(수십 MB) | With Skin으로 받은 것. Without Skin으로 다시 받기 |
| 동작이 앞으로 미끄러져 나감 | In Place 체크 안 함. 체크하고 다시 받기 |
| 프레임 번호를 볼 방법이 없음 | 팀 단톡방에 말하면 프레임 번호가 찍힌 영상을 만들어 드립니다 |
| 슬라이드 링크에서 수정이 안 됨 | 팀 단톡방에. 편집 권한을 다시 주거나 파워포인트 파일로 드림 |

혼자 30분 넘게 막히면 멈추고 **화면 캡처 + 무엇을 하다가 생겼는지 한 줄**을 팀 단톡방에 올려 주세요.
