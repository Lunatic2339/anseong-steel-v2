# 유진 — AI 활용 안내

[← 유진 처음으로](../README.md)

**모두 공통**

- **Claude에게 맡기면 좋은 것**: 같은 일을 여러 번 반복하는 작업(스크립트), 표·목록 정리, 초안 쓰기. Claude는 화면을 직접 못 보므로 **모양을 빚거나 눈으로 다듬는 일은 약합니다.** 그런 일은 사람이 합니다.
- **3D 생성 AI**(우리 로봇을 만든 Tripo 같은 것)는 **소품 초안**용입니다. 나온 모델은 Blender에서 다듬어야 하고, 뼈대가 있는 모델(로봇·보스)에는 쓰지 않습니다.
- AI로 만든 파일도 출처를 적습니다: `SOURCES.md`(또는 드라이브 `SOURCES`)에 `파일 이름 / AI 생성 / 서비스 이름 / 날짜 / 그 서비스의 이용 조건(전시에 써도 되는지)`. 이용 조건을 모르면 쓰기 전에 팀 단톡방에 올려 같이 봅니다.
- 요청하는 곳: 자기 Claude가 있으면 직접, 없으면 아래 예시 문구를 **팀 단톡방**에 그대로 올리면 코드 담당(선우)의 Claude 세션이 만듭니다.
- Claude가 알려 준 메뉴 이름이 화면에 없으면(버전 차이로 틀릴 수 있음) 찾느라 헤매지 말고 화면 캡처를 보내 다시 묻습니다.
- 스크립트는 **실행 전에 파일을 새 번호로 저장**하고 돌립니다. 결과가 이상하면 이전 번호 파일로 돌아가면 됩니다.

**유진님 일에서**

| 일 | AI(Claude)에 맡겨도 됨 | 직접 해야 함 |
|---|---|---|
| A-01 애니메이션 | 검색어 후보 더 뽑기, 받은 클립의 길이·반복 표 정리 | Mixamo에서 **고르기**(묵직한지, 예고가 보이는지는 눈으로) |
| D-01 보스 패턴 | 프레임 번호 → 초 계산, 표 정리, "어색한 곳"을 바탕으로 수치 고친 안 | 클립을 보며 어색한지 판단, 최종 수치 확인 |
| P-01 발표 | 슬라이드 초안("P-01 발표 초안 만들어줘"), 말할 내용 초안 | 내용이 맞는지 확인, 발표 연습 |
| 보스 색 | 6슬롯 색 조합 2~3안(색 코드), 플레이어 색과 겹치지 않는지 점검 | 헤드셋으로 40m 거리에서 보고 고르기(팀 회의에서 정할 것) |
| 부서지는 조각 | 여러 구조물에 Cell Fracture를 같은 설정으로 돌리고 `_Intact`·`_Broken`을 같은 위치로 내보내는 Blender 스크립트 | 조각 모양이 자연스러운지, 삼각형 5,000 이하인지 확인 |
| 효과(VFX) | 무료 효과 팩 후보 찾기, 레퍼런스 표 정리 | 어떤 느낌이 좋은지 고르기 |

- AI 동작 생성 도구로 만든 애니메이션은 뼈대가 달라 쓰지 않습니다. 동작은 Mixamo에서 받습니다(쓰고 싶으면 팀 회의에서 정할 것).
- AI 이미지는 **레퍼런스(참고 그림)** 로는 써도 됩니다. 게임 안에 들어가는 그림·텍스처로 쓰면 출처를 적습니다.

**요청 예시**

```
D-01 보스 패턴 표에서 Boss_PunchLeft는 30fps로 준비 동작이 0~28프레임, 때리는 순간이 34프레임이야.
준비 시간과 명중 시간을 초로 바꿔서 표의 "예고" "명중" 칸에 넣어줘.
```

```
보스 색 조합 3안 만들어줘. 슬롯은 ArmorMain, ArmorAccent, Metal, Dark, Glow, Trim.
플레이어는 흰색·파랑·하늘색 발광이고, 보스는 공격 전 붉게 빛나니까 Glow에 빨강은 피해줘.
배경은 회색·갈색 제철소야. 색 코드로 표를 만들어줘.
```
