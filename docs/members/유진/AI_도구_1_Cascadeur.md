# 유진 — Cascadeur로 보스 클립 다듬기

[← 유진 처음으로](README.md) · 전체 도구 표: [13 AI 도구](../../design/13_ai_tools.md) · 일정: [07 마일스톤](../../design/07_milestones.md)

## 무엇을, 왜

게임 전체 기준은 **"복싱 게임이 아니라 육중한 로봇"**입니다. 지금 보스 클립(유진님이 가져온 Mixamo 동작)은 사람처럼 가볍고 빠릅니다. Cascadeur로 **같은 동작을 무겁게** 다듬습니다.

- **새 동작은 만들지 않습니다**(대본 확정 사항 6, 팀 부담). 지금 클립을 고치거나, 지금 클립을 조금 바꾼 "변형"까지만.
- 학교에 낸 활용 계획서에는 "기존에 없는 모션 생성"으로 적었습니다. 그래서 **지금 클립을 바꾼 변형**으로 없는 동작 3개(돌진·무릎·밀려남)를 만드는 것을 제안합니다. 완전히 새 동작(던지기·발차기)은 안 합니다. 확정은 **팀 회의에서 정할 것**(11/12).
- 플랜은 Cascadeur **Pro**(한 달 구독, FBX 내보내기·상업 사용 됨). 구독이 끝나기 전 **12/08까지** 모든 클립을 내보내 둡니다.
- 손가락은 건드리지 않습니다(코드가 주먹으로 고정).

## 준비 (한 번만, 11/12~11/13)

1. 선우에게서 계정을 받아 cascadeur.com에서 프로그램을 설치하고 로그인합니다.
2. 로그인한 뒤 플랜이 **Indie나 Pro**로 보이는지 확인합니다. 무료(Free)로 보이면 FBX로 내보낼 수 없으니 팀 단톡방에 알립니다.
3. 원본 준비: 처음에 Mixamo에서 받은 FBX(드라이브 `안성제철_애니메이션`)를 씁니다. Unity에서 직접 고친 부분이 있었다면 그 부분은 Cascadeur에서 다시 합니다. FBX가 없으면 Mixamo에서 같은 동작을 다시 받습니다(설정: FBX, 30fps, 이동하는 동작은 In Place).
4. 보스 몸: 레포 `Assets/_Anseong/Art/Robot/Source/BossUpdatedCompatible.fbx`.

## 보스 몸을 Cascadeur에 한 번 세팅하기

Cascadeur 공식 도움말 **"Using Mixamo Rig in Cascadeur"** 순서를 따릅니다(우리 보스는 Mixamo 뼈 `mixamorig:` 그대로).

1. `File → Import FBX/DAE → Scene`으로 `BossUpdatedCompatible.fbx`를 엽니다.
2. 도움말대로 **팔꿈치를 조금 굽혀** 둡니다(Mixamo 팔이 일자라 안 굽히면 리그가 반대로 꺾임).
3. **Quick Rigging Tool**로 뼈를 이어 주고(도움말의 Cascadeur ↔ Mixamo 뼈 표) `Generate rig`.
4. `Boss_Rig.casc`로 저장 → 드라이브에 올려 둡니다. 다음부터는 이 파일을 열고 동작만 불러옵니다.

막히면 화면 캡처와 함께 팀 단톡방이나 Claude에게 "Cascadeur에서 Mixamo 리그 Generate rig가 이렇게 나와" 하고 물어보세요.

## 클립 하나 다듬는 순서

1. `Boss_Rig.casc` 열기 → `File → Import FBX/DAE → Animation`으로 클립 FBX를 불러옵니다.
2. 아래 "묵직하게 만드는 법"대로 고칩니다. **AutoPhysics**를 켜서 무게중심이 자연스러워지는지 비교해 봅니다.
3. 내보내기: FBX, **30fps**, 원래 이름 그대로(예: `Punch.fbx`). 뼈 이름·개수·길이를 바꾸지 않습니다. 걷기·돌진은 제자리(In Place, 이동은 코드가 함).
4. 레포 `유진`(Eugene) 브랜치의 `Assets/_Anseong/Art/Boss/Animation/Source/`에 넣고(원래 `.anim`은 그대로 둠), 같은 폴더 `SOURCES.md`에 한 줄: `Punch.fbx / Cascadeur(플랜) / 날짜 / 유진 / 무엇을 고쳤는지`.
5. 팀 단톡방에 `[올림] Cascadeur Punch.fbx` → 선우가 Import Boss Clips 메뉴로 넣고 헤드셋으로 봅니다.

> FBX를 읽는 메뉴는 코드 쪽에서 11/19 전에 만듭니다(07의 M4-08 ①). 그 전에 올린 것도 버리지 않고 메뉴가 생기면 넣습니다.

## 묵직하게 만드는 법

| 고칠 것 | 어떻게 |
|---|---|
| 예비 동작 | 치기 전 뒤로 당기는 동작을 **길게**(3~6프레임 더). 거대한 기계는 출발이 느림 |
| 명중 | 치는 순간은 **빠르게**, 끝에서 아주 잠깐 멈춤 |
| 복귀 | 원래 자세로 **천천히** 돌아옴(사람처럼 바로 튀어 돌아오지 않게) |
| 무게 이동 | 칠 때 골반·몸통이 같이 앞으로 실림, 발은 땅에 붙어 있음 |
| 발 | 미끄러짐·땅에 빠짐 없애기(M2-06에서 발 한쪽이 빠져 보였음) |
| 생물 느낌 금지 | 숨쉬기·어깨 들썩임 대신 기계처럼 딱딱한 미세 흔들림. 보스는 기계(대본 확정 사항) |

명중 순간(주먹이 가장 빠른 때)이 앞뒤로 움직여도 괜찮습니다. 메뉴가 그 순간을 재서 예고 시간에 맞춥니다. 다만 몇 번째 프레임인지 `SOURCES.md`에 적어 주세요.

## 순서와 마감

| 마감 | 원본 이름 | 게임에서 쓰는 곳 | 다듬을 것 |
|---|---|---|---|
| **11/14 첫 시험** | `Punch` | 좌·우 펀치(왼손은 코드가 거울로 만듦), 주먹 포탄 | 위 표 전부. 왕복(불러오기 → 내보내기 → Unity)이 되는지가 목적 |

| 11/18 | `Stagger` | 휘청, 크레인 코일·컨베이어에 박힘 | 무거운 기계가 흔들리다 버팀, 발 고정 |
