# 최종 보스 애니메이션 테스트 (2026-11-04)

## 실행

Unity 6000.3.26f1에서 `Assets/_Anseong/Scenes/Sandbox/Sandbox_Yujin_BossAnimations.unity`를 열고 Play한다.

- 왼쪽 목록에서 동작을 하나씩 선택한다. 자동으로 공격들을 연결하지 않는다.
- Pause / Resume, Restart, Pose 슬라이더(이동하면 일시정지), Speed(0.1~2배), Loop motion으로 관찰한다.
- Full / Eye level / Hand로 시점을 바꾼다. 마우스 오른쪽 드래그로 회전하고 Zoom + / -로 거리를 조절한다.
- 단발 동작은 끝 포즈에서 멈춘다. 대기와 걷기는 기본 반복이며 다른 동작도 Loop motion으로 반복할 수 있다.
- 다시 만들기: `Anseong → Sandbox → Build Final Boss Animation Test` 메뉴. 현재 테스트 씬의 수동 변경은 재생성하면 초기화되므로 먼저 별도 저장한다.

## 연결한 결과물

- 최종 V13 HQ51 검정·빨강 표면과 BaseColor, Normal, Metallic/Smoothness, Emission 네 맵.
- 수정한 손 리깅과 최종 아틀라스에 맞춘 손 UV. 몸의 원래 뼈대/동작은 유지한다.
- 이전 검 방향·손잡이·왼손 받침·칼날 회전 보정. 검 뽑기/넣기의 장착 전환 포함.
- 모델 프리팹: `Assets/_Anseong/Art/Boss/AnimationSandbox/BossV13FinalAnimation.prefab`.
- 조작 UI: `Runtime/Boss/BossAnimationSandbox.cs`(Editor/Development Build 전용).
- 생성 메뉴: `Editor/BossAnimationSandboxMenu.cs`.
- 검사: `Tests/EditMode/BossAnimationSandboxTests.cs`.

## 확인 범위

6000.3.26f1의 실제 Play 모드에서 22개 선택, 각 15/50/85% 구간, 손 뼈대, 네 텍스처 연결, UI 버튼 수, 일시정지/재개를 검사했다. 대기·펀치·검 대기·검 뽑기/넣기·횡베기·잡기와 손 확대 화면을 캡처해 확인했다.

이 씬은 애니메이션·모델 검토용이다. 이전 전투 AI, 타격 판정, 미사일/레이저 등의 공격 효과, 네트워크, VR 입력은 이관하지 않았다. 동작 선택 시에는 해당 클립을 처음부터 독립 재생하므로 서로 다른 동작 사이의 게임용 전환을 검증하는 씬도 아니다. 헤드셋 검증은 수행하지 않았다.

캡처와 검사 결과는 Git 제외 경로 `docs/test_vid/BossAnimationSandbox/`에 둔다. 파일은 모두 50MB 미만이며 압축한 미리보기 클립 22개는 합계 약 20MB다. 텍스처 8K 설정은 아트 확인용이므로 실제 게임 프리팹 통합 때 성능 예산에 맞춰 조정한다.

기존 Main, Robot_Boss, 공용 로봇 FBX와 이전 손 리깅 비교 씬은 수정하지 않는다. 커밋/푸시하지 않았다.
