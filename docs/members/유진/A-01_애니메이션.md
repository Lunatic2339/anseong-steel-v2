# 유진 — A-01 애니메이션 클립

[← 유진 처음으로](../README.md)

우리 로봇(보스와 플레이어 모두)은 Mixamo 뼈대라서 **Mixamo 동작을 그대로 쓸 수 있습니다.** 모델링·리깅 지식은 필요 없고, 고르는 눈이 가장 중요합니다.

## 고르는 기준

- **묵직하고 크게**: 65m 로봇입니다. 가볍게 튀는 동작보다 몸 전체로 힘을 싣는 동작.
- **예고가 보이게**: 보스 공격은 플레이어가 보고 막아야 합니다. 팔을 뒤로 빼는 준비 동작이 또렷한 것(준비가 1초 안팎이면 좋음).
- **제자리에서**: 발이 크게 미끄러지거나 방향이 크게 바뀌는 것은 피하기.
- 후보가 여러 개면 2~3개 받아 두고 팀과 같이 고릅니다. 파일 이름 끝에 `_a`, `_b`를 붙이면 됩니다.

## 받는 법 (클립 하나)

1. mixamo.com에 Adobe 계정으로 로그인(무료).
2. 위쪽 **Animations** 탭 → 검색창에 아래 표의 검색어.
3. 목록을 눌러 오른쪽 미리보기로 확인. 캐릭터는 기본 그대로 둡니다(우리 로봇을 올릴 필요 없음).
4. 오른쪽 슬라이더: **Overdrive**(속도)는 보통 그대로나 조금 느리게, **Character Arm-Space**(팔 간격)는 팔이 몸을 뚫으면 조금 넓게. 이동하는 동작이면 **In Place** 체크.
5. **Download** → 아래 설정으로.

| 항목 | 값 |
|---|---|
| Format | FBX for Unity(.fbx) |
| Skin | **Without Skin** (뼈 움직임만. 파일이 작아짐) |
| Frames per Second | 30 |
| Keyframe Reduction | none |

6. 파일 이름을 표의 이름으로 바꿉니다. 보스용은 `Boss_`, 플레이어 몸용은 `Pilot_`로 시작.
7. 아래 진행표에 원래 Mixamo 이름과 바꾼 값(속도 등)을 적습니다. 나중에 다시 받을 때 필요합니다.

## 진행표

| 우선 | 파일 이름 | 동작 | 어디에 쓰나 | 검색어 | Mixamo 원래 이름 · 바꾼 값 | 받음 |
|---|---|---|---|---|---|---|
| 1 | `Boss_PunchLeft` | 왼손 펀치 | 보스 일반 공격 | punch, jab, hook |  |  |
| 1 | `Boss_Knockback` | 크게 밀려남 | 부스트 펀치에 맞았을 때 | hit reaction, knocked back, big hit |  |  |
| 2 | `Boss_SlamBoth` | 두 손 내려찍기 | 2페이즈 강공격 | ground slam, smash, hammer |  |  |
| 2 | `Boss_Charge` | 돌진 | 3페이즈 가드 불가 | charge, tackle, shoulder, run |  |  |
| 2 | `Boss_Kneel` | 무릎 꿇기 | HP 10%, 필살기 기다릴 때 | kneel, defeated, exhausted |  |  |
| 2 | `Boss_WalkBack` | 뒤로 걷기 | 거리 조절 | walking backward |  |  |
| 2 | `Pilot_StrafeLeft` | 옆걸음 왼쪽 | 협동 회피 | strafe, side step |  |  |
| 2 | `Pilot_StrafeRight` | 옆걸음 오른쪽 | 협동 회피 | strafe, side step |  |  |
| 3 | `Boss_Roar` | 포효·도발 | 등장, 페이즈 전환 | taunt, roar, battlecry |  |  |

- 왼손 버전이 없으면 오른손 버전만 받고 표에 "왼손 없음"이라고 적습니다. 좌우 뒤집기는 코드 담당이 처리합니다.
- 옆걸음은 활발한 것보다 **무겁게 한 발씩 옆으로 옮기는 것**이 좋습니다. 로봇이 한쪽으로 크게 피하는 동작입니다.
- 돌진은 어깨를 앞세우고 달려드는 느낌. 달리기 동작이면 In Place 체크.
