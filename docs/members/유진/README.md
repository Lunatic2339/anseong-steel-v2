### 시작하기 전에 팀 회의에서 정할 것

1. **Unity를 쓸지**: 이미 있는 보스 클립(`Stagger`, `AlternatingCombo`, `Death`, `GroundCast`)은 기존 레포 Unity 프로젝트 안에 있습니다. 유진님이 직접 열어 볼지, 아니면 새 레포에 넣어 두고 영상으로 볼지.
2. **클립을 넘기는 방법**: GitHub으로 직접 올릴지, 드라이브에 올릴지.
3. **발표 자료 도구**: Claude가 만드는 슬라이드 링크에서 바로 고칠지, 파워포인트로 받아 고칠지.
4. **발표자**: 누가 발표할지, 나눠서 할지.
