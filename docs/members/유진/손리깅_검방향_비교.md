# 손 리깅·검 방향 비교 (2026-11-04)

이번 작업은 유진 요청에 따른 아트 검토용이다. 기존 프로젝트에서 잘 맞았던 검 방향을 기준으로 새 손 리깅의 검 대기·횡베기·내려찍기 모습을 맞췄다. 실제 전투 프리팹 교체 작업은 아니다.

## 기준과 변경

- 기준: 이전 저장소의 `AnseongSteel/Assets/_BossSteelV13/BossSteelV13.prefab`, `BossSwordAttachment`, `BossHandPose`, 공격별 `bladeRoll` 설정.
- 검 메시·손잡이 장착점·손목 대기 보정·왼손 받침·공격 중 칼날 회전을 기준에서 재현했다.
- 몸 전체를 Humanoid로 다시 변환하지 않았다. 기준의 몸 동작을 유지하고 새 손가락에는 이전 손가락 회전을 새 관절 축에 맞춰 적용했다.
- 두 프리팹의 비교 클립은 같은 시점에 샘플한 아트 미리보기다. 새로운 전투 AI나 네트워크 동작이 아니다. 검 뽑기/넣기 및 다른 공격은 이번 비교에 포함하지 않았다.
- 모양 확인용 중립 금속 재질을 사용한다. 기존 V13 텍스처를 교체한다는 뜻은 아니다.

## 위치와 실행

- 아트: `Assets/_Anseong/Art/Boss/HandRigComparison/`
- 에디터 메뉴: `Assets/_Anseong/Editor/BossHandRigComparisonMenu.cs`
- **Unity 6000.3.26f1**에서 `Anseong → Sandbox → Build Yujin Hand Rig Comparison` 실행.
- `Assets/_Anseong/Scenes/Sandbox/Sandbox_Yujin_HandRigComparison.unity` 생성·저장 완료. 이 씬을 바로 열고 Play하면 된다. 메뉴로 다시 생성할 수도 있다.
- 왼쪽은 이전 기준, 오른쪽은 새 손 리깅. Play하면 검 대기 → 횡베기 → 내려찍기가 반복된다.
- `Anseong → Sandbox → Hand Rig Comparison Controls`에서 동작과 시점을 골라 확인할 수도 있다.
- `Main.unity`, `Robot_Boss.prefab`, 공용 원본 FBX, ProjectSettings, Packages는 수정하지 않았다.

## 검증 범위와 남은 확인

- 작업용 Unity 6000.3.24f1에서 이전 기준과 새 리깅의 검 위치·회전을 126개 시점에서 비교했다. 회전 차이 0도, 위치 최대 차이 약 0.0000041m(비교 모델 크기 기준).
- 저장된 비교 프리팹/클립을 다시 불러와 147개 시점에서 재생 검사했다. 검 회전 차이 0도, 위치 최대 차이 약 0.0000131m였다. 실행 로그·렌더·영상은 Git에 넣지 않는다.
- 6000.3.26f1 설치 후 새 팀 프로젝트에서 Sandbox 생성·저장 및 실제 Play 모드 검사 완료. 세 동작의 자동 순환, 동기화, 검 방향 일치, URP Lit 재질 지원을 확인했다. 테스트 1개 통과. 캡처와 결과는 Git 제외 폴더 `docs/test_vid/BossHandRigComparison/`에 있다.
- 사람 확인: 검 대기 각도, 횡베기의 칼날 방향, 내려찍기의 칼끝, 양손 손잡이 접촉. VR/실제 전투 연결은 미검증.
- 공용 뼈대 고정 규칙 때문에 새 손 리깅은 비교용 아트로 격리했다. 실제 게임에 넣는 단계에서는 코드 담당이 손 보정·검 장착과 함께 연결해야 한다.
- 커밋/푸시는 수행하지 않았다. 현재 사용 중인 브랜치를 바꾸지 않았다.

`Assets/_Anseong/Tests/EditMode/BossHandRigComparisonTests.cs`는 실제 Play 모드에 진입해 세 동작과 검 정렬, URP 재질을 검사한다. VR 기기 검사는 포함하지 않는다.
