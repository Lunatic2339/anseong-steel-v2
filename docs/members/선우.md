### 새 세션을 시작할 때

1. `git pull` → 지시서(`docs/tasks/<번호>.md`)를 읽고 계획부터 받기.
2. 계획을 총괄 채팅에 붙여 검토 → 승인 후 작업.
3. PR 링크를 총괄 채팅에 보내면 리뷰, 병합은 직접.
4. VR 동작은 헤드셋으로 확인한 것만 완료로.
