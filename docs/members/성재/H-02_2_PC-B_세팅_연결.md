# 성재 — H-02 ②·③·④ PC-B 세팅, 두 PC 연결, 멀티플레이 검증

[← 성재 처음으로](../README.md)

PC-B를 PC-A(선우 PC)와 **완전히 같은 상태**로 만드는 것이 목표입니다. 프로젝트 설정이나 패키지는 **절대 바꾸지 마세요**. 문제가 생기면 고치려 하지 말고 화면을 찍어 팀 단톡방에 올리면 됩니다.

## ②-1 사양 기록 (5분)

1. `Ctrl + Shift + Esc` → 작업 관리자 → **성능** 탭.
2. CPU 이름, 메모리(GB), GPU 이름을 캡처해 팀 단톡방에 올리기.
3. **팀 회의에서 정할 것**: 이 사양으로 VR이 돌아가는지. GPU가 약하면 다른 PC를 PC-B로 써야 할 수 있습니다.

## ②-2 Unity 설치 (30분~1시간)

1. Unity Hub를 설치하고 Unity 계정으로 로그인.
2. 브라우저에서 Unity 다운로드 아카이브("Unity download archive"로 검색) → **6000.3.26f1**을 찾아 옆의 Unity Hub 버튼 클릭 → Hub에서 설치가 시작됨.
3. 모듈 선택 화면에서는 **아무것도 추가하지 않아도 됩니다**(Windows용 실행은 기본 포함). 버전 번호가 한 글자라도 다르면 안 됩니다.

## ②-3 Quest Link 앱 (15분)

1. Meta 공식 사이트에서 **Meta Quest Link** PC 앱 설치, 헤드셋과 같은 Meta 계정으로 로그인.
2. 앱 → **설정 → 일반** → OpenXR 런타임 항목에서 **Meta Quest Link를 활성화로 설정**.
3. 헤드셋을 케이블로 연결(케이블이 아직 없으면 Air Link) → 헤드셋 빠른 설정에서 **Link** 켜기 → 헤드셋에 어두운 Link 화면이 뜨면 성공.

## ②-4 레포 받기 (20분 + Unity 첫 열기 10~30분)

1. GitHub 초대 메일을 **수락**.
2. **GitHub Desktop** 설치 → 로그인 → File → Clone repository → URL 탭에 `https://github.com/Lunatic2339/anseong-steel-v2.git` → 저장 위치는 경로에 한글이 없는 곳(예: `C:\Projects\`).
3. Unity Hub → Projects → **Add → Add project from disk** → 받은 폴더 선택 → 열기. 처음은 오래 걸립니다.
4. 열리면 아래 Project 창에서 `Assets/_Anseong/Scenes/Main` 더블클릭.

## ②-5 헤드셋 확인 (10분)

1. Link가 켜진 상태에서 Unity 위쪽 ▶(Play) 클릭.
2. 헤드셋을 쓰고 확인:
   - [ ] 고개를 돌리면 시야가 따라온다
   - [ ] 양손의 초록 큐브가 컨트롤러 손잡이를 따라온다
   - [ ] 화면이 끊기거나 떨리지 않는다
3. Unity 아래 Console 창에 빨간 오류가 있으면 캡처.

## ③ 두 PC 랜 연결 (30분, 선우와 같이)

1. 두 PC를 랜선으로 허브(또는 공유기)에 꼽기.
2. 각 PC에서 네트워크 프로필을 **개인(Private)으로**: 설정 → 네트워크 및 인터넷 → 이더넷 → 네트워크 프로필 유형 → 개인.
3. 허브만 쓰면 IP를 직접 지정(공유기를 쓰면 이 단계는 건너뜀): 이더넷 → IP 할당 편집 → 수동 → IPv4 켜기 → PC-A `192.168.10.1`, PC-B `192.168.10.2`, 서브넷 `255.255.255.0`, 나머지 빈칸.
4. 명령 프롬프트에서 `ipconfig`로 각자 IP 확인 → PC-B에서 `ping 192.168.10.1`, PC-A에서 `ping 192.168.10.2`.
5. ping이 안 되면 Windows 방화벽이 막고 있는 것입니다: Windows 보안 → 방화벽 및 네트워크 보호 → 고급 설정 → 인바운드 규칙 → "파일 및 프린터 공유(에코 요청 - ICMPv4-In)"을 사용으로.
6. Unity를 처음 Play할 때 방화벽 창이 뜨면 **개인·공용 모두 허용**.

## 보고 양식 (팀 단톡방에 그대로 복사해서)

```
구매 후보: 품목 / 제품명 / 링크 / 가격 / 배송일
```

## ④ 멀티플레이 검증 (선우와 같이, 같은 기숙사에서)

2인 네트워크 코드가 준비되면 성재님과 선우가 기숙사에서 PC-A·PC-B를 나란히 놓고 각자 헤드셋을 쓰고 시험합니다. 성재님은 **오른쪽 조종사(PC-B)** 자리를 맡습니다. 코드는 선우가 준비하고, 성재님은 플레이하면서 느낀 점을 말해 주면 됩니다. 날짜·횟수는 팀 회의에서 정합니다.

매번 확인할 것:

- [ ] PC-B가 PC-A에 접속됨(세 번 연속)
- [ ] 내 팔은 손을 바로 따라옴, 상대 팔은 끊김 없이 부드럽게 움직임
- [ ] 두 사람이 스틱을 같은 방향으로 밀 때만 로봇이 이동
- [ ] 잽–잽–훅 연계에서 차례가 맞게 넘어감
- [ ] 보스 동작·HP가 두 화면에서 같음
- [ ] 랜선을 뽑았다 다시 꼽아도 게임이 멈추지 않음

끝나면 "어색했던 순간"을 한 줄씩 적어 둡니다(예: "훅 때 상대 팔이 잠깐 멈춤"). 화면 녹화가 있으면 더 좋습니다.
