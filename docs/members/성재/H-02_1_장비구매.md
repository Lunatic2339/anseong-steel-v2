# 성재 — H-02 ① 장비 구매 목록

[← 성재 처음으로](../README.md)

시연은 유선 Link가 기본이고, 무선(Air Link)은 예비입니다. **사기 전에 후보 링크와 가격을 팀 회의에서 함께 정하세요.**

| 품목 | 수량 | 고를 때 볼 것 | 피할 것 |
|---|---|---|---|
| Link 케이블 | 3 (PC-A·PC-B·예비) | 길이 약 5m. **USB 3.x(데이터 전송 5Gbps 이상)** 표기. "VR Link 호환", "Quest Link"라고 적힌 제품. 헤드셋 쪽은 USB-C, PC 쪽은 PC의 남는 포트에 맞게(C 또는 A). 헤드셋 쪽이 ㄱ자(L자)면 더 좋음 | USB 2.0 충전 전용 케이블(데이터가 느려 Link 화질이 나쁨). 길이만 길고 사양 표기가 없는 것 |
| 랜선 | 2~3 | Cat6, 2~5m | – |
| 스위칭 허브 | 1 | 기가비트(1000Mbps) 5포트. 두 PC를 여기에 꼽음 | – |
| Wi-Fi 6 공유기 | 1 | Air Link 예비용. 학교에 있으면 빌리기. 샀다면 5GHz 지원 + 랜 포트 있는 것(허브 대신 써도 됨) | – |
| 멀티탭 | 2 | 개별 스위치, 3m 이상 | – |
| 케이블 정리 | 약간 | 벨크로 케이블타이. 헤드셋 선과 외골격 선을 한 줄로 묶는 용도 | – |

보고할 때는 항목마다 **제품명 / 링크 / 가격 / 배송일**을 적어 주세요. 케이블은 배송이 늦으면 중간발표 전 시험을 못 하므로 배송일이 중요합니다.

**팀 회의에서 정할 것**: 예산 한도, 누구 이름으로 결제하는지, 학교에서 빌릴 수 있는 장비(공유기·허브)가 있는지.
