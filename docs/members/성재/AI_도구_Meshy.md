## 무엇을, 왜

게임에는 지금 무기·드론·보스 무기가 **상자·원통·구**로 들어가 있습니다. 성재님이 Meshy로 모델을 만들고 Blender로 원점·방향만 정리해 넘기면, 코드 담당이 프리팹 칸에 넣는 것만으로 바뀝니다. 크기는 코드가 로봇 팔 길이에 맞춰 키우므로 **비율과 원점·방향만** 맞으면 됩니다.

Meshy 주 담당은 성재님이고, Meshy에 넣을 **컨셉 이미지도 Higgsfield로 성재님이 만듭니다**(선우 11/11). 윤주님이 맵 소품을 부탁하면(단톡방) 같이 만들어 줍니다. Higgsfield 계정은 11/19부터 유진님이 영상에 쓰니 **이미지는 11/18까지** 끝냅니다. 플랜: Meshy Premium, Higgsfield Plus(둘 다 상업 사용 됨). 텍스처 그림(A-03 디테일 맵)을 고칠 땐 ChatGPT도 쓸 수 있습니다(고건님과 같이 쓰는 계정).

## 0. 컨셉 이미지 (Higgsfield, 11/14 4장 → 11/18 7개 확정)

Meshy의 Image to 3D에 넣을 그림입니다. **3D로 만들기 좋은 그림**이어야 합니다.

- 물체 **하나만**, 흰색·밝은 회색 배경, 정면에서 약간 비스듬히, 그림자 약하게, 글자·로고 없음. 같은 물체를 2~3장 만들어 고릅니다.
- 다운로드할 때 **워터마크가 없는지** 확인(있으면 단톡방에). 사람 얼굴 사진은 넣지 않습니다.
- 고른 그림은 단톡방에 `[컨셉] 팔뚝 포`처럼 올려 팀이 한 번 보고, 드라이브 `안성제철_모델/컨셉`에 저장 + `SOURCES`에 프롬프트.

| 물체 | 설명(대본 기준) | 쪽 |
|---|---|---|
| 방패 | 왼 팔뚝을 덮는 큰 직사각 판, 두꺼운 테두리 | 우리 |
| 스캐너 | 왼손 위 레이저 장치, 렌즈 하나 | 우리 |
| 검 | 오른손 큰 칼, 공장 절단기처럼 투박하게 | 우리 |
| 포 | 오른 팔뚝에 붙는 포신 하나 | 우리 |
| 드론 | 숨어서 쏘는 작은 비행 포대, 어두운 색, 붉은 렌즈 하나 | 보스 편 |
| 핵 | 보스 가슴에서 빛나는 붉은 구(맨손 장면의 목표) | 보스 |
| 주먹 포탄 | 보스 주먹에서 날아오는 탄 | 보스 |

예시 프롬프트: `heavy alien-built war machine part, angular black armor, red accents, yellow-orange emissive glow, worn dark metal, hard surface, no text, no logo, single object, arm-mounted heavy cannon, plain light grey background, three-quarter view`

## 하나 만드는 순서

1. **만들기**: meshy.ai → 0번 컨셉 이미지를 **Image to 3D**에 넣습니다(급하면 Text to 3D). 프롬프트 앞에 [스타일 한 줄](../../design/13_ai_tools.md#3-모두-지킬-것)을 붙이고 물체 설명을 영어로 씁니다. 실제 게임·애니 이름은 쓰지 않습니다.
2. **고르기**: 후보 중 실루엣이 가장 또렷한 것. 65m 로봇이 들고 40m 앞에서 보이니 **가까이 디테일보다 큰 모양**이 중요합니다.
3. **면 줄이기**: 보기 화면 위 **Remesh** → **Target Polycount**를 위 표 숫자로.
4. **텍스처**: **Texture**(이미 있으면 Retexture) → **Generate PBR Maps** 켜기. 색이 틀리면 프롬프트로 다시.
5. **받기**: **Download** → Format **FBX**.
6. **Blender 정리**(A-02에서 하던 대로):
   - 원점을 위 표 자리로(3D 커서를 그 자리에 → Set Origin → Origin to 3D Cursor).
   - 방향: Unity로 가져갔을 때 위 표 방향이 되게 돌린 뒤 Apply → Rotation & Scale.
   - 재질 1~2개, 텍스처 2048 이하.
   - 내보내기는 **A-02 때 PC-A와 맞춘 FBX 설정 그대로**(단위 m).
7. **Unity에서 확인**(PC-B): 빈 씬에 끌어다 놓고 ① 원점이 위 표 자리에 있는지(Move 도구 화살표 위치) ② 초록 화살표(+Y)·파랑 화살표(+Z)가 표 방향인지 ③ 삼각형 수·재질 수(메시 Inspector).
8. **넘기기**: `sungjae` 브랜치 `Assets/_Anseong/Art/Weapons/<파일 이름>/`(보스 부품은 `Assets/_Anseong/Art/Boss/Weapons/<이름>/`)에 FBX + 텍스처 png. 같은 폴더 위 `SOURCES.md`에 `파일 / Meshy(플랜) / 날짜 / 성재 / 프롬프트`. `.blend`는 드라이브에만. 단톡방 `[올림] Weapon_Sword`.

코드 담당이 `PlayerWeaponVisuals`(우리 무기 4칸), `DroneDirector`(드론 칸), `BossWeaponVisuals`(보스 핵·포탄 칸, 보스 포·검·방패는 우리 모델에 보스 색)에 넣고 헤드셋으로 봅니다. 철판 칸은 11/19 전에 코드로 만듭니다.

## 잘 안 될 때
- 얇은 부분(칼날)이 뭉개짐 → 프롬프트에 `thick, chunky, simple shapes` 추가, Polycount를 조금 올림.
- 텍스처가 지저분함 → Retexture로 `clean painted metal, large color blocks`.
- 크레딧 아끼기: 첫 시험(검 하나)으로 순서를 익힌 뒤 나머지를 몰아서.

## 하지 말 것
- 로봇 몸(`BossUpdatedCompatible.fbx`)을 Meshy로 새로 만들기: 뼈가 바뀌어 동작이 다 깨집니다. 로봇 몸은 A-02 정리본을 씁니다. 활용 계획서의 "로봇 모델링"은 로봇에 **붙이는 부품**(무기·장갑 조각)으로 합니다.
- 무료 플랜으로 만든 모델 쓰기(쓰면 "Meshy" 출처 표기 필요).
