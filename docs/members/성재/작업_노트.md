# 성재 — 작업 노트

[← 성재 처음으로](README.md) · 쓰는 법: [작업 노트 규칙](../README.md#작업-노트-질문변경을-claude에게-묻기)

내가 한 작업을 설명하고, 질문하거나 "내 판단으로 이렇게 바꿨다"를 남기는 곳입니다. **새 글은 맨 위**에 씁니다. 파일과 같이 커밋하고 팀 단톡방에 알리면, Claude가 읽고 답을 씁니다(코드 담당(선우)이 확인한 뒤에 올라옵니다).

## 쓰는 양식 (복사해서 맨 위 "노트" 아래에 붙이기)

```
### MM/DD · [질문] 또는 [변경] 또는 [설명] · 한 줄 제목

- 관련: (지시서 번호나 파일. 예: A-01, Assets/_Anseong/Art/Robot/Animation/Source/Mixamo/Boss_PunchLeft.fbx)
- 내용: (무엇을 했나 / 무엇이 궁금한가)
- 왜: ([변경]이면 왜 지시서와 다르게 했는지)
- 상태: 답변 대기

> Claude 답변: (Claude가 씀)
```

- **[질문]**: 모르는 것, 고르기 어려운 것. 예: "Overdrive 80과 100 중 뭐가 나아요?"
- **[변경]**: 지시서와 다르게 했거나 내 판단으로 바꾼 것. Claude가 괜찮은지 보고 답합니다. 예: "Smooth by Angle을 30° 대신 40°로 했어요. 30°는 어깨가 각져 보여서요."
- **[설명]**: 답이 필요 없는 작업 기록. 나중에 다른 사람이 볼 때 도움이 됩니다.
