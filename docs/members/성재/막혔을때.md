# 성재 — 막혔을 때

[← 성재 처음으로](../README.md)

| 증상 | 해결 |
|---|---|
| Unity Hub에 6000.3.26f1이 안 보임 | 다운로드 아카이브 페이지에서 버전 옆 Unity Hub 버튼으로 설치 |
| 프로젝트를 여는데 "버전이 다르다"는 창 | **업그레이드하지 말고** 취소. 버전을 다시 확인 |
| GitHub Desktop에서 레포가 안 보임 | 초대 메일 수락을 안 했거나 다른 계정으로 로그인한 것. 레포 관리자와 아이디 다시 확인 |
| Play를 눌러도 헤드셋에 안 나옴 | Link가 켜져 있는지, Quest Link 앱의 OpenXR 런타임 설정, 케이블이 USB 3 포트에 꼽혔는지 |
| ping이 안 됨 | 네트워크 프로필 "개인", ICMP 방화벽 규칙, IP 오타 확인 |
| Blender에서 텍스처가 분홍색 | Find Missing Files로 `Textures` 폴더 지정 |
| 합친 뒤 포즈를 움직이면 일부 부품이 안 따라옴 | 그 부품이 뼈 가중치 없이 부모로만 붙어 있던 것. 합치기 전 파일로 돌아가 팀 단톡방에 캡처 |
| 내보낸 FBX의 뼈 수가 다르다는 답을 받음 | Add Leaf Bones가 켜져 있었는지 확인 |
| 굽기가 까맣게 나옴 | 모든 재질에 대상 이미지 노드가 선택돼 있어야 함. 팀 단톡방에 스크립트 요청 |
