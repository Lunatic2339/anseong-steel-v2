## A-03 표면 방식과 플레이어 색

- Claude가 만든 비교 화면에서 로봇 세 대를 나란히 봅니다: (가) Tripo 텍스처 그대로 / (나) 색 슬롯 6개 + 반복 디테일 + AO / (다) Tripo 아틀라스 + 반복 디테일.
- 가까이(10m)와 멀리(40m)에서 보고, 헤드셋으로도 한 번(선우·유진과) → 하나를 고릅니다.
- 플레이어 색 방향: 흰색·밝은 회색 장갑, 파란 포인트, 하늘색 발광. 보스 색은 유진님이 정합니다.
- 지금 미리 할 수 있는 것: 마음에 드는 거대 로봇 레퍼런스 이미지 5장 모으기(색 조합이 잘 보이는 것).

## 조종석 모델

- M0-04 결과를 보고 팀 회의에서 조종석 높이(로봇 머리 vs 가슴 상단)를 정하면 시작합니다.
- 만들 것: 바닥, 양옆 콘솔, 앞쪽 창틀 정도. 두 사람이 나란히 서는 조종석(좌석 간격은 실제 바닥 테이프 간격과 같게).
- 주의: 조종사 시야를 가리면 안 됩니다. 창틀은 눈높이보다 아래·바깥에.
- **팀 회의에서 정할 것**(M0-04 후): 조종석 높이, 두 좌석 간격, 내부에 넣고 싶은 장치(화면·레버 등)가 있는지.
