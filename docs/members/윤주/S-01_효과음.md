# 윤주 — S-01 효과음 모으기

[← 윤주 처음으로](../README.md)

지금 게임에는 소리가 하나도 없습니다. 거대 로봇의 무게감은 절반이 소리에서 나옵니다. 윤주님은 **소리를 골라 이름을 맞춰 드라이브에 모으는 것**까지 합니다. Unity도 편집 프로그램도 필요 없고, 앞뒤 무음 자르기·변환·게임에 넣기는 코드 담당이 합니다.

## 처음 한 번

1. 구글 드라이브에 `안성제철_소리` 폴더 → 안에 `SFX`, `BGM`, `Voice`, `후보` 폴더. 폴더를 팀원에게 공유(편집 권한).
2. 같은 폴더에 구글 문서 `SOURCES` 만들기.
3. freesound.org 가입(다운로드에 필요).

## 소리 하나 받는 법 (freesound)

1. 검색창에 아래 표의 **영어 검색어**를 하나 넣습니다.
2. 왼쪽(또는 위쪽) 필터 **License → Creative Commons 0**를 고릅니다. 이것만 고르면 출처 문제가 없습니다.
3. ▶로 들어봅니다. **고르는 기준**: 시작이 바로 나오고 또렷한가, 사람 말소리·음악·잡음이 없는가, 표의 길이와 비슷한가.
4. 마음에 들면 Download → 파일 이름을 표의 이름 + 번호로 바꾸기(예: `SFX_PunchHit_01.wav`, `_02`, `_03`). MP3여도 괜찮습니다.
5. `SOURCES`에 한 줄: `파일 이름 / freesound / 원래 제목 / 만든 사람 / CC0 / 주소`.
6. 고르기 어려우면 2~3개를 `후보` 폴더에 넣어 두고 나중에 팀과 같이 들어보고 고릅니다.

**사람 크기 소리여도 됩니다.** 게임에서 낮게 끌어내리면 거대하게 들립니다. 드럼통을 망치로 친 소리가 훌륭한 로봇 펀치가 됩니다. 다른 무료 출처: Sonniss GDC 무료 번들, Kenney 오디오(CC0).

## 2차 목록 (11/19까지)

나머지 약 27종입니다. 파일 이름·예시·검색어는 「안성제철 작업 지시서 모음」의 S-01 표에 다 있습니다. 크게 나누면:

- **공격 연출**: 그립 놓음, 연계 단계 신호, 부스트(준비·분사·명중), 가드로 버팀, 맞음, HP 경보
- **이동**: 이동 승인 "삑삑", 다리 유압, 회피(분사·끌림), 몸 회전
- **보스**: 예고음 3가지(일반·강공격·가드 불가, 서로 확실히 다르게), 휘두름, 내려찍기, 돌진, 밀려남, 포효, 쓰러짐
- **필살기·흐름**: 충전, 광선, 구조물 붕괴, 정비고 문, 사이렌, UI 확인음, 결과 음악
- **사령관 대사 10줄**(`VO_Commander_01~10`): 팀원이 조용한 곳에서 휴대폰으로 녹음. 무전기 효과는 나중에 넣습니다. 누가 녹음할지와 대사 문구는 **팀 회의에서 정할 것**.

## 하지 말 것

- 유튜브에서 뜯은 소리, 게임·영화에서 뽑은 소리, 라이선스를 모르는 소리.
- AI 음성(TTS)을 쓸 때는 전시에 써도 되는지 먼저 확인하고 `SOURCES`에 적기.

## 끝낼 때

폴더 링크를 팀 단톡방에 올리면 끝입니다. 코드 담당이 레포에 넣고, 게임에서 들어보며 하나씩 바꿀 수 있습니다. 넣은 뒤 "이 소리는 더 묵직한 걸로" 같은 요청이 있을 수 있어요.
