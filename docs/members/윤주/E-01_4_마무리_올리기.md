## 프리팹으로 저장 (완성 전에도 가끔)

"프리팹"은 묶음을 파일 하나로 저장한 것입니다. 다른 사람이 이 파일만 가져다 쓰면 맵 전체가 들어갑니다.

1. Project 창에서 `Assets/_Anseong/Art/Environment/` 폴더를 엽니다.
2. Hierarchy의 `Env_Steelworks`를 그 폴더로 **끌어다 놓습니다.** "Original Prefab"을 고릅니다.
3. Hierarchy에서 이름이 파란색으로 바뀌면 성공. `Env_Steelworks.prefab` 파일이 생깁니다.
4. 그 뒤에 고친 것은 Inspector 위쪽 **Overrides → Apply All**을 눌러야 파일에 반영됩니다.

## 삼각형 수 확인

VR은 두 눈을 따로 그리므로 무거우면 어지럽습니다. 환경은 **삼각형 30만 개 이하**로 맞춥니다.

1. 위쪽 가운데 ▶ 버튼으로 Play.
2. Game 창 오른쪽 위 **Stats** 버튼 → **Tris** 숫자를 봅니다.
3. 비교하려면 `Env_Steelworks`를 꺼 두고(Inspector 맨 위 체크 해제) 한 번, 켜고 한 번. 두 숫자의 차이가 환경의 삼각형 수입니다.
4. ▶를 다시 눌러 Play를 끕니다. **Play 중에 고친 것은 끄면 사라집니다.**
5. 30만을 넘으면: 멀리 있는 건물을 단순한 것으로 바꾸거나 개수를 줄입니다. 어떤 게 무거운지 모르겠으면 팀 단톡방에.

## 올리기 (1차 10/27, 2차 11/18)

올리는 방법은 두 가지 중 편한 것으로.

**가. GitHub Desktop으로 직접**

1. Unity에서 Ctrl+S로 씬 저장.
2. GitHub Desktop 왼쪽에 바뀐 파일 목록이 나옵니다. 위쪽 Current branch가 `yunju`인지 확인.
3. 목록에 **내가 안 건드린 파일**(ProjectSettings, Packages, 다른 씬)이 있으면 올리지 말고 팀 단톡방에 캡처.
4. 왼쪽 아래 Summary에 한 줄(예: `E-01 1차: 바닥, 트럭, 부서질 자리, 배경`) → Commit → 위쪽 Push origin.
5. 팀 단톡방에 `[올림]` 양식으로 알리기([GitHub 작업 규칙](../../GitHub_작업_규칙.md)). PR은 만들지 않습니다.

**나. 어렵거나 불안하면**: 팀 단톡방에 "올릴 준비 됐어요"라고 하면 같이 화면을 보며 올립니다.
