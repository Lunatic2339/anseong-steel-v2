# 윤주 — E-01 ② 에셋 고르기와 출처 기록

[← 윤주 처음으로](../README.md)

"에셋"은 남이 만들어 둔 3D 모델(트럭, 건물 등)입니다. 우리는 **무료이고 전시에 써도 되는 것**만 씁니다.

## 어디서 찾나

| 사이트 | 특징 | 찾아볼 검색어 |
|---|---|---|
| Unity Asset Store (무료 필터) | Unity에 바로 들어옴. **"URP" 지원 표시**가 있는 것 | industrial, factory, warehouse, container, truck, crane |
| Poly Haven (polyhaven.com) | 모두 CC0(출처 표시 없이도 됨). 하늘 사진(HDRI)과 바닥 재질이 특히 좋음 | HDRI: overcast, industrial, sunset / 재질: concrete, asphalt |
| Kenney (kenney.nl) | CC0, 단순한 모양 | city kit, industrial |
| Quaternius (quaternius.com) | CC0, 단순한 모양 | city, buildings |

이 네 곳 밖(Sketchfab 등)에서 찾은 것은 쓰기 전에 팀 단톡방에 링크를 올려 라이선스를 같이 봅니다.

## 필요한 물건 목록

| 무엇 | 몇 개 | 대략 크기 | 찾음 |
|---|---|---|---|
| 트럭·덤프트럭 | 2~3종류 | 길이 8~12m |  |
| 컨테이너 | 1~2종류(색만 바꿔도 됨) | 12m × 2.5m × 2.6m |  |
| 지게차·작은 차 | 1~2 | 3~5m |  |
| 철골 구조물·건트리 크레인 | 2~3 | 높이 25~45m로 키움 |  |
| 사일로·급수탑(원통형) | 1~2 | 높이 30~45m |  |
| 큰 공장 건물 | 2~3 | 높이 60~120m로 키움 |  |
| 굴뚝 | 1 | 100m 이상 |  |
| 바닥 재질 | 1 | 콘크리트나 아스팔트 |  |
| 하늘 | 1 | 흐린 날이나 해 질 녘 |  |

고로(용광로)는 무료 모델이 거의 없습니다. 1차에서는 원통 + 상자를 쌓아 비슷한 모양을 만들거나(Hierarchy에서 우클릭 → 3D Object → Cylinder/Cube) 비워 둡니다. 모양이 단순해도 멀리 있으면 괜찮습니다.

## 가져오는 법

- **Asset Store**: 웹에서 "Add to My Assets" → Unity에서 Window → Package Manager → 왼쪽 위 "My Assets" → Download → Import. 가져올 파일을 고르는 창이 뜨면 **쓸 것만 체크**합니다(데모 씬·예제 폴더는 빼기).
- **다운로드한 파일**: FBX나 OBJ를 골라서 Unity Project 창의 폴더로 끌어다 놓습니다. 텍스처(사진 파일)도 같은 폴더에.
- 넣을 위치: `Assets/_Anseong/Art/Environment/Source/<사이트이름>/` (예: `Source/Kenney/`). 없는 폴더는 우클릭 → Create → Folder.
- **분홍색으로 보이면**: Window → Rendering → Render Pipeline Converter → Material Upgrade 체크 → Initialize And Convert. 그래도 분홍색이면 그 에셋은 두고 팀 단톡방에.
- 용량: 한 번에 100MB가 넘는 패키지는 가져오기 전에 팀 단톡방에 물어봅니다(레포가 무거워집니다).

## 출처 기록 (SOURCES.md)

에셋을 하나 넣을 때마다 `Assets/_Anseong/Art/Environment/SOURCES.md`에 한 줄씩 적습니다. 메모장으로 열어서 쓰면 됩니다. 없으면 새로 만듭니다.

```
| 파일/폴더 | 사이트 | 원래 이름 | 만든 사람 | 라이선스 | 주소 |
|---|---|---|---|---|---|
| Source/Kenney/truck.fbx | Kenney | Car Kit | Kenney | CC0 | (에셋 페이지 주소) |
```

출처를 모르거나 라이선스가 헷갈리면 **쓰지 않습니다.** 전시는 공개 행사라 중요합니다.
