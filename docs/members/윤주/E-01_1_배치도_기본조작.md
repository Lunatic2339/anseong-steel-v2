# 윤주 — E-01 ① 종이 배치도와 기본 조작

## 만들 맵의 모양

제철소의 **길고 곧은 마당**입니다. 우리 로봇은 가운데에 서 있고, 보스는 정면 40m 앞에 있습니다. 두 로봇 모두 65m(아파트 20층 정도)라, 조종사는 약 60m 높이에서 **아래와 앞**을 봅니다. 작은 트럭·컨테이너가 발밑에 보여야 "내가 거대하다"는 느낌이 납니다.

지킬 규칙 세 가지:

1. **로봇과 보스 사이는 비웁니다.** 양옆으로 피할 수 있게 폭 약 100m.
2. **양옆 가장자리에 로봇 팔 높이(25~45m) 구조물**을 둡니다. 나중에 팔을 휘두르다 부수는 것들입니다.
3. **더 바깥에는 눈높이보다 큰 건물(60~120m)**. 고로·굴뚝 같은 것으로 제철소라는 걸 알려 줍니다.

## 종이 배치도 그리기 (10/17~10/19, Unity 없이)

A4 한 장에 **위에서 내려다본 모습**을 그립니다. 잘 그릴 필요 없고 네모와 글자만으로 충분합니다.

1. 종이 가운데 아래쪽에 ○(우리 로봇), 그 위쪽에 ●(보스). 위쪽이 보스 방향입니다.
2. 두 동그라미를 둘러싼 큰 점선 네모 = 비워 둘 전투 공간.
3. 점선 네모 양옆에 부서질 구조물을 한쪽 3개씩 + 보스 뒤에 사일로 1개. 각각 무엇일지 적기(예: "크레인", "급수탑", "컨베이어 다리").
4. 그 바깥에 큰 배경 건물 몇 개(고로, 굴뚝, 공장).
5. 로봇 뒤쪽에 정비고(로봇이 출격하는 건물).
6. 사진을 찍어 팀 단톡방에 올립니다.

참고할 만한 것: 인터넷에서 "제철소 항공사진", "steel mill aerial"을 검색해 보면 실제 배치가 나옵니다. 마음에 드는 사진 2~3장을 배치도와 같이 올려 주세요.

## Unity 기본 조작 연습 (처음 준비 다음 날, 1시간)

`Sandbox_Yunju` 씬에서 연습합니다. 망쳐도 괜찮습니다. 저장 안 하고 닫으면 되돌아갑니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 화면 둘러보기 | Scene 창에서 **마우스 오른쪽 버튼을 누른 채** 마우스를 움직임 |
| 걸어다니기 | 오른쪽 버튼을 누른 채 **W A S D**(앞 왼쪽 뒤 오른쪽), **Q E**(아래 위). **Shift**를 같이 누르면 빨라짐 |
| 가까이·멀리 | 마우스 휠 |
| 물체로 바로 가기 | Hierarchy에서 물체 이름을 고르고 Scene 창에서 **F** |
| 옮기기 | 물체를 고르고 **W** → 빨강·초록·파랑 화살표를 끌기 |
| 돌리기 | **E** → 동그라미를 끌기 |
| 크기 | **R** → 가운데 하얀 상자를 끌면 전체가 같이 커짐 |
| 복사 | **Ctrl + D** |
| 되돌리기 | **Ctrl + Z** |
| 저장 | **Ctrl + S** (자주!) |
| 정확한 위치 넣기 | 오른쪽 Inspector의 Transform → Position에 숫자 입력 |

**연습 과제** (다 하면 배치를 시작해도 됩니다):

- [ ] 로봇 발밑으로 낮게 내려가 트럭 기준물 옆에 서 보기
- [ ] 다시 로봇 머리 높이(60m)로 올라가 아래를 내려다보기 — 이게 조종사 시점
- [ ] 트럭 기준물을 Ctrl+D로 세 개 복사해 나란히 놓기
- [ ] 하나를 돌리고, 하나를 두 배로 키우기
- [ ] Inspector에서 Position을 X 30, Y 0, Z 0으로 입력해 보기
- [ ] 연습한 트럭을 지우기(Delete 키)

좌표 읽는 법: **X = 왼쪽(-)·오른쪽(+), Y = 높이, Z = 뒤(-)·보스 쪽(+)**. 단위는 m입니다. 로봇이 X 0, Z 0에 있고 보스는 Z 40입니다.
