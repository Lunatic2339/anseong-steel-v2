# 윤주 — ElevenLabs로 사령관 대사 만들기

[← 윤주 처음으로](README.md) · 효과음·음악: [AI 도구 ① 효과음·음악](AI_도구_1_효과음_음악.md) · 전체 도구 표: [13 AI 도구](../../design/13_ai_tools.md)

게임 내내 사령관 한 명이 무전으로 지시합니다(대본 확정 사항 12). 지금은 글자로만 뜹니다. ElevenLabs의 글 → 목소리(Text to Speech)로 아래 34줄을 만들면, 이름만 맞으면 코드가 알아서 찾아 틉니다.

> 사령관 목소리를 AI로 할지 팀원 녹음으로 할지는 **팀 회의에서 정할 것**(11/12). 아래는 AI로 정했을 때의 순서입니다.

## 순서

1. 선우에게서 계정(ElevenLabs **Creator** 플랜, 상업 사용 됨)을 받아 elevenlabs.io에 로그인 → 왼쪽 **Text to Speech**.
2. **목소리 고르기**: 목소리 목록(Voice Library)에서 한국어가 자연스러운 **차분하고 단단한 중년 목소리**를 3개 골라, 1번 대사로 들어 보고 팀 단톡방에 올려 하나로 정합니다(11/14). 실제 연예인·유명인 목소리를 흉내 낸 목소리나 **남의 목소리 복제(Voice Clone)는 쓰지 않습니다**.
3. **모델**은 한국어를 지원하는 것(Multilingual 등)을 고릅니다. 설정은 처음 정한 값을 끝까지 같게 둡니다(줄마다 목소리가 달라지지 않게). 정한 목소리 이름과 설정값을 `SOURCES`에 적어 둡니다.
4. 아래 표의 대사를 **한 줄씩** 넣고 만들기 → 들어 보고 어색하면 다시(문장 끝 `!`·`.`로 말투가 바뀜). 
5. 다운로드 → 파일 이름을 표의 이름으로(**두 자리 번호**: `VO_Commander_01.wav`). 
6. 드라이브 `안성제철_소리/Voice`에 넣고 `SOURCES`에 `파일 / ElevenLabs(플랜) / 목소리 이름 / 날짜`.
7. 다 되면 팀 단톡방 `[올림] 사령관 대사 34줄`. 무전기 느낌(지직거림)은 코드 담당이 게임 안에서 입힙니다.

**대사를 고치고 싶으면**: 고친 문구를 단톡방에 올려 같이 정한 뒤 다시 만듭니다(게임 글자도 같이 바꿔야 하니 코드 담당에게 알리기). 번호는 바꾸지 않습니다.
