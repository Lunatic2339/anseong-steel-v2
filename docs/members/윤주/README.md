## 한눈에 보기

윤주님은 **코드를 전혀 쓰지 않는** 두 가지를 맡습니다. 모르는 말이 나오면 그 자리에서 멈추고 팀 단톡방에 물어보는 것이 가장 빠릅니다. 틀려도 되돌릴 수 있는 작업이니 편하게 해 보세요.

| 일 | 무엇을 | Unity 필요 |
|---|---|---|
| **E-01 제철소 맵** | 65m 로봇 두 기가 싸울 제철소 마당을 Unity 화면에서 물체를 끌어다 놓아 만들기 | 필요 |
| **S-01 효과음** | 무료 소리 사이트에서 펀치·발소리 같은 소리를 골라 이름을 맞춰 구글 드라이브에 모으기 | 필요 없음 |

S-01은 Unity 없이 바로 시작할 수 있으니, Unity 준비를 기다리는 동안 먼저 하면 좋습니다.

### 일정

| 언제 | E-01 맵 | S-01 효과음 |
|---|---|---|
| 10/17~10/19 | 종이 배치도 그리기 → 사진을 팀 단톡방에 | 드라이브 폴더 만들기, freesound 가입, 1차 소리 시작 |
| 팀 회의에서 정한 날(1~2시간) | 처음 준비: 설치, 레포 받기, Unity 열기 |  |
| 준비 다음 날 | 기본 조작 연습 1시간 |  |
| ~10/24 | 에셋 고르기, 바닥·전투 공간·부서질 자리 | 1차 소리 절반 |
| ~10/27 | 배경 건물·하늘, 프리팹 저장 | 1차 소리 다 모음, 선우와 같이 들어보기 |
| **10/28** | **1차 마감**: 선우와 헤드셋으로 한 번 보기 | **1차 마감**: 폴더 링크 전달 |
| 10/30 | 중간발표(예상 영상에 윤주님 맵이 나옴) |  |
| **11/19** | **2차**: 제철소 느낌(고로·불빛·연기), 정비고 | **2차**: 나머지 소리 + 사령관 대사 녹음 |

### 시작하기 전에 팀 회의에서 정할 것

1. **내 컴퓨터로 Unity가 돌아갈지**: [처음 준비](0_처음_준비.md)의 PC 확인표를 채워서 팀 단톡방에 올립니다. 안 되면 학교·팀 PC를 쓸지 팀 회의에서 정합니다.
2. **처음 준비 날짜와 장소**: 선우와 1~2시간, 같은 자리에서(또는 화면 공유).
3. **GitHub 계정**: 없으면 만들고 아이디를 팀 단톡방에. 레포 관리자가 팀 레포에 초대합니다.
4. **구글 드라이브**: 소리 폴더를 내 드라이브에 만들지, 팀 공유 드라이브에 만들지.
5. **헤드셋으로 보는 날**: 10/28 전에 PC-A에서 맵을 헤드셋으로 볼 시간.
