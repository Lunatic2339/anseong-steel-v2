## ① PC 확인 (혼자, 5분)

키보드에서 **Ctrl + Shift + Esc** → 작업 관리자 → 위쪽 "성능" 탭에서 보고 아래 표를 채워 팀 단톡방에 올립니다(스크린샷도 좋아요).

| 항목 | 어디서 보나 | 내 PC | 권장 |
|---|---|---|---|
| 운영체제 | 설정 → 시스템 → 정보 |  | Windows 10/11 64비트 |
| 메모리 | 성능 → 메모리(오른쪽 위 숫자) |  | 16GB 이상 |
| 그래픽 | 성능 → GPU(여러 개면 다) |  | NVIDIA·AMD 외장 그래픽 권장 |
| 남은 디스크 | 파일 탐색기 → 내 PC |  | 40GB 이상 |
| 노트북인가 |  |  | 노트북이면 작업할 때 충전기 꼽기 |

내장 그래픽만 있거나 메모리가 8GB면 느리게 돌 수 있습니다. 그래도 물체 배치는 될 수 있으니 팀 회의에서 보고 정합니다.

## ② 설치 (선우와 같이, 다운로드가 길어 미리 시작해도 됨)

1. **Unity Hub** 설치 → Unity 계정으로 로그인(무료 Personal 라이선스).
2. **Unity 6000.3.26f1** 설치. Hub에 이 번호가 안 보이면 웹의 "Unity download archive"에서 번호를 찾아 Hub 설치 버튼을 누릅니다. 추가 모듈은 아무것도 체크하지 않아도 됩니다. **번호가 정확히 같아야 합니다.**
3. **GitHub Desktop** 설치 → GitHub 계정으로 로그인. 초대 메일을 먼저 수락해야 팀 레포가 보입니다.

## ③ 레포 받기

1. GitHub Desktop → File → Clone repository → `Lunatic2339/anseong-steel-v2` 선택.
2. 받을 위치(Local path)는 **짧고 한글이 없는 경로**로: 예 `C:\Projects\anseong-steel-v2`. 바탕화면·OneDrive 폴더는 피합니다.
3. Clone 버튼. 텍스처가 많아 몇 분 걸립니다.

## ④ 처음 열기

1. Unity Hub → Projects → Add(또는 Open) → 위에서 받은 폴더 선택.
2. 처음 열 때는 **10~30분** 걸립니다. 진행 막대가 멈춘 것 같아도 기다리세요.
3. "버전이 다르다"거나 "업그레이드하겠냐"는 창이 뜨면 **누르지 말고** 팀 단톡방에.
4. "Safe Mode"로 열겠냐는 창이 뜨면 Ignore를 누르고 팀 단톡방에 알립니다.
5. 열리면 선우가 아래 ⑤를 같이 해 줍니다.

## ⑤ 내 작업 씬 만들기 (선우와 같이)

1. 위 메뉴 **Anseong → Sandbox → Build Scale Test**. 65m 로봇과 사람·트럭·건물 크기 기준물이 있는 씬이 생깁니다.
2. **File → Save As** → `Assets/_Anseong/Scenes/Sandbox/` 폴더에 `Sandbox_Yunju`라는 이름으로 저장.
3. 앞으로 **이 씬에서만** 작업합니다. Unity를 다시 열면 Project 창에서 이 파일을 더블클릭해 엽니다.
4. GitHub Desktop에서 브랜치를 `yunju`로 만들어 둡니다(선우가 해 줌). `main`에는 직접 올리지 않습니다.
