## 한눈에 보기

고건님은 **외골격(포스 피드백) 전담**입니다. Unity는 만지지 않습니다. 게임 쪽 코드와 ESP32 펌웨어 초안은 선우·Claude가 쓰고, 고건님은 장치를 만들고 보드에 올려 시험하고 측정합니다. 자세한 근거는 함께 드린 PDF「외골격 진행 평가와 설계 가이드」에 있고, 이 문서는 **무엇을 어떤 순서로 하는지**만 적습니다.

외골격은 "있으면 더 좋은 것"입니다. 고장 나도 게임은 컨트롤러 진동만으로 끝까지 돕니다. 그러니 **크고 복잡한 장치보다 작고 확실하고 안전한 장치**가 목표입니다.

### 확정된 것

- 힘 방향: **펼 때 막힘**(펀치는 팔을 펴는 동작이라 명중감이 여기서 나옴). 10/16 확정.
- 장치 구성: 조종사 한 명당 **담당 팔 하나**. 조종사 A = 왼팔, B = 오른팔(왼팔 장치의 좌우 대칭). 담당 팔 손에 Quest 컨트롤러를 쥐고, 반대 손은 비워 둡니다.
- 순서: **책상 위 시제품 먼저**, 착용형은 그 다음.
- 연결: 각 PC가 자기 ESP32를 USB 시리얼(115200bps)로 제어.

## 안전 원칙

감속비 1:51이라 모터 축에서 나오는 힘은 생각보다 큽니다. 관객이 차는 장치이므로 아래 세 겹을 **모두** 갖추기 전에는 사람이 차지 않습니다. 책상 시제품에서도 같은 규칙을 씁니다.

| 겹 | 할 것 | 확인 시험 |
|---|---|---|
| ① 소프트웨어 | 0.2초 동안 명령이 없으면 출력 0(워치독). 한 번의 저항은 최대 0.5초로 자름. 세기 상한을 펌웨어 상수로 고정. 켜질 때는 항상 0에서 시작 | T5 |
| ② 전기 | 비상 정지 스위치(버섯형)가 **모터 전원선을 직접 끊음**(ESP32를 거치지 않음). 모터 전원선에 퓨즈 | T6 |
| ③ 기계 | 약한 고리: 일정 장력 이상이면 끊어지거나 빠지는 연결부(케이블타이, 얇게 출력한 링크, 자석 커플러 등)를 끈과 팔 사이에. 손으로 1초 안에 풀 수 있는 착탈부 | T6 |

### 절대 하지 말 것

- 비상 정지·약한 고리가 T6을 통과하기 전에 사람 팔에 묶기.
- 혼자 있을 때 착용 시험. **옆에 비상 정지를 누를 사람**이 항상 있어야 합니다.
- "누가 잠깐 버틴 힘"을 합격값으로 삼기. 세기는 약하게 시작해 팀원이 손잡이를 잡고 체감하며 조금씩 올립니다.
- 끈이 팔을 관절 한계 너머로 끌어당기는 방향으로 걸리게 두기.
- 드라이버 보호 기능을 끄거나 퓨즈를 굵은 것으로 바꾸기.

**팀 회의에서 정할 것**: 약한 고리를 몇 kg에서 끊어지게 할지는 T3 세기표가 나온 뒤 함께 정합니다. 그 전에는 손으로 쉽게 끊을 수 있는 정도(얇은 케이블타이)로 둡니다.

## 1단계: 책상 시제품과 역구동 확인 (10/17 ~ 10/24)

등판·하네스·커프 없이 **팔꿈치 관절 하나만** 책상에 고정해 만듭니다. 목적은 ① 힘 방향 확인, ② 세기·지연 측정, ③ 안전장치 동작 확인. 중간발표 영상도 이걸로 찍습니다.

### ① 먼저 멈추고 정리하기 (최우선, 10/17)

1. **전체 13장 출력을 멈춥니다.** 최신 조립 검사에서 141쌍이 겹칩니다.
2. 이미 뽑은 부품의 ID 목록을 만듭니다(부품 ID, 날짜, 재료). → 팀 단톡방에 사진이나 표로.
3. 모터가 돌고 멈추던 **그 코드와 배선 사진**을 저장합니다. 나중에 문제가 생기면 여기로 돌아옵니다.

### ② 역구동 확인 (부품이 오기 전에 할 수 있음)

감속비 1:51 기어는 출력축을 손으로 돌리기(역구동) 어려울 수 있습니다. 이걸 먼저 알아야 모터 제어 방식을 고를 수 있습니다.

1. 전원을 끄고 출력축에 스풀(또는 테이프 한 조각)을 달고 손으로 돌려 봅니다.
2. 스풀에 끈을 감고 끈을 당겨서 풀려 나오는지 봅니다. 수하물 저울을 걸어 **몇 kg에서 풀리기 시작하는지** 기록합니다.
3. 결과를 팀 단톡방에 올립니다: "손으로 잘 돈다 / 뻑뻑하다(약 __kg) / 안 돈다".

| 결과 | 의미 | 다음 |
|---|---|---|
| 잘 돈다 | 끈을 팔에 묶어 둬도 팔이 덜 걸림 | "느슨 + 감기"로 시작, 느슨 길이를 짧게 잡아 지연을 줄임 |
| 뻑뻑하거나 안 돈다 | 모터가 멈춰 있으면 팔이 걸림 | "느슨 + 감기"에서 끈 여유를 팔 전체 움직임만큼 충분히 |

드라이버 사양서에서 **브레이크 입력**이 있는지도 같이 확인해 주세요. 있으면 나중에 다른 방식을 시험할 수 있습니다.

### ③ CAD 수정: 책상 시제품에 필요한 것만

| 순서 | 대상 (원본 ID) | 할 것 |
|---|---|---|
| 1 | 팔꿈치 풀리·출구 브래킷·지지 기둥 (A070↔A084, A076↔금속 기둥) | 간섭 수정 + **끈 감김 방향을 반대로**(펼 때 막힘). 상완·전완 가이드 출구 위치만 옮기는 것이 가장 작은 변경 |
| 2 | 상완 끈 통로 ↔ 소형 풀리 (A087↔A105) | 끈이 실제로 통하는지 |
| 3 | A042/A070 체결 구멍 | 팔꿈치 링크 조립 |
| 뒤로 | 등판, 하네스, 오른쪽 어깨, 전완 클램프 | 11/12 착용형 단계에서 |

CAD에서 팔꿈치를 0°(폄)에서 135°(굽힘)까지 돌려 보며 **펼 때** 끈 길이가 늘어나는지 확인합니다. 끈은 당기기만 하므로, 펼 때 끈이 길어져야 모터가 그걸 막을 수 있습니다. 끈이 팔 안쪽(이두 쪽)에 가까워지므로 피부·커프에 닿는지도 봅니다. 0°·45°·90°·135° 네 각도의 끈 길이를 적어 팀 단톡방에 올려 주세요.

## 2단계: 펌웨어와 통신 규약 (10/22 ~ 10/29)

펌웨어는 **Claude가 아래 규약대로 작성**하고, 고건님이 보드에 올려 시험합니다. 고건님이 직접 쓸 필요는 없지만, 직접 고치고 싶으면 고친 줄과 이유를 팀 단톡방에 알려 주세요.

### Claude가 펌웨어를 쓰려면 필요한 것 (고건 → 코드 담당, 10/20까지)

| 항목 | 예시로 적을 것 |
|---|---|
| ESP32 보드 이름 | ESP32 DevKit V1 / ESP32-S3 등 |
| 모터 드라이버와 연결한 핀 | PWM = GPIO __, 방향 = GPIO __, 브레이크/사용 = GPIO __, 회전 신호(FG) = GPIO __ |
| 드라이버 사양서 | 파일이나 링크. PWM 주파수 범위, 방향·브레이크 논리(High가 무엇인지) |
| 지금 돌아가는 코드 | 모터가 돌고 멈췄던 그 코드 파일 그대로 |
| 감는 방향 | 방향 핀 High일 때 스풀이 끈을 감는지 푸는지 |
| 개발 도구 | Arduino IDE / PlatformIO, ESP32 보드 패키지 버전 |

### 규약 (한 줄씩, 줄 끝 `\n`, 115200bps)

PC(Unity) → ESP32:

| 명령 | 뜻 | 언제 옴 |
|---|---|---|
| `P,<ms>` | 준비: 느슨한 끈을 약하게 감아 둠. ms 안에 R이 안 오면 다시 풀기 | 보스 공격 예고 시작(1.2~2.0초 전), 펀치가 닿기 0.1~0.2초 전 |
| `R,<0-255>,<ms>` | 저항: 세기와 시간 | 명중(약 0.12초), 가드 접촉(약 0.3초) |
| `X` | 즉시 해제 | 부스트 점화, 게임 멈춤, 연결 끊김 |
| `H` | 살아 있음 신호 | 100ms마다 |

ESP32 → PC (10Hz, 기록용): `S,<상태>,<출력>,<오류코드>` 예: `S,RESIST,180,0`

### 상태 흐름

| 상태 | 하는 일 | 다음 상태 |
|---|---|---|
| IDLE | 출력 0, 끈 느슨 | P → PRE, R → RESIST(감으면서) |
| PRE | 약하게 감아 둠 | R → RESIST, ms 초과 → RELEASE |
| RESIST | 세기대로 버팀(최대 0.5초) | 시간 끝 또는 X → RELEASE |
| RELEASE | 끈을 다시 풀어 느슨하게 | 끝나면 IDLE |
| SAFE | 출력 0 | 0.2초 명령 없음이면 어느 상태에서나 여기로. 다음 명령이 오면 IDLE |

### 고건님이 할 일

1. 받은 펌웨어를 올립니다. **처음에는 끈을 스풀에서 빼고** 모터만 돌게 해서 확인합니다.
2. 시리얼 모니터(115200, 줄 끝 = 새 줄)를 열고 아래를 순서대로 입력합니다.
   - `R,40,300` → 약하게 0.3초 돌고 멈춤
   - `R,40,2000` → 0.5초에서 잘려야 함(상한)
   - `P,1000` 후 아무것도 안 보냄 → 1초 뒤 풀림
   - `P,1000` 후 바로 `R,60,200` → 준비 없을 때보다 빨리 힘이 남
   - `R,60,400` 도중 `X` → 즉시 멈춤
   - `H`를 보내다 끊음 → 0.2초 뒤 `S,SAFE,...`
3. 다 되면 끈을 걸고 같은 순서를 반복합니다. 세기는 40부터.
4. 하나라도 이상하면 멈추고, 입력한 줄과 돌아온 `S,...` 줄을 그대로 복사해 팀 단톡방에 올립니다.

동작한 펌웨어는 레포 `Hardware/Exo/firmware/`에 배선 사진과 함께 저장해 기준본으로 삼습니다.
