# 고건 — 2단계 펌웨어와 통신 규약

[← 고건 처음으로](../README.md)

펌웨어는 **Claude가 아래 규약대로 작성**하고, 고건님이 보드에 올려 시험합니다. 고건님이 직접 쓸 필요는 없지만, 직접 고치고 싶으면 고친 줄과 이유를 팀 단톡방에 알려 주세요.

## Claude가 펌웨어를 쓰려면 필요한 것 (고건 → 코드 담당, 10/20까지)

| 항목 | 예시로 적을 것 |
|---|---|
| ESP32 보드 이름 | ESP32 DevKit V1 / ESP32-S3 등 |
| 모터 드라이버와 연결한 핀 | PWM = GPIO __, 방향 = GPIO __, 브레이크/사용 = GPIO __, 회전 신호(FG) = GPIO __ |
| 드라이버 사양서 | 파일이나 링크. PWM 주파수 범위, 방향·브레이크 논리(High가 무엇인지) |
| 지금 돌아가는 코드 | 모터가 돌고 멈췄던 그 코드 파일 그대로 |
| 감는 방향 | 방향 핀 High일 때 스풀이 끈을 감는지 푸는지 |
| 개발 도구 | Arduino IDE / PlatformIO, ESP32 보드 패키지 버전 |

## 규약 (한 줄씩, 줄 끝 `\n`, 115200bps)

PC(Unity) → ESP32:

| 명령 | 뜻 | 언제 옴 |
|---|---|---|
| `P,<ms>` | 준비: 느슨한 끈을 약하게 감아 둠. ms 안에 R이 안 오면 다시 풀기 | 보스 공격 예고 시작(1.2~2.0초 전), 펀치가 닿기 0.1~0.2초 전 |
| `R,<0-255>,<ms>` | 저항: 세기와 시간 | 명중(약 0.12초), 가드 접촉(약 0.3초) |
| `X` | 즉시 해제 | 부스트 점화, 게임 멈춤, 연결 끊김 |
| `H` | 살아 있음 신호 | 100ms마다 |

ESP32 → PC (10Hz, 기록용): `S,<상태>,<출력>,<오류코드>` 예: `S,RESIST,180,0`

## 상태 흐름

| 상태 | 하는 일 | 다음 상태 |
|---|---|---|
| IDLE | 출력 0, 끈 느슨 | P → PRE, R → RESIST(감으면서) |
| PRE | 약하게 감아 둠 | R → RESIST, ms 초과 → RELEASE |
| RESIST | 세기대로 버팀(최대 0.5초) | 시간 끝 또는 X → RELEASE |
| RELEASE | 끈을 다시 풀어 느슨하게 | 끝나면 IDLE |
| SAFE | 출력 0 | 0.2초 명령 없음이면 어느 상태에서나 여기로. 다음 명령이 오면 IDLE |

## 고건님이 할 일

1. 받은 펌웨어를 올립니다. **처음에는 끈을 스풀에서 빼고** 모터만 돌게 해서 확인합니다.
2. 시리얼 모니터(115200, 줄 끝 = 새 줄)를 열고 아래를 순서대로 입력합니다.
   - `R,40,300` → 약하게 0.3초 돌고 멈춤
   - `R,40,2000` → 0.5초에서 잘려야 함(상한)
   - `P,1000` 후 아무것도 안 보냄 → 1초 뒤 풀림
   - `P,1000` 후 바로 `R,60,200` → 준비 없을 때보다 빨리 힘이 남
   - `R,60,400` 도중 `X` → 즉시 멈춤
   - `H`를 보내다 끊음 → 0.2초 뒤 `S,SAFE,...`
3. 다 되면 끈을 걸고 같은 순서를 반복합니다. 세기는 40부터.
4. 하나라도 이상하면 멈추고, 입력한 줄과 돌아온 `S,...` 줄을 그대로 복사해 팀 단톡방에 올립니다.

동작한 펌웨어는 레포 `Hardware/Exo/firmware/`에 배선 사진과 함께 저장해 기준본으로 삼습니다.
