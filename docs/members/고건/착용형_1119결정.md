게임 쪽 코드가 들어가면, 책상 장치를 PC-A에 USB로 꽂고 함께 시험합니다(한 번, 1시간 정도). 고건님은 장치를 들고 오고 비상 정지 버튼 옆에 있으면 됩니다. 날짜는 **팀 회의에서 정할 것**.

## 착용형 한 팔 (11/06 ~ 11/12)

| 항목 | 원칙 |
|---|---|
| 범위 | 담당 팔 한쪽 모듈만: 상완 가이드 + 팔꿈치 풀리 + 전완 커프 + 끈 경로. 먼저 왼팔(조종사 A) |
| 무게 배치 | 모터·전자함은 등이나 허리. 팔에 달리는 무게는 최소. 반대쪽 어깨끈으로 균형 |
| 추적 | **손목·손 주변 약 10cm는 비움.** 전완 커프는 전완 중간~팔꿈치 쪽. Quest는 카메라로 컨트롤러를 보므로 가리면 팔이 튀어요 |
| 착탈 | 벨크로·버클로 30초 안팎. 운영자가 도와 입히는 방식 |
| 크기 | M 하나로 먼저. S/L은 여유가 있으면 |
| 위생·내구 | 패드 커버 교체식, 예비 끈 |
| 출력 | 간섭을 고친 모듈만. 부품 ID·날짜·재료를 표에 기록 |

두 번째 장치(오른팔, 조종사 B)는 왼팔 장치를 CAD에서 좌우 대칭(미러)으로 만듭니다. 그러려면 왼팔 장치를 설계할 때부터 **좌우 비대칭 부품을 줄여** 둡니다. 만들지는 11/12 팀 회의에서 결정(모터·ESP32·드라이버가 한 벌 더 필요).

**11/12 끝 기준**: 팀원이 착용형을 차고 1인 양팔 모드로 5분 플레이. 끝난 뒤 팔이 아프거나 컨트롤러 추적이 튀지 않았는지 물어봅니다.

## 11/19 결정

다음을 **모두** 만족하면 착용형을 시연에 넣습니다.

- [ ] T1~T7 모두 통과, 특히 T5·T6
- [ ] 착용 상태에서 평소 팔이 걸리지 않음
- [ ] 컨트롤러 추적이 튀지 않음
- [ ] 5분 플레이 후 장치가 풀리거나 뜨거워지지 않음
- [ ] 착탈이 1분 안

하나라도 안 되면: 책상형을 **부스 체험용**(관객이 손잡이를 잡고 느껴 보는 코너)으로 두고, 게임은 컨트롤러 진동으로 진행합니다. 실패가 아니라 계획된 대안입니다.
