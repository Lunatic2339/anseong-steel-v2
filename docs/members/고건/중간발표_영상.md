# 고건 — 중간발표 영상

[← 고건 처음으로](../README.md)

발표 자료는 유진님이 만듭니다. 고건님은 **10/28까지** 아래 세 가지를 유진님에게 보내고 팀 단톡방에도 올립니다.

1. **30초 영상**: 책상 시제품이 명령 → 저항 → 해제하는 장면.
2. **현재 상태 사진 1장**: 장치 전체가 보이게, 밝은 곳에서.
3. **CAD 화면 1장**: 착용형 최종 모습(계획임을 발표에서 표시합니다).

## 30초 영상 콘티

| 시간 | 화면 | 방법 |
|---|---|---|
| 0~5초 | 장치 전체 | 천천히 옆에서 돌며 찍기 |
| 5~15초 | 팔을 펴는 도중 막힘 | 한 사람이 손잡이를 밀면서 폄. 다른 사람이 PC에서 `R,…`을 보내면 멈칫하고 막힘. 화면 구석에 시리얼 창이 보이면 좋음 |
| 15~22초 | 해제 | `X` 또는 시간이 끝나면 다시 가볍게 폄 |
| 22~30초 | 안전장치 | 비상 정지 버튼을 누르는 장면 |

- 가로로, 삼각대나 책상 위에 휴대폰을 고정해서. 배경은 정리.
- 모터 소리가 들리면 좋습니다. 잔소리(대화)는 나중에 빼도 됩니다.
- **아직 사람 팔에 차는 장면은 찍지 않습니다**(T6 통과 전). 손잡이를 잡고 밀기만 합니다. T6을 통과했다면 손잡이를 잡는 것까지 괜찮습니다.
- 펼 때 막히는 끈 경로가 10/28까지 안 되면 지금 구조로 찍고, 발표에서 "방향 수정 중"이라고 표시합니다. **팀 회의에서** 결정.

Unity와 연결해 "게임에서 때리면 장치가 반응"하는 영상은 11/05 목표입니다. 중간발표에는 필요 없습니다.
