# 고건 — 1단계 책상 시제품과 역구동 확인

[← 고건 처음으로](../README.md)

등판·하네스·커프 없이 **팔꿈치 관절 하나만** 책상에 고정해 만듭니다. 목적은 ① 힘 방향 확인, ② 세기·지연 측정, ③ 안전장치 동작 확인. 중간발표 영상도 이걸로 찍습니다.

## ① 먼저 멈추고 정리하기 (최우선, 10/17)

1. **전체 13장 출력을 멈춥니다.** 최신 조립 검사에서 141쌍이 겹칩니다.
2. 이미 뽑은 부품의 ID 목록을 만듭니다(부품 ID, 날짜, 재료). → 팀 단톡방에 사진이나 표로.
3. 모터가 돌고 멈추던 **그 코드와 배선 사진**을 저장합니다. 나중에 문제가 생기면 여기로 돌아옵니다.

## ② 역구동 확인 (부품이 오기 전에 할 수 있음)

감속비 1:51 기어는 출력축을 손으로 돌리기(역구동) 어려울 수 있습니다. 이걸 먼저 알아야 모터 제어 방식을 고를 수 있습니다.

1. 전원을 끄고 출력축에 스풀(또는 테이프 한 조각)을 달고 손으로 돌려 봅니다.
2. 스풀에 끈을 감고 끈을 당겨서 풀려 나오는지 봅니다. 수하물 저울을 걸어 **몇 kg에서 풀리기 시작하는지** 기록합니다.
3. 결과를 팀 단톡방에 올립니다: "손으로 잘 돈다 / 뻑뻑하다(약 __kg) / 안 돈다".

| 결과 | 의미 | 다음 |
|---|---|---|
| 잘 돈다 | 끈을 팔에 묶어 둬도 팔이 덜 걸림 | "느슨 + 감기"로 시작, 느슨 길이를 짧게 잡아 지연을 줄임 |
| 뻑뻑하거나 안 돈다 | 모터가 멈춰 있으면 팔이 걸림 | "느슨 + 감기"에서 끈 여유를 팔 전체 움직임만큼 충분히 |

드라이버 사양서에서 **브레이크 입력**이 있는지도 같이 확인해 주세요. 있으면 나중에 다른 방식을 시험할 수 있습니다.

## ③ CAD 수정: 책상 시제품에 필요한 것만

| 순서 | 대상 (원본 ID) | 할 것 |
|---|---|---|
| 1 | 팔꿈치 풀리·출구 브래킷·지지 기둥 (A070↔A084, A076↔금속 기둥) | 간섭 수정 + **끈 감김 방향을 반대로**(펼 때 막힘). 상완·전완 가이드 출구 위치만 옮기는 것이 가장 작은 변경 |
| 2 | 상완 끈 통로 ↔ 소형 풀리 (A087↔A105) | 끈이 실제로 통하는지 |
| 3 | A042/A070 체결 구멍 | 팔꿈치 링크 조립 |
| 뒤로 | 등판, 하네스, 오른쪽 어깨, 전완 클램프 | 11/12 착용형 단계에서 |

CAD에서 팔꿈치를 0°(폄)에서 135°(굽힘)까지 돌려 보며 **펼 때** 끈 길이가 늘어나는지 확인합니다. 끈은 당기기만 하므로, 펼 때 끈이 길어져야 모터가 그걸 막을 수 있습니다. 끈이 팔 안쪽(이두 쪽)에 가까워지므로 피부·커프에 닿는지도 봅니다. 0°·45°·90°·135° 네 각도의 끈 길이를 적어 팀 단톡방에 올려 주세요.

## ④ 책상 시제품 부품

| 부품 | 비고 | 상태 |
|---|---|---|
| 바닥판, 클램프 | 합판이나 알루미늄 프로파일, 책상에 클램프 고정 |  |
| 상완 기둥 + 전완 막대 | 있는 파이프(Ø20) 재사용 |  |
| 팔꿈치 힌지 + 풀리 | 위 수정한 풀리·출구 브래킷만 따로 출력. 608 베어링, M8 볼트 축 |  |
| 모터 + 스풀 + 끈 | PM28 그대로, 스풀 Ø60 |  |
| 손잡이 | 전완 끝에 사람이 잡고 밀어 볼 수 있게 |  |
| 수하물 저울 | 끈 중간에 걸어 장력 측정. 디지털 최고값 표시형 |  |
| 비상 정지 스위치, 퓨즈 | 버섯형, 모터 전원선에 직렬. 퓨즈 용량은 모터 정격에 맞춤 |  |
| 약한 고리 | 케이블타이 등, 끈과 손잡이 사이 |  |
| 고무줄·작은 스프링 | 느슨한 끈이 엉키지 않게 살짝 당김 |  |
