# 고건 — 막혔을 때

[← 고건 처음으로](../README.md)

| 증상 | 먼저 볼 것 |
|---|---|
| 펌웨어 업로드가 안 됨 | USB 케이블이 충전 전용인지, 포트(COM) 선택, 업로드 중 BOOT 버튼. 시리얼 모니터가 포트를 잡고 있으면 닫기 |
| 시리얼에 깨진 글자만 나옴 | 통신 속도 115200, 줄 끝 = 새 줄 |
| 명령을 보내도 반응 없음 | `S,…` 줄이 오는지. 오면 상태 값을 그대로 팀 단톡방에. 안 오면 포트·케이블 |
| 모터가 반대로 돈다(풀어야 할 때 감김) | 펌웨어 맨 위 "감는 방향" 상수 한 줄만 바꾸면 되게 만듭니다. 어느 줄인지는 펌웨어를 드릴 때 알려 드림 |
| 모터가 멈추지 않음 | **비상 정지 먼저.** 그다음 전원을 끄고 팀 단톡방에. 다시 켜서 확인하지 마세요 |
| 저항 중 모터가 덜덜 떨거나 소리가 큼 | 세기를 낮추고 영상으로 찍어 팀 단톡방에. 멈춘 채 버티는(스톨) 상태에서 드라이버 보호가 동작하는 것일 수 있음 |
| 끈이 스풀에서 빠짐 | 스풀 양쪽 턱(테두리)을 높이거나, 고무줄로 끈을 살짝 당겨 둠 |
| 퓨즈가 자꾸 나감 | 퓨즈를 굵게 바꾸지 말고 팀 단톡방에. 모터가 멈춘 채 오래 버티고 있는 것 |
| 출력물이 안 맞음 | 부품 ID와 안 맞는 곳 사진을 기록해 두고 다음 단계로. 책상 시제품은 테이프·케이블타이로 고정해도 됩니다 |

혼자 30분 넘게 막히면 멈추고 **사진·영상 + 무엇을 하다가 생겼는지 한 줄**을 팀 단톡방에 올려 주세요. 특히 모터가 예상과 다르게 움직이면 혼자 고치려 하지 말고 바로 멈춥니다.
