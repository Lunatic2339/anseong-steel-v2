# 고건 — 3단계 시험 T1~T7

[← 고건 처음으로](../README.md)

순서: **T1·T2·T5·T6은 10/29까지**(안전과 방향), **T3·T4·T7은 11/05까지**(수치). T6을 통과하기 전에는 손잡이를 사람이 잡지 말고 저울만 걸고 시험합니다.

| 번호 | 시험 | 방법 | 통과 기준 |
|---|---|---|---|
| T1 | 힘 방향 | `R,60,500`을 보내고 전완이 어느 쪽으로 밀리는지 봄 | 펴는 쪽으로 밀면 막힘(굽히는 쪽으로 당김) |
| T2 | 평소 자유도 | 명령 없이 손잡이를 0~135° 빠르게 20번 왕복 | 걸림이 거의 없고 끈이 엉키거나 스풀에서 빠지지 않음 |
| T3 | 세기표 | 전완 90° 고정, 세기 0·32·64·96·128·160·192·224·255를 각 3번, 저울 최고값 | 아래 기록표가 다 채워짐 |
| T4 | 지연 | 명령을 받으면 보드 LED가 켜짐(펌웨어에 넣어 둠). 휴대폰 슬로모션 240fps로 LED와 저울을 같이 찍음. (장력이 오른 프레임 − LED 프레임) ÷ 240 | 느슨 길이 3가지 × P 있음/없음으로 값이 나옴. 목표 50ms 안팎(제안) |
| T5 | 워치독 | `R,60,500` 도중 USB 케이블을 뽑음 | 0.2초 안에 힘이 풀림 |
| T6 | 비상 정지·약한 고리 | ① 저항 중 비상 정지 버튼 ② 약한 고리에 힘을 올려 가며 저울로 끊어지는 값 확인 | 버튼으로 즉시 풀림. 약한 고리가 정한 힘 근처에서 끊어짐 |
| T7 | 발열 | "0.3초 저항, 2초 쉬기"를 10분 반복(테스트용 자동 명령은 펌웨어에 넣어 드림). 2분마다 모터·드라이버를 손등으로 대봄 | 손을 대기 힘들 만큼 뜨겁지 않음. 뜨거워지면 바로 중단 |

## 기록 규칙

- 시험마다 날짜, 펌웨어 버전(파일 이름), 느슨 길이, 결과, 사진·영상 1개.
- 실패도 기록합니다. "T2 실패: 90° 근처에서 끈이 스풀 옆으로 빠짐" 같은 한 줄이 가장 쓸모 있습니다.
- 기록은 이 문서의 표에 바로 채워도 됩니다(표 칸을 클릭해 입력).
