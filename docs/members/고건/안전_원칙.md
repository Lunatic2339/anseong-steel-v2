# 고건 — 안전 원칙 (먼저 읽기)

[← 고건 처음으로](../README.md)

감속비 1:51이라 모터 축에서 나오는 힘은 생각보다 큽니다. 관객이 차는 장치이므로 아래 세 겹을 **모두** 갖추기 전에는 사람이 차지 않습니다. 책상 시제품에서도 같은 규칙을 씁니다.

| 겹 | 할 것 | 확인 시험 |
|---|---|---|
| ① 소프트웨어 | 0.2초 동안 명령이 없으면 출력 0(워치독). 한 번의 저항은 최대 0.5초로 자름. 세기 상한을 펌웨어 상수로 고정. 켜질 때는 항상 0에서 시작 | T5 |
| ② 전기 | 비상 정지 스위치(버섯형)가 **모터 전원선을 직접 끊음**(ESP32를 거치지 않음). 모터 전원선에 퓨즈 | T6 |
| ③ 기계 | 약한 고리: 일정 장력 이상이면 끊어지거나 빠지는 연결부(케이블타이, 얇게 출력한 링크, 자석 커플러 등)를 끈과 팔 사이에. 손으로 1초 안에 풀 수 있는 착탈부 | T6 |

## 절대 하지 말 것

- 비상 정지·약한 고리가 T6을 통과하기 전에 사람 팔에 묶기.
- 혼자 있을 때 착용 시험. **옆에 비상 정지를 누를 사람**이 항상 있어야 합니다.
- "누가 잠깐 버틴 힘"을 합격값으로 삼기. 세기는 약하게 시작해 팀원이 손잡이를 잡고 체감하며 조금씩 올립니다.
- 끈이 팔을 관절 한계 너머로 끌어당기는 방향으로 걸리게 두기.
- 드라이버 보호 기능을 끄거나 퓨즈를 굵은 것으로 바꾸기.

**팀 회의에서 정할 것**: 약한 고리를 몇 kg에서 끊어지게 할지는 T3 세기표가 나온 뒤 함께 정합니다. 그 전에는 손으로 쉽게 끊을 수 있는 정도(얇은 케이블타이)로 둡니다.
