## AI 활용 안내

**모두 공통**

- **Claude에게 맡기면 좋은 것**: 같은 일을 여러 번 반복하는 작업(스크립트), 표·목록 정리, 초안 쓰기. Claude는 화면을 직접 못 보므로 **모양을 빚거나 눈으로 다듬는 일은 약합니다.** 그런 일은 사람이 합니다.
- **3D 생성 AI**(우리 로봇을 만든 Tripo 같은 것)는 **소품 초안**용입니다. 나온 모델은 Blender에서 다듬어야 하고, 뼈대가 있는 모델(로봇·보스)에는 쓰지 않습니다.
- AI로 만든 파일도 출처를 적습니다: `SOURCES.md`(또는 드라이브 `SOURCES`)에 `파일 이름 / AI 생성 / 서비스 이름 / 날짜 / 그 서비스의 이용 조건(전시에 써도 되는지)`. 이용 조건을 모르면 쓰기 전에 팀 단톡방에 올려 같이 봅니다.
- 요청하는 곳: 자기 Claude가 있으면 직접, 없으면 아래 예시 문구를 **팀 단톡방**에 그대로 올리면 코드 담당(선우)의 Claude 세션이 만듭니다.
- Claude가 알려 준 메뉴 이름이 화면에 없으면(버전 차이로 틀릴 수 있음) 찾느라 헤매지 말고 화면 캡처를 보내 다시 묻습니다.
- 스크립트는 **실행 전에 파일을 새 번호로 저장**하고 돌립니다. 결과가 이상하면 이전 번호 파일로 돌아가면 됩니다.

## A-01 애니메이션 클립

우리 로봇(보스와 플레이어 모두)은 Mixamo 뼈대라서 **Mixamo 동작을 그대로 쓸 수 있습니다.** 모델링·리깅 지식은 필요 없고, 고르는 눈이 가장 중요합니다.

### 고르는 기준

- **묵직하고 크게**: 65m 로봇입니다. 가볍게 튀는 동작보다 몸 전체로 힘을 싣는 동작.
- **예고가 보이게**: 보스 공격은 플레이어가 보고 막아야 합니다. 팔을 뒤로 빼는 준비 동작이 또렷한 것(준비가 1초 안팎이면 좋음).
- **제자리에서**: 발이 크게 미끄러지거나 방향이 크게 바뀌는 것은 피하기.
- 후보가 여러 개면 2~3개 받아 두고 팀과 같이 고릅니다. 파일 이름 끝에 `_a`, `_b`를 붙이면 됩니다.

### 받는 법 (클립 하나)

1. mixamo.com에 Adobe 계정으로 로그인(무료).
2. 위쪽 **Animations** 탭 → 검색창에 아래 표의 검색어.
3. 목록을 눌러 오른쪽 미리보기로 확인. 캐릭터는 기본 그대로 둡니다(우리 로봇을 올릴 필요 없음).
4. 오른쪽 슬라이더: **Overdrive**(속도)는 보통 그대로나 조금 느리게, **Character Arm-Space**(팔 간격)는 팔이 몸을 뚫으면 조금 넓게. 이동하는 동작이면 **In Place** 체크.
5. **Download** → 아래 설정으로.

| 항목 | 값 |
|---|---|
| Format | FBX for Unity(.fbx) |
| Skin | **Without Skin** (뼈 움직임만. 파일이 작아짐) |
| Frames per Second | 30 |
| Keyframe Reduction | none |

6. 파일 이름을 표의 이름으로 바꿉니다. 보스용은 `Boss_`, 플레이어 몸용은 `Pilot_`로 시작.
7. 아래 진행표에 원래 Mixamo 이름과 바꾼 값(속도 등)을 적습니다. 나중에 다시 받을 때 필요합니다.

## D-01 보스 패턴 검토 (10/20 ~ 10/27)

보스 패턴은 레포 `docs/design/05_boss_patterns.md`에 Claude가 제안값으로 채워 두었습니다. 유진님은 **처음부터 쓰지 않고, 보스 담당 눈으로 검토하고 다듬습니다.** 아래에 필요한 내용을 옮겨 두었으니 이 문서에서 바로 채우면 됩니다.

### 보스 공격 한 번의 흐름

쉬는 중(가드 자세) → **예고**(준비 동작 + 경고음) → **명중 순간** → 회복 → **빈틈**(플레이어가 반격) → 쉬는 중 …

보스는 빈틈과 휘청일 때만 피해를 받습니다. "막고 → 빈틈에 반격"이라는 리듬이 게임의 핵심입니다.

### ① 타이밍 칸 채우기

각 클립을 열어 두 가지를 잽니다.

- **명중 순간**: 클립 시작부터 주먹(또는 몸)이 닿는 순간까지 몇 초인지.
- **끝**: 동작이 끝나 다시 가드 자세로 돌아오는 데 몇 초인지.

재는 법: 클립을 멈춰 두고 프레임 번호를 보면 됩니다. 우리 클립은 30fps라 **프레임 번호 ÷ 30 = 초**입니다(예: 27프레임 = 0.9초). 어느 화면으로 볼지는 팀 회의에서 정한 대로(Unity Animation 창, 또는 프레임 번호가 찍힌 영상). 대략 0.1초 단위면 충분합니다. 아직 없는 클립은 비워 둡니다.

| 기술 | 페이즈 | 클립 | 예고 (제안) | 명중 순간 | 끝 | 대응 | 실패 피해 | 메모 |
|---|---|---|---|---|---|---|---|---|
| 왼손 펀치 | 1~ | `Boss_PunchLeft` | 1.2 |  |  | 왼팔 가드 | 6 |  |
| 오른손 펀치 | 1~ | `Punch` | 1.2 |  |  | 오른팔 가드 | 6 |  |
| 좌우 연타 | 2~ | `AlternatingCombo` | 1.2(첫 타), 이후 0.7 간격 | 1타: / 2타: / 3타: / 4타: |  | 번갈아 가드, 4타 | 타당 4 | 실제 몇 타? |

### ② 어색한 곳 찾기

아래를 보면서 고칠 곳이 있으면 숫자를 바꾸고 메모 칸에 이유를 한 줄 적습니다.

- **예고 시간 ↔ 준비 동작**: 예고 1.2초는 "경고음이 울리고 맞기까지"의 시간입니다. 클립의 명중 순간이 0.8초라면, 클립 시작 전에 0.4초를 더 기다려야 합니다. 그 대신 예고를 0.8로 줄이는 게 나을지, 준비 동작을 느리게 해서 맞추는 게 나을지 의견을 주세요.
- **좌우 연타 타 수**: 제안은 4타입니다. 클립이 3타나 5타면 클립에 맞춰 고칩니다.
- **초보가 보고 막을 수 있는가**: 처음 해 보는 관객 두 명이 예고를 보고 팔을 올리기에 충분한지.
- **쉬는 시간과 비율**: 페이즈별 표를 보고 지루하거나 정신없지 않을지.

| 페이즈 | 첫 공격 | 이후 고르는 비율 | 쉬는 시간(초) | 규칙 | 메모 |
|---|---|---|---|---|---|
| 1 (HP 100→60%) | 오른손 펀치 | 왼손 50 · 오른손 50 | 2.5~3.5 | 같은 손 3번 연속 금지 |  |
| 2 (60→25%) | 두 손 내려찍기 | 단발 50 · 연타 25 · 내려찍기 25 | 2.0~3.0 | 시작 후 3번 안에 연타 한 번. 내려찍기 연속 금지 |  |
