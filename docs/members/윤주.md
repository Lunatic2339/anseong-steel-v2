## AI 활용 안내

**모두 공통**

- **Claude에게 맡기면 좋은 것**: 같은 일을 여러 번 반복하는 작업(스크립트), 표·목록 정리, 초안 쓰기. Claude는 화면을 직접 못 보므로 **모양을 빚거나 눈으로 다듬는 일은 약합니다.** 그런 일은 사람이 합니다.
- **3D 생성 AI**(우리 로봇을 만든 Tripo 같은 것)는 **소품 초안**용입니다. 나온 모델은 Blender에서 다듬어야 하고, 뼈대가 있는 모델(로봇·보스)에는 쓰지 않습니다.
- AI로 만든 파일도 출처를 적습니다: `SOURCES.md`(또는 드라이브 `SOURCES`)에 `파일 이름 / AI 생성 / 서비스 이름 / 날짜 / 그 서비스의 이용 조건(전시에 써도 되는지)`. 이용 조건을 모르면 쓰기 전에 팀 단톡방에 올려 같이 봅니다.
- 요청하는 곳: 자기 Claude가 있으면 직접, 없으면 아래 예시 문구를 **팀 단톡방**에 그대로 올리면 코드 담당(선우)의 Claude 세션이 만듭니다.
- Claude가 알려 준 메뉴 이름이 화면에 없으면(버전 차이로 틀릴 수 있음) 찾느라 헤매지 말고 화면 캡처를 보내 다시 묻습니다.
- 스크립트는 **실행 전에 파일을 새 번호로 저장**하고 돌립니다. 결과가 이상하면 이전 번호 파일로 돌아가면 됩니다.

## E-01 ① 종이 배치도와 기본 조작

### 만들 맵의 모양

제철소의 **길고 곧은 마당**입니다. 우리 로봇은 가운데에 서 있고, 보스는 정면 40m 앞에 있습니다. 두 로봇 모두 65m(아파트 20층 정도)라, 조종사는 약 60m 높이에서 **아래와 앞**을 봅니다. 작은 트럭·컨테이너가 발밑에 보여야 "내가 거대하다"는 느낌이 납니다.

지킬 규칙 세 가지:

1. **로봇과 보스 사이는 비웁니다.** 양옆으로 피할 수 있게 폭 약 100m.
2. **양옆 가장자리에 로봇 팔 높이(25~45m) 구조물**을 둡니다. 나중에 팔을 휘두르다 부수는 것들입니다.
3. **더 바깥에는 눈높이보다 큰 건물(60~120m)**. 고로·굴뚝 같은 것으로 제철소라는 걸 알려 줍니다.

### 종이 배치도 그리기 (10/17~10/19, Unity 없이)

A4 한 장에 **위에서 내려다본 모습**을 그립니다. 잘 그릴 필요 없고 네모와 글자만으로 충분합니다.

1. 종이 가운데 아래쪽에 ○(우리 로봇), 그 위쪽에 ●(보스). 위쪽이 보스 방향입니다.
2. 두 동그라미를 둘러싼 큰 점선 네모 = 비워 둘 전투 공간.
3. 점선 네모 양옆에 부서질 구조물을 한쪽 3개씩 + 보스 뒤에 사일로 1개. 각각 무엇일지 적기(예: "크레인", "급수탑", "컨베이어 다리").
4. 그 바깥에 큰 배경 건물 몇 개(고로, 굴뚝, 공장).
5. 로봇 뒤쪽에 정비고(로봇이 출격하는 건물).
6. 사진을 찍어 팀 단톡방에 올립니다.

참고할 만한 것: 인터넷에서 "제철소 항공사진", "steel mill aerial"을 검색해 보면 실제 배치가 나옵니다. 마음에 드는 사진 2~3장을 배치도와 같이 올려 주세요.

### Unity 기본 조작 연습 (처음 준비 다음 날, 1시간)

`Sandbox_Yunju` 씬에서 연습합니다. 망쳐도 괜찮습니다. 저장 안 하고 닫으면 되돌아갑니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 화면 둘러보기 | Scene 창에서 **마우스 오른쪽 버튼을 누른 채** 마우스를 움직임 |
| 걸어다니기 | 오른쪽 버튼을 누른 채 **W A S D**(앞 왼쪽 뒤 오른쪽), **Q E**(아래 위). **Shift**를 같이 누르면 빨라짐 |
| 가까이·멀리 | 마우스 휠 |
| 물체로 바로 가기 | Hierarchy에서 물체 이름을 고르고 Scene 창에서 **F** |
| 옮기기 | 물체를 고르고 **W** → 빨강·초록·파랑 화살표를 끌기 |
| 돌리기 | **E** → 동그라미를 끌기 |
| 크기 | **R** → 가운데 하얀 상자를 끌면 전체가 같이 커짐 |
| 복사 | **Ctrl + D** |
| 되돌리기 | **Ctrl + Z** |
| 저장 | **Ctrl + S** (자주!) |
| 정확한 위치 넣기 | 오른쪽 Inspector의 Transform → Position에 숫자 입력 |

**연습 과제** (다 하면 배치를 시작해도 됩니다):

- [ ] 로봇 발밑으로 낮게 내려가 트럭 기준물 옆에 서 보기
- [ ] 다시 로봇 머리 높이(60m)로 올라가 아래를 내려다보기 — 이게 조종사 시점
- [ ] 트럭 기준물을 Ctrl+D로 세 개 복사해 나란히 놓기
- [ ] 하나를 돌리고, 하나를 두 배로 키우기
- [ ] Inspector에서 Position을 X 30, Y 0, Z 0으로 입력해 보기
- [ ] 연습한 트럭을 지우기(Delete 키)

좌표 읽는 법: **X = 왼쪽(-)·오른쪽(+), Y = 높이, Z = 뒤(-)·보스 쪽(+)**. 단위는 m입니다. 로봇이 X 0, Z 0에 있고 보스는 Z 40입니다.

## E-01 ② 에셋 고르기와 출처 기록

## E-01 ③ 구역별 배치

### 묶음 만들기 (먼저 한 번)

## S-01 효과음 모으기

지금 게임에는 소리가 하나도 없습니다. 거대 로봇의 무게감은 절반이 소리에서 나옵니다. 윤주님은 **소리를 골라 이름을 맞춰 드라이브에 모으는 것**까지 합니다. Unity도 편집 프로그램도 필요 없고, 앞뒤 무음 자르기·변환·게임에 넣기는 코드 담당이 합니다.

### 처음 한 번

1. 구글 드라이브에 `안성제철_소리` 폴더 → 안에 `SFX`, `BGM`, `Voice`, `후보` 폴더. 폴더를 팀원에게 공유(편집 권한).
2. 같은 폴더에 구글 문서 `SOURCES` 만들기.
3. freesound.org 가입(다운로드에 필요).

### 소리 하나 받는 법 (freesound)

1. 검색창에 아래 표의 **영어 검색어**를 하나 넣습니다.
2. 왼쪽(또는 위쪽) 필터 **License → Creative Commons 0**를 고릅니다. 이것만 고르면 출처 문제가 없습니다.
3. ▶로 들어봅니다. **고르는 기준**: 시작이 바로 나오고 또렷한가, 사람 말소리·음악·잡음이 없는가, 표의 길이와 비슷한가.
4. 마음에 들면 Download → 파일 이름을 표의 이름 + 번호로 바꾸기(예: `SFX_PunchHit_01.wav`, `_02`, `_03`). MP3여도 괜찮습니다.
5. `SOURCES`에 한 줄: `파일 이름 / freesound / 원래 제목 / 만든 사람 / CC0 / 주소`.
6. 고르기 어려우면 2~3개를 `후보` 폴더에 넣어 두고 나중에 팀과 같이 들어보고 고릅니다.

**사람 크기 소리여도 됩니다.** 게임에서 낮게 끌어내리면 거대하게 들립니다. 드럼통을 망치로 친 소리가 훌륭한 로봇 펀치가 됩니다. 다른 무료 출처: Sonniss GDC 무료 번들, Kenney 오디오(CC0).

## 막혔을 때

| 증상 | 해결 |
|---|---|
| Scene 창에서 물체가 안 보임 | Hierarchy에서 물체를 고르고 Scene 창에 마우스를 올린 뒤 **F** |
| 화면이 이상하게 돌아감 / 방향을 잃음 | Scene 창 오른쪽 위 방향 상자(Gizmo)의 Y를 누르면 위에서 내려다보기 |
| 물체가 분홍색 | Render Pipeline Converter → Material Upgrade. 안 되면 그 에셋은 두고 팀 단톡방에 |
| 가져온 물체가 엄청 크거나 작음 | 단위가 다른 것. 기준물 옆에 놓고 R로 맞추기 |
| 고친 게 사라짐 | Play 중에 고친 것은 사라집니다. Play를 끄고 고치기. 자주 Ctrl+S |
| 프리팹을 고쳤는데 파일에 안 들어감 | Inspector 위쪽 Overrides → Apply All |
| Unity가 느리거나 멈춘 것 같음 | 몇 분 기다리기. 그래도 안 되면 저장하고 다시 열기 |
| 빨간 글씨(에러)가 아래 Console에 뜸 | 에셋을 가져온 직후라면 그 에셋 때문일 가능성이 큽니다. 먼저 Ctrl+Z나 그 폴더 지우기, 그리고 팀 단톡방에 캡처 |
| GitHub Desktop에 모르는 파일이 잇따라 나옴 | 올리지 말고 팀 단톡방에 캡처 |
| freesound에서 Download 버튼이 안 나옴 | 로그인해야 보입니다 |
| 마음에 드는 소리가 없음 | 검색어를 바꿔 보기(예: metal 대신 steel, iron). 도저히 없으면 비워 두고 다음으로 |
