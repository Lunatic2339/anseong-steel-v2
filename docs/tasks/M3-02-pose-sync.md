# M3-02 상대 조종사 팔·머리 동기화

- 마일스톤: M3 / 담당: 선우(코드는 Claude), 2인 검증 성재 / 브랜치: `feat/m3-02-pose-sync`

- 기한(제안): 11/10

## 목표
PC-A에서 오른팔(PC-B 조종사)이, PC-B에서 왼팔(PC-A 조종사)이 상대 조종사의 움직임대로 끊김 없이 움직인다. 자기 팔은 M1처럼 로컬 입력으로 바로 그린다. 상대 조종사의 머리·양손도 조종석 안에 보인다(임시 모양).

## 배경
- `02_architecture.md` "누가 무엇을 계산하나": 머리·양손 자세는 각 PC가 소유, 비신뢰 60Hz → 상대 PC가 100ms 버퍼로 보간. 자기 팔은 네트워크를 거치지 않음. 펀치 명중은 때린 쪽 PC가 판정해 신뢰 RPC로 서버에 보고.
- 명중 보고(`HitReport`)는 M2-01 `CombatServer.HitRpc`가 이미 ServerRpc라 PC-B에서도 그대로 서버로 간다. M3-01이 팔 주인 검사를 넣었다.
- 가드 상태·필살기 준비 RPC는 M2-03·05 위에서 붙인다(그 브랜치가 develop에 들어간 뒤).

## Claude가 할 일
1. 순수 `Net/PoseBuffer`: 자세 보간 버퍼(늦게·순서 바뀌어 온 것 버림, 마지막 뒤는 유지·예측 없음, 0.5초 끊김).
2. `Net/PilotPoseSync`(NetworkBehaviour, Combat Server에): 자기 팔 뼈 회전(로봇 루트 기준) + 머리·양손(조종석 기준)을 60Hz 비신뢰 RPC로 상대에게. 받은 쪽은 서버 시각 − 0.1초로 보간해 팔 IK 뒤에 상대 팔 뼈를 덮어쓰고, 머리·손 임시 표시를 옮긴다. 1인 양팔은 아무것도 안 함.
3. `RobotArmDriver`: 팔 뼈·로봇 루트 읽기 전용 속성 4개.
4. 메뉴 Add Network Session이 `PilotPoseSync`와 조종석 안 `Remote Pilot (임시)`를 만든다.
5. 조절 메뉴 "2인 동기화": 상대 팔 늦게 그리기(초), 상대 조종사 표시, 확인 칸 3개.
6. EditMode 테스트 `PoseBufferTests`.

  - 허리 회전(`TorsoTwist`)은 각 PC가 자기 조종사 기준으로 계산해 두 PC에서 몸통 각도가 조금 다를 수 있다. 상대 팔은 로봇 루트 기준 회전이라 어깨 위치가 허리만큼 다르게 보일 수 있다. 눈에 띄면 허리를 끄거나(1인 양팔처럼) 허리 값도 보낸다.
  - 상대 조종사 표시는 임시 구·상자. 조종사 아트(Art/Pilot)가 오면 같은 칸에 넣는다.
  - 보내는 양: 한 PC 초당 약 60 × 160바이트 ≈ 10KB. 유선 LAN에서 문제 없음.
