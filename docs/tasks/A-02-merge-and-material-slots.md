# A-02 로봇 메시 정리: 병합·재질 슬롯·각진 모서리

- 마일스톤: M3 전 (11/05) / 담당: 성재 (Blender 막히면 유진 도움, 재질 슬롯 배정은 윤주와) / 브랜치: `feat/sungjae-robot-cleanup`
- 선행: M0-03 병합(사용할 v026 파일 확정)

## 목표
v026 로봇의 메시 291개·재질 124개를 **재질 슬롯 6개 기준으로 합쳐** 렌더러 8개 이하·재질 6개 이하로 만들고, 텍스처 없이도 **각진 기계**로 보이게 모서리를 정리한다.

## 배경
- `docs/design/04_art_spec.md`의 "바꾸면 안 되는 기준", "현재 모델의 문제와 해결 순서", "성능 한도", "공용 재질 슬롯".
- 뼈대(이름·계층·개수), 팔 길이 비율, 정면 방향은 바꾸지 않는다. 그래야 코드는 그대로 두고 파일만 바꿔 끼울 수 있다.
- 원본: M0-03에서 확정한 `Assets/_Anseong/Art/Robot/Source/BossUpdatedCompatible.fbx`(단위 m, `Armature` 스케일 1, 텍스처는 같은 폴더 `Textures/`). 짝이 되는 `.blend`가 기존 레포에 있는지 모르므로 **이 FBX를 Blender로 임포트해서 시작하는 것을 기본**으로 한다.
- 주의: M0-03에서 단위 cm·`Armature` 스케일 100인 파일은 Idle 재생 시 몸이 사라졌다. 내보낼 때 단위·스케일이 원본과 같아야 한다.

## 경로 1 (우선): Blender

사람이 할 일 (성재, 필요하면 유진):
1. 레포의 `BossUpdatedCompatible.fbx`를 Blender로 임포트한다(File → Import → FBX). 텍스처가 보이도록 `Textures/` 폴더도 함께 복사해 둔다. **새 `.blend` 이름으로 저장**하고 레포의 FBX는 건드리지 않는다.
2. **병합**: 메시 오브젝트들을 선택해 Join(Ctrl+J)으로 합친다. 한 오브젝트가 너무 크면 몸통·팔·다리 정도로 나눠도 된다(최대 8개). Armature 모디파이어와 버텍스 그룹(뼈 가중치)이 유지되는지 확인. 이 단계에서는 원래 재질 124개가 그대로 붙어 있어도 된다.
3. **각진 모서리**: Shade Auto Smooth(각도 30~45°)를 적용하고, 장갑판 경계가 날카롭게 보이는 각도를 고른다. 필요한 곳은 Mark Sharp.
4. (선택, 마지막 수단) 면이 울퉁불퉁하면 Decimate(Planar)를 일부 부위에만. 적용 후 포즈 모드에서 팔·다리를 굽혀 찢어짐이 없는지 확인.
5. **A-03 비교용 굽기** (`04_art_spec.md` "표면 표현 3안"). 모양 정리가 끝났고 **원래 재질이 아직 붙어 있을 때** 한다:
   - 합친 메시에 두 번째 UV를 만든다(Smart UV Project). 원래 UV는 지우지 않는다.
   - **AO**: 판 사이 틈 그림자를 두 번째 UV로 2048 텍스처 1장에 굽는다 → `Robot_v026_AO.png`.
   - **Tripo 색 아틀라스**: 원래 재질 122장의 색을 두 번째 UV로 4096(또는 2048) 1장에 굽는다 → `Robot_v026_Atlas.png`.
6. **재질 정리**: 124개 재질을 슬롯 6개(ArmorMain, ArmorAccent, Metal, Dark, Glow, Trim)로 다시 배정하고, 슬롯 이름의 재질 6개만 남긴다. 애매한 부분은 Dark.
7. FBX로 내보내기: Armature + Mesh만, 원본과 **같은 단위·스케일·축**(단위 m, `Armature` 스케일 1, 정면 +Z·위 +Y가 Unity에서 유지). 확실하지 않으면 Claude Code에 원본 FBX의 설정을 물어본다. 파일 이름 `Robot_v026_clean.fbx`. 텍스처 두 장은 따로 넘긴다. **다시 내보낼 때마다 약 20MB가 git 히스토리에 쌓이므로** 확인이 끝난 버전만 레포에 넣는다(중간본은 드라이브로 주고받기).
8. Claude Code에 파일을 넘긴다(직접 레포에 넣거나 선우에게 전달).

Claude가 할 일:
1. `Robot_v026_clean.fbx`를 `Assets/_Anseong/Art/Robot/Source/`에 넣고 임포트 규칙에 맞춘다.
2. 샌드박스 메뉴: 원본과 정리본을 나란히, 같은 Idle 재생, 회색 재질 + URP SSAO 켠 비교 화면.
3. 뼈 이름·개수·계층과 `Armature` 스케일·임포트 높이(약 1.056m)가 원본과 같은지 검사하는 에디터 메뉴(다르면 목록 출력). 렌더러·재질·삼각형 수는 M0-03의 **Report Robot Stats**를 정리본에도 쓸 수 있게 해서 결과 칸에 기록.
4. 공용 재질 12개(슬롯 6 × 플레이어/보스)를 기본 색으로 만들어 정리본에 연결한다. AO·아틀라스 텍스처가 있으면 함께 임포트한다(새 UV 채널 확인). 색과 최종 방식은 A-03에서 정한다.

## 경로 2 (대안): Unity 도구
Blender에서 막히면 Claude Code가 만든다: 재질 매핑 에셋 + 에디터 창(**Anseong → Art → Material Slot Mapper**, 원본 재질별 슬롯 드롭다운) + 병합 도구(**Anseong → Art → Build Merged Robot**, 같은 뼈·bindpose 유지). 모서리는 임포트 설정 Normals = Calculate, Smoothing Angle 30~45°를 세 벌 비교해 고른다.

## 하지 말 것
- 뼈 이름·계층·개수 변경, 팔 비율 변경. 모델 전용 텍스처를 새로 그리기. 원본 파일 덮어쓰기.

## 완료 기준
- 정리된 로봇: 렌더러 8개 이하, 재질 6개 이하, 뼈 검사 통과, Idle이 원본과 같게 움직임, 장갑판 모서리가 각져 보임(헤드셋으로 한 번 확인).
- A-03 비교용 AO·아틀라스 텍스처가 있음(경로 2로 갔다면 생략 가능).
