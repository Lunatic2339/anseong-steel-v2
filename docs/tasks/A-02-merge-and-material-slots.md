# A-02 로봇 메시 정리: 병합·재질 슬롯·각진 모서리

- 마일스톤: M3 전 (11/05) / 담당: Blender 경험자 (+윤주, Claude Code) / 브랜치: `feat/<이름>-robot-cleanup`
- 선행: M0-03 병합(사용할 v026 파일 확정)

## 목표
v026 로봇의 메시 291개·재질 124개를 **재질 슬롯 6개 기준으로 합쳐** 렌더러 8개 이하·재질 6개 이하로 만들고, 텍스처 없이도 **각진 기계**로 보이게 모서리를 정리한다.

## 배경
- `docs/design/04_art_spec.md`의 "바꾸면 안 되는 기준", "현재 모델의 문제와 해결 순서", "성능 한도", "공용 재질 슬롯".
- 뼈대(이름·계층·개수), 팔 길이 비율, 정면 방향은 바꾸지 않는다. 그래야 코드는 그대로 두고 파일만 바꿔 끼울 수 있다.
- 원본 Blender 파일: 기존 레포 `AnseongSteel/Assets/_Project/02_Art/01_Models/mecha-finger-rig-mixamo-v026.blend` 등(M0-03에서 고른 FBX와 짝인 것을 확인).

## 경로 1 (우선): Blender

사람이 할 일 (Blender 경험자):
1. M0-03에서 고른 v026의 `.blend`를 연다(없으면 FBX를 Blender로 임포트). **새 이름으로 저장**하고 원본은 그대로 둔다.
2. **재질 정리**: 124개 재질을 슬롯 6개(ArmorMain, ArmorAccent, Metal, Dark, Glow, Trim)로 다시 배정한다. 슬롯 이름의 재질 6개만 남기고, 기존 이미지 텍스처 연결은 끊는다. 애매한 부분은 Dark.
3. **병합**: 메시 오브젝트들을 선택해 Join(Ctrl+J)으로 합친다. 한 오브젝트가 너무 크면 몸통·팔·다리 정도로 나눠도 된다(최대 8개). Armature 모디파이어와 버텍스 그룹(뼈 가중치)이 유지되는지 확인.
4. **각진 모서리**: Shade Auto Smooth(각도 30~45°)를 적용하고, 장갑판 경계가 날카롭게 보이는 각도를 고른다. 필요한 곳은 Mark Sharp.
5. (선택, 마지막 수단) 면이 울퉁불퉁하면 Decimate(Planar)를 일부 부위에만. 적용 후 포즈 모드에서 팔·다리를 굽혀 찢어짐이 없는지 확인.
6. FBX로 내보내기: Armature + Mesh만, 기존 v026 FBX와 **같은 내보내기 설정**(스케일·축). Claude Code에 기존 FBX의 설정을 물어보면 알려준다. 파일 이름 `Robot_v026_clean.fbx`.
7. Claude Code에 파일을 넘긴다(직접 레포에 넣거나 선우에게 전달).

Claude가 할 일:
1. `Robot_v026_clean.fbx`를 `Assets/_Anseong/Art/Robot/Source/`에 넣고 임포트 규칙에 맞춘다.
2. 샌드박스 메뉴: 원본과 정리본을 나란히, 같은 Idle 재생, 회색 재질 + URP SSAO 켠 비교 화면.
3. 뼈 이름·개수·계층이 원본과 같은지 검사하는 에디터 메뉴(다르면 목록 출력). 렌더러·재질·삼각형 수를 결과 칸에 기록.
4. 공용 재질 12개(슬롯 6 × 플레이어/보스)를 기본 색으로 만들어 정리본에 연결한다. 색은 A-03에서 정한다.

## 경로 2 (대안): Unity 도구
Blender에서 막히면 Claude Code가 만든다: 재질 매핑 에셋 + 에디터 창(**Anseong → Art → Material Slot Mapper**, 원본 재질별 슬롯 드롭다운) + 병합 도구(**Anseong → Art → Build Merged Robot**, 같은 뼈·bindpose 유지). 모서리는 임포트 설정 Normals = Calculate, Smoothing Angle 30~45°를 세 벌 비교해 고른다.

## 하지 말 것
- 뼈 이름·계층·개수 변경, 팔 비율 변경. 새 텍스처 그리기. 원본 파일 덮어쓰기.

## 완료 기준
- 정리된 로봇: 렌더러 8개 이하, 재질 6개 이하, 뼈 검사 통과, Idle이 원본과 같게 움직임, 텍스처 없이도 장갑판 모서리가 각져 보임(헤드셋으로 한 번 확인).
