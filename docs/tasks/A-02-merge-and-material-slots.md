# A-02 로봇 메시 정리: 병합·재질 슬롯·각진 모서리

- 마일스톤: M3 전 (11/05) / 담당: 성재 (Blender 막히면 유진 도움) / 브랜치: `sungjae`
- 선행: M0-03 병합(사용할 v026 파일 확정)

## 목표
v026 로봇의 메시 291개·재질 124개를 **재질 슬롯 6개 기준으로 합쳐** 렌더러 8개 이하·재질 6개 이하로 만들고, 텍스처 없이도 **각진 기계**로 보이게 모서리를 정리한다.

## 배경
- `docs/design/04_art_spec.md`의 "바꾸면 안 되는 기준", "현재 모델의 문제와 해결 순서", "성능 한도", "공용 재질 슬롯".
- 뼈대(이름·계층·개수), 팔 길이 비율, 정면 방향은 바꾸지 않는다. 그래야 코드는 그대로 두고 파일만 바꿔 끼울 수 있다.
- 원본: M0-03에서 확정한 `Assets/_Anseong/Art/Robot/Source/BossUpdatedCompatible.fbx`(단위 m, `Armature` 스케일 1, 텍스처는 같은 폴더 `Textures/`). 짝이 되는 `.blend`가 기존 레포에 있는지 모르므로 **이 FBX를 Blender로 임포트해서 시작하는 것을 기본**으로 한다.
- 주의: M0-03에서 단위 cm·`Armature` 스케일 100인 파일은 Idle 재생 시 몸이 사라졌다. 내보낼 때 단위·스케일이 원본과 같아야 한다.

## 경로 1 (우선): Blender

사람이 할 일 (성재, 필요하면 유진):
1. 레포의 `BossUpdatedCompatible.fbx`를 Blender로 임포트한다(File → Import → FBX). 텍스처가 보이도록 `Textures/` 폴더도 함께 복사해 둔다. **새 `.blend` 이름으로 저장**하고 레포의 FBX는 건드리지 않는다.
2. **병합**: 메시 오브젝트들을 선택해 Join(Ctrl+J)으로 합친다. 단 **머리 부품(Head·Head_end 뼈에 붙은 조각, 지금 11개)은 그들끼리만 합쳐 `Robot_Head`로 따로 남긴다.** 조종석이 로봇 머리 안(Head 좌석)이라 게임에서 자기 로봇 머리만 숨기기 때문이다(M0-04). 11개 이름은 M0-04 샌드박스 메뉴 로그에 있다. 나머지는 하나로 합쳐도 되고, 너무 크면 몸통·팔·다리 정도로 나눠도 된다(머리 포함 최대 8개). Armature 모디파이어와 버텍스 그룹(뼈 가중치)이 유지되는지 확인. 이 단계에서는 원래 재질 124개가 그대로 붙어 있어도 된다.
3. **어깨 장갑 웨이트 다시 칠하기** (M1-03 헤드셋 확인에서 나옴). 지금 어깨 장갑이 위팔 뼈(`mixamorig:LeftArm`/`RightArm`)에 100% 묶여 있어서, 팔을 크게 돌리면 장갑이 같이 돌아 몸통을 파고든다. 모델에 쇄골 뼈가 없어서 코드로는 못 막는다. **어깨 장갑은 몸통 뼈 `mixamorig:Spine` 위주로, 위팔은 조금만** 섞는다. **뼈 이름·개수·계층은 그대로 둔다**(뼈를 새로 만들거나 지우지 않는다, 버텍스 그룹 값만 바꾼다).
   1. 합친 메시를 클릭하고 3D 화면 왼쪽 위 모드 메뉴(`Object Mode`라고 쓰인 곳)에서 **Edit Mode**로 바꾼다.
   2. 키보드 `1`로 점 선택 모드. 왼쪽 어깨 장갑 위에 마우스를 올리고 `L`을 누르면 그 조각이 통째로 선택된다(여러 조각이면 `Shift`+`L`로 더 고른다). 몸통 쪽 이음새 점까지 잡혔는지 본다.
   3. 오른쪽 Properties 창의 **Object Data Properties**(초록 삼각형 아이콘) → **Vertex Groups** 목록에서 `mixamorig:Spine`을 클릭하고, 아래 **Weight**를 `0.8`로 맞춘 뒤 **Assign**.
   4. 같은 목록에서 `mixamorig:LeftArm`을 클릭하고 **Weight** `0.2` → **Assign**. (Assign은 고른 점의 값을 이 숫자로 바꿔 쓴다.)
   5. 오른쪽 어깨 장갑도 같은 방법으로(`mixamorig:RightArm`).
   6. 모드 메뉴에서 **Weight Paint**로 바꾸고 위쪽 **Weights** 메뉴 → **Normalize All**을 누른다(한 점의 값 합이 1이 되게).
   - 0.8 / 0.2는 시작값이다. 아래 확인에서 장갑이 팔과 너무 떨어져 보이면 위팔 쪽을 올리고(예: 0.7 / 0.3), 여전히 파고들면 내린다. 어느 값이 좋은지 애매하면 두 장면 스크린샷을 **팀 단톡방**에 올리고 **팀 회의에서 정할 것**.
   - **확인 1 (색으로 보기)**: Weight Paint 모드에서 Vertex Groups 목록의 뼈 이름을 하나씩 클릭하면 그 뼈의 영향이 색으로 보인다(빨강 = 1, 파랑 = 0). `mixamorig:Spine`을 고르면 어깨 장갑이 주황~빨강, `mixamorig:LeftArm`을 고르면 어깨 장갑이 파랑~하늘색이고 위팔 본체는 빨강이어야 한다.
   - **확인 2 (팔을 돌려 보기)**: `Object Mode`로 돌아가 Armature(뼈대)를 클릭 → 모드 메뉴 **Pose Mode** → 위팔 뼈를 클릭하고 `R`을 눌러 마우스로 크게 돌린다(앞으로 들기, 옆으로 들기, 위로 올리기). 어깨 장갑이 몸통 속으로 들어가지 않고, 위팔 본체와 장갑 사이가 찢어지지 않는지 본다. 다 보면 `Alt`+`R`로 원래 자세로 돌리고 `Object Mode`로 나온다.
4. **각진 모서리**: Shade Auto Smooth(각도 30~45°)를 적용하고, 장갑판 경계가 날카롭게 보이는 각도를 고른다. 필요한 곳은 Mark Sharp.
5. (선택, 마지막 수단) 면이 울퉁불퉁하면 Decimate(Planar)를 일부 부위에만. 적용 후 포즈 모드에서 팔·다리를 굽혀 찢어짐이 없는지 확인.
6. **A-03 비교용 굽기** (`04_art_spec.md` "표면 표현 3안"). 모양 정리가 끝났고 **원래 재질이 아직 붙어 있을 때** 한다:
   - 합친 메시에 두 번째 UV를 만든다(Smart UV Project). 원래 UV는 지우지 않는다.
   - **AO**: 판 사이 틈 그림자를 두 번째 UV로 2048 텍스처 1장에 굽는다 → `Robot_v026_AO.png`.
   - **Tripo 색 아틀라스**: 원래 재질 122장의 색을 두 번째 UV로 4096(또는 2048) 1장에 굽는다 → `Robot_v026_Atlas.png`.
7. **재질 정리**: 124개 재질을 슬롯 6개(ArmorMain, ArmorAccent, Metal, Dark, Glow, Trim)로 다시 배정하고, 슬롯 이름의 재질 6개만 남긴다. 애매한 부분은 Dark.
8. FBX로 내보내기: Armature + Mesh만, 원본과 **같은 단위·스케일·축**(단위 m, `Armature` 스케일 1, 정면 +Z·위 +Y가 Unity에서 유지). 확실하지 않으면 Claude Code에 원본 FBX의 설정을 물어본다. 파일 이름 `Robot_v026_clean.fbx`. 텍스처 두 장은 따로 넘긴다. **다시 내보낼 때마다 약 20MB가 git 히스토리에 쌓이므로** 확인이 끝난 버전만 레포에 넣는다(중간본은 드라이브로 주고받기).
9. Claude Code에 파일을 넘긴다(직접 레포에 넣거나, 드라이브에 올리고 팀 단톡방에 링크).

Claude가 할 일:
1. `Robot_v026_clean.fbx`를 `Assets/_Anseong/Art/Robot/Source/`에 넣고 임포트 규칙에 맞춘다.
2. 샌드박스 메뉴: 원본과 정리본을 나란히, 같은 Idle 재생, 회색 재질 + URP SSAO 켠 비교 화면.
3. 뼈 이름·개수·계층과 `Armature` 스케일·임포트 높이(약 1.056m)가 원본과 같은지 검사하는 에디터 메뉴(다르면 목록 출력). 렌더러·재질·삼각형 수는 M0-03의 **Report Robot Stats**를 정리본에도 쓸 수 있게 해서 결과 칸에 기록.
4. 공용 재질 12개(슬롯 6 × 플레이어/보스)를 기본 색으로 만들어 정리본에 연결한다. AO·아틀라스 텍스처가 있으면 함께 임포트한다(새 UV 채널 확인). 색과 최종 방식은 A-03에서 정한다.

## 경로 2 (대안): Unity 도구
Blender에서 막히면 Claude Code가 만든다: 재질 매핑 에셋 + 에디터 창(**Anseong → Art → Material Slot Mapper**, 원본 재질별 슬롯 드롭다운) + 병합 도구(**Anseong → Art → Build Merged Robot**, 같은 뼈·bindpose 유지). 모서리는 임포트 설정 Normals = Calculate, Smoothing Angle 30~45°를 세 벌 비교해 고른다.
