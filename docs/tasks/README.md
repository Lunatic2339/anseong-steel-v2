# 작업 지시서

총괄 채팅이 지시서를 쓰고, Claude Code 세션이 하나씩 수행한다. **지시서 하나 = 세션 하나 = 브랜치 하나 = PR 하나.**

## 진행 순서

1. Claude Code(데스크톱 앱 Code 탭) 새 세션 → 이 레포 폴더 선택 → 모드 **Plan**.
2. "git pull 하고 docs/tasks/<파일> 읽고 계획 세워줘. 아직 수정하지 마."
3. 계획 승인 → 모드 **Accept edits** → "계획대로 진행해."
4. 사람이 할 일(Unity 조작, 헤드셋 확인)을 한다.
5. "결과 칸 채우고 feat/<이름>-<기능> 브랜치로 커밋하고 PR 만들어줘."
6. 총괄 채팅에 PR 링크를 보낸다.

## 지시서 형식

```markdown
# <번호> <제목>

- 마일스톤 / 담당 / 브랜치 이름

## 목표
한두 문장.

## 배경
읽을 설계 문서 섹션, 참고할 기존 코드(03_reuse 표의 항목).

## Claude가 할 일
번호 목록.

## 사람이 할 일
Unity 에디터 조작, 헤드셋 확인.

## 하지 말 것
범위 밖 작업.

## 완료 기준
헤드셋이나 에디터에서 사람이 확인할 수 있는 문장.

## 결과 (작업 후 Claude가 작성)
- 바뀐 파일:
- 사람이 확인할 것:
- 남은 문제 / 제안:
```
