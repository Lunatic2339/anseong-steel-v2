# A-03 로봇 표면 방식 고르기와 색 디자인

- 마일스톤: M4 (11/19) / 담당: 성재 (표면 방식·플레이어 색) + 유진 (보스 색) / 브랜치: `feat/sungjae-robot-surface`
- 선행: A-02 병합

## 목표
`docs/design/04_art_spec.md`의 "표면 표현 3안"을 헤드셋으로 비교해 하나를 고르고, 플레이어와 보스가 **한눈에 구분되면서 단색 플라스틱이 아닌 거대 기계**로 보이게 색·금속감·디테일을 정한다.

## 배경
- 3안: (가) Tripo 텍스처 그대로 / (나) 색 슬롯 6개 + 반복 디테일 맵 + AO / (다) Tripo 아틀라스 + 반복 디테일 맵.
- 거대감은 디테일보다 **명암 대비와 금속 반사**에서 나온다. 너무 매끈하거나 단색이면 장난감처럼 보인다.
- 기존 기획 메모의 보스 방향: 레드·블랙, 광택 있는 도장, 노란 눈, 부분적으로 낡은 금속, 무광 금색.

## Claude가 할 일
1. 반복 디테일 맵 준비: 무료(CC0) 금속·패널·긁힘 텍스처 2~3종을 `Assets/_Anseong/Art/Robot/Detail/`에 넣고 출처를 `Detail/SOURCES.md`에 적는다. (내려받기는 사람이 하고 파일을 넘겨도 된다.)
2. 3안 재질 세트를 만든다. 디테일은 URP Lit의 Detail Inputs(Detail Map·Detail Normal, 타일링), AO는 A-02에서 구운 `Robot_v026_AO.png`(두 번째 UV).
3. 샌드박스 메뉴 **Anseong → Art → Surface Compare**: 같은 로봇 세 대(가·나·다)를 나란히, 같은 조명. 키 하나로 거리 10m / 40m 카메라 전환.
4. 고른 안을 플레이어·보스 두 세트로 정리하고, 나머지 안의 재질은 지운다.

## 사람이 할 일 (성재, 보스 색은 유진)
1. Surface Compare에서 세 안을 가까이(10m)·멀리(40m) 본다. 헤드셋으로도 한 번 본다(선우·유진과).
2. 하나를 고른다. 기준: 가까이서 번지지 않음, 40m에서 판 구분이 보임, 단색처럼 보이지 않음.
3. 고른 안으로 색을 정한다. 플레이어는 성재, 보스는 유진(Base Color, Metallic, Smoothness, Emission, 디테일 세기·타일링).
4. 40m 거리에서 보스가 또렷한지, 플레이어 팔이 시야에서 너무 밝거나 눈부시지 않은지 헤드셋으로 확인.

## 하지 말 것
- 재질 수 늘리기(로봇당 6개 이하). 모델 전용 텍스처를 새로 그리기.

## 완료 기준
- 3안 중 하나를 팀이 고름. 헤드셋에서 플레이어와 보스가 한눈에 구분되고 단색처럼 보이지 않음.
