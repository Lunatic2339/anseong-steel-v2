# A-03 플레이어·보스 색 디자인

- 마일스톤: M4 (11/19) / 담당: 윤주 / 브랜치: `feat/yunju-robot-colors`
- 선행: A-02 병합

## 목표
같은 모델인 플레이어와 보스가 전장에서 **한눈에 구분되고, 65m 거대 기계로 보이게** 재질 12개(슬롯 6 × 2세트)의 색·금속감·발광을 정한다.

## 배경
- `docs/design/04_art_spec.md`의 "공용 재질 슬롯" 표는 제안 색이다. 기존 기획 메모의 보스 방향: 레드·블랙, 광택 있는 도장, 노란 눈, 부분적으로 낡은 금속, 무광 금색.
- 거대감은 디테일보다 **명암 대비와 금속 반사**에서 나온다. 너무 매끈하면 장난감처럼 보인다.

## 사람이 할 일 (윤주)
1. `Assets/_Anseong/Art/Robot/Materials/` 재질 12개를 Inspector에서 조절: Base Color, Metallic, Smoothness, Emission(Glow 슬롯만).
2. 샌드박스 씬(M0-03의 Scale Test)에서 두 로봇을 나란히 두고, 햇빛 방향을 바꿔 보며 확인.
3. 헤드셋으로 한 번 확인(선우와): 40m 거리에서 보스가 또렷한지, 플레이어 팔이 시야에서 너무 밝거나 눈부시지 않은지.
4. 기존 HUD 시트·컨셉 이미지와 어울리는지 본다.

## Claude가 할 일 (필요할 때)
- 낡은 금속 느낌이 필요하면, 텍스처 없이 쓸 수 있는 디테일 노멀·더러움 마스크를 URP Shader Graph로 하나 만들어 제안한다(선택).
- 색 조합 3안을 빠르게 바꿔 볼 수 있는 프리셋 전환 메뉴(선택).

## 하지 말 것
- 재질 수 늘리기(슬롯 6개 유지). 새 텍스처 그리기.

## 완료 기준
- 헤드셋에서 플레이어와 보스가 한눈에 구분되고, 팀이 색에 합의함.
