# M3-04 외골격 연결 (게임 → ESP32 시리얼)

- 마일스톤: M3 / 담당: 선우(코드는 Claude), 시험 고건 / 브랜치: `feat/m3-04-exo-serial`
- 선행: M1-05(전투 이벤트). M2와 무관해서 M2-01 병합 전에 develop에서 시작(11/01).
- 기한(제안): 11/12 (`07_milestones.md`: 11/05 → 11/12로 옮김, 팀 회의에서 정할 것)

## 목표
게임에서 펀치를 맞히면 그 팔 외골격이 짧게 버티고, 헛치거나 부스트를 쓰면 바로 풀린다. 포트가 없거나 선이 빠져도 게임은 아무 일 없이 계속된다.

## 배경
- `02_architecture.md` "외골격", "외골격 시리얼 프로토콜"(115200bps, `P,<ms>`·`R,<세기>,<ms>`·`X`·`H` 100ms, 응답 `S,<상태>,<출력>,<오류>`, 워치독 200ms, 별도 스레드, 포트 없으면 조용히 비활성).
- `01_combat_rules.md` "외골격 피드백"(명중 120ms, 가드 접촉 300ms, 부스트 즉시 해제, 끊김·종료 즉시 0).
- `06_feel_and_sound.md`: 명중 순간 소리 + 진동 + 외골격 저항을 같이.
- `H-01` 3번 "Unity 연결": 이 작업이 그것이다. 펌웨어(`Hardware/Exo/firmware/`)는 H-01 범위.
- 각 PC는 자기 팔 장치만. 1인 양팔은 한 PC에 장치 두 대(왼팔·오른팔).

## Claude가 할 일
1. `Runtime/Haptics/ExoProtocol`(순수): 명령 글자 만들기(세기 0-255, 저항 500ms, 준비 3000ms로 자름), `S` 줄 읽기.
2. `ExoCueRules`(순수): 전투 이벤트 → 그 팔 명령. 펀치 발사 → `P`(400ms), 명중 → `R`(140, 120ms, 세기 임시), 헛침·부스트 → `X`, 보스 쓰러짐 → 두 팔 `X`. 다른 팔 이벤트는 무시.
3. `ExoSerialLink`: 별도 스레드. 포트가 생길 때까지 2초마다 찾기, 연결되면 먼저 `X`. `H` 100ms(메인 스레드가 0.3초 넘게 멈추면 안 보냄 → 펌웨어 SAFE). 끊긴 동안 명령은 버림. 끝날 때 `X` 후 닫기. `.NET Framework`가 아니면 꺼짐으로만 표시.
4. `ExoArmLink`(MonoBehaviour, 팔 하나): 포트 이름 Inspector, 빌드는 실행 인자 `-exoLeft COM3` / `-exoRight COM4`가 우선. 연결·끊김 Console 한 줄, 개발용 `exo_<팔>_<날짜시각>.csv`(보낸 명령·받은 상태). 조절 메뉴 "외골격" 묶음.
5. 에디터 메뉴 **Anseong → Setup → Add Exoskeleton Links**.
6. EditMode 테스트: 명령 형식·자르기, 상태 읽기, 이벤트별 명령, 다른 팔 무시, 실행 인자.

## 사람이 할 일
- [ ] 외골격 없이: Play → Console에 `[Exo]` 경고·오류 없음, M1 기능 그대로(포트 비움 / 없는 포트 둘 다).
- [ ] 장치 연결(고건): 연결 Console 한 줄, 명중 때만 팔 펴는 쪽이 짧게 막힘, 헛치기·부스트 때 바로 풀림, 평소엔 자유로움.
- [ ] Play 중 USB 선 뽑기 → 게임 계속, 장치는 0.2초 안에 SAFE. 다시 꽂으면 2초 안에 다시 연결.
- [ ] Play 멈춤 → 장치가 바로 풀림.

## 하지 말 것
- 보스 공격 예고 `P`·가드 접촉 `R`(M2-02·03 이벤트가 생긴 뒤 `ExoCueRules`에 한 줄씩), 펌웨어(H-01), 운영자 화면의 포트 고르기(M3-01에서 필요하면).
