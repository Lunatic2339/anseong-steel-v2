# P-01 중간발표 자료와 시연 영상

- 마일스톤: 10/29 완성, **10/30 중간발표** / 담당: 유진 (+Claude 초안, 영상 촬영은 선우) / 브랜치: 없음
- 선행: 없음 (영상은 M1 결과가 나오는 10/27~29에 촬영)

## 목표
중간발표에서 **무엇을 만들고 있는지, 어디까지 됐는지, 끝까지 어떻게 갈지**를 짧고 분명하게 보여준다.

## 배경
- 학교 규정: 중간발표·과제전은 분반 통합, 과제전은 학부 교수님들이 평가하고 졸업 전시 참여가 결정된다.
- 기존 회의 메모: 교수님은 기능보다 **그래픽**을 더 걱정하셨다. 더미 캡슐·큐브 화면은 피한다.
- 내용 출처: 총괄 채팅의 「안성제철 최종 기획안」, `docs/design/00_plan.md`(중간발표 시연 범위, 일정), `01_combat_rules.md`.

## 발표 구성 (제안, 7~8분)
1. 한 문장 소개와 핵심 장면 이미지 (30초)
2. 어떤 게임인가: 두 조종사가 팔 하나씩, 잽–잽–훅 연계, 가드·협동 회피, 3페이즈, 합동 필살기 (1분 30초)
3. 왜 재미있는가: 협동이 필요한 이유, 거대감(65m 시점), 외골격 저항 (1분)
4. 기술 구조: PC 2대·Quest 3·외골격, 1인 양팔 대체 모드 (1분)
5. **진행 상황 시연 영상**: VR 화면에서 로봇 팔이 손을 따라오고 보스를 때리는 장면, 제철소 환경, 외골격 시제품 (2분)
6. 남은 일정: M2~M7과 12/11 전시 (1분)
7. 질문

## 사람이 할 일 (유진)
1. 선우가 총괄 채팅에 "P-01 발표 초안 만들어줘"라고 하면 Claude가 위 구성으로 슬라이드 초안을 만들어 링크를 준다. 유진은 그 링크에서 바로 글자·이미지를 고친다(파워포인트처럼 클릭해서 고치면 된다).
2. 이미지 모으기: 레퍼런스 이미지, 팀원 작업 사진(외골격, Blender 화면 등)을 팀원에게 받아 모은다. 로봇·보스 캡처는 팀 단톡방에 요청한다(선우가 찍음).
3. 시연 영상: 선우가 10/27~29에 녹화한 영상(1인 양팔로 펀치·가드·보스 경직, 1~2분)과 고건의 외골격 영상을 받아 슬라이드에 넣는다.
4. 리허설: 10/29에 팀 전체 한 번. 시간 재기.
5. 발표 당일 라이브 시연을 할지는 10/29 리허설 결과를 보고 팀이 함께 정한다(기본은 영상).
