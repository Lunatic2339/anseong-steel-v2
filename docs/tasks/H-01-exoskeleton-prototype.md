# H-01 외골격 한 팔 시제품

- 마일스톤: 10/29 (중간발표에서 시연) → M2에서 Unity 연결, M3에서 두 팔 / 담당: 고건 / 브랜치: `feat/gogeon-exo`
- 선행: 없음

## 목표
한 팔용 외골격이 **PC에서 보낸 명령대로 저항을 주고, 명령이 끊기면 스스로 풀리게** 만든다. 펌웨어 코드는 Claude Code가 쓰고, 고건이 ESP32에 올려 시험한다.

## 배경
- `docs/design/02_architecture.md`의 "외골격 시리얼 프로토콜": 115200bps, 한 줄 `R,<세기 0-255>,<지속ms>\n` (예: `R,180,120`). 200ms 동안 명령이 없으면 출력 0.
- `docs/design/01_combat_rules.md`의 "외골격 피드백": 명중 = 짧은 저항 120ms, 가드 접촉 = 강한 저항 300ms, 부스트 = 저항 해제.
- 외골격이 없어도 게임은 끝까지 돌아가야 한다. 외골격은 "있으면 더 좋은 것"이며, 안전이 가장 우선이다.

## 사람이 할 일 (고건)
0. **현재 상태를 결과 칸에 먼저 적는다**: 쓰는 모터·드라이버·전원, ESP32 보드 이름, 어디까지 조립됐는지, 사진 1장. 이걸 보고 Claude가 펌웨어를 맞춘다.
1. 안전장치(필수):
   - 손으로 바로 누를 수 있는 **비상 정지 스위치**(전원 차단).
   - **전류 제한**(드라이버 설정 또는 퓨즈).
   - 힘을 줘서 당기면 **기계적으로 풀리는 구조**(클러치, 벨크로, 약한 핀 등). 모터가 팔을 잡아당기는 방향으로는 힘이 걸리지 않게.
2. Claude Code에 펌웨어를 요청한다: "docs/tasks/H-01 읽고, 내 하드웨어(0번 내용)에 맞춰 ESP32 펌웨어 써줘". 파일 위치는 `Hardware/Exo/firmware/`.
3. ESP32에 올리고 Arduino IDE의 시리얼 모니터(115200, 줄바꿈 LF)에서 직접 입력해 시험:
   - `R,100,120` → 짧고 약한 저항, `R,255,300` → 강한 저항, `R,0,0` → 해제.
   - 명령을 보내지 않고 기다리면 0.2초 안에 풀리는지(워치독).
   - 비상 정지와 기계적 풀림이 실제로 되는지.
4. 팔에 차고 10분 이상 써 보고 불편한 점·열·소음을 결과 칸에 적는다.
5. 중간발표용: 시리얼 모니터로 명령을 보내며 저항이 걸리는 짧은 영상(30초). Unity 연결은 M2에서 선우·Claude가 한다.
6. 두 번째 팔용 부품 목록과 가격을 결과 칸에 적는다(M3에서 두 팔).

## 하지 말 것
- 안전장치 없이 사람 팔에 차기.
- 강한 모터로 팔을 실제로 끌어당기는 동작(저항만 준다).

## 완료 기준
- 시리얼 명령으로 세기·시간대로 저항이 걸리고, 명령이 끊기면 0.2초 안에 풀림.
- 비상 정지와 기계적 풀림이 동작.
