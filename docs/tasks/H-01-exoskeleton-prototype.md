- 단계별 자세한 순서·기록표는 [`docs/members/고건/`](../members/고건/README.md), 설계 근거는 PDF「외골격 진행 평가와 설계 가이드」.

## 목표
PC에서 보낸 명령대로 **팔을 펼 때 저항**을 주고, 명령이 끊기면 스스로 풀리는 한 팔 장치를 만든다. 먼저 책상 위에서 방향·세기·지연·안전을 확인하고, 그다음 착용형으로 간다. 펌웨어 코드는 Claude가 쓰고, 고건이 ESP32에 올려 시험한다.

## 배경
- `docs/design/02_architecture.md`의 "외골격"과 "외골격 시리얼 프로토콜"(`P`·`R`·`X`·`H`, 응답 `S`, 워치독 200ms).
- `docs/design/01_combat_rules.md`의 "외골격 피드백": 명중 약 120ms, 가드 접촉 약 300ms, 부스트 = 즉시 해제, 평소 = 저항 없음.
- 확정: 힘 방향 = **펼 때 막힘**(10/16). 장치 = 조종사당 담당 팔 하나(A 왼팔, B 오른팔 = 좌우 대칭).
- 외골격이 없어도 게임은 끝까지 돌아가야 한다. 외골격은 "있으면 더 좋은 것"이며, 안전이 가장 우선이다.

## 사람이 할 일 (고건)
1. **멈추고 정리 (10/17)**: 전체 출력 중단(최신 조립 검사에서 141쌍 간섭). 이미 뽑은 부품 ID 목록, 동작했던 코드·배선 사진을 저장.
2. **역구동 확인**: 전원을 끈 채 1:51 감속기 출력축을 끈으로 당겨 몇 kg에서 풀리는지 기록. 드라이버에 브레이크 입력이 있는지 사양서 확인.
3. **CAD 수정**(책상 시제품에 필요한 것만): 팔꿈치 풀리·출구 브래킷·지지 기둥의 간섭과 끈 감김 방향(펼 때 막힘). 0°·45°·90°·135°에서 끈 길이를 적는다.
4. **펌웨어 정보 전달 (10/20)**: 보드 이름, 핀 번호(PWM·방향·브레이크·FG), 드라이버 사양서, 지금 코드, 방향 핀 High일 때 감기/풀기.
5. **책상 시제품 조립 (~10/29)**: 바닥판 + 상완 기둥·전완 막대 + 팔꿈치 힌지·풀리 + 모터·스풀·끈 + 손잡이 + 수하물 저울 + 비상 정지·퓨즈 + 약한 고리.
6. **시험** (기록은 결과 칸이나 `Hardware/Exo/`):

   | 번호 | 시험 | 통과 기준 | 기한 |
   |---|---|---|---|
   | T1 | 힘 방향 | 펴는 쪽으로 밀면 막힘 | 10/29 |
   | T2 | 평소 자유도 | 명령 없이 0~135° 빠르게 왕복해도 걸림 거의 없음, 끈 엉킴·이탈 없음 | 10/29 |
   | T5 | 워치독 | 저항 중 USB를 뽑으면 0.2초 안에 풀림 | 10/29 |
   | T6 | 비상 정지·약한 고리 | 버튼으로 즉시 풀림, 약한 고리가 정한 힘 근처에서 끊어짐 | 10/29 |
   | T3 | 세기표 | 세기 0~255(32 간격) × 3회 장력(kg) | 11/05 |
   | T4 | 지연 | LED + 240fps 촬영, 느슨 길이 3가지 × `P` 있음/없음 | 11/05 |
   | T7 | 발열 | 0.3초 저항·2초 쉼 10분 반복에도 손댈 수 없을 만큼 뜨겁지 않음 | 11/05 |

7. **중간발표 영상 (10/28)**: 30초(명령 → 저항 → 해제 → 비상 정지). T6 전이면 사람이 손잡이를 잡지 않는다. 사진 1장 + CAD 화면 1장과 함께 유진에게.
8. **착용형 한 팔 (11/06~11/12)**: 간섭을 고친 모듈만 출력, 손목 주변 비움, 모터·전자함은 등·허리, 착탈 30초 안팎. 팀원이 1인 양팔 모드로 5분 플레이.
9. **11/19 결정** 기준: T1~T7 통과, 착용 상태에서 평소 팔이 안 걸림, 컨트롤러 추적이 안 튐, 5분 뒤 풀림·발열 없음, 착탈 1분 안. 하나라도 안 되면 책상형은 부스 체험용, 게임은 컨트롤러 진동만.

## Claude가 할 일
1. `Hardware/Exo/firmware/` ESP32 펌웨어: 프로토콜(`P`·`R`·`X`·`H`, `S` 응답 10Hz), 상태 `IDLE`·`PRE`·`RESIST`·`RELEASE`·`SAFE`, 워치독 200ms, 저항 최대 500ms, 세기 상한·감는 방향을 맨 위 상수로, 명령 수신 시 LED, T7용 자동 반복 모드(개발용).
2. 시리얼 모니터로 할 시험 순서를 펌웨어 README에 적는다(끈을 뺀 상태 → 건 상태, 세기 40부터).
3. Unity 연결(11/05, 선우): 명중·가드·예고 이벤트 → `P`/`R`/`X`, `H` 100ms, 포트가 없으면 조용히 비활성.

## 하지 말 것
- 비상 정지·약한 고리가 T6을 통과하기 전에 사람 팔에 차기. 혼자 있을 때 착용 시험.
- 팔을 몸 쪽이나 관절 한계 너머로 끌어당기는 방향의 힘. 드라이버 보호 끄기, 퓨즈를 굵게 바꾸기.
- 간섭을 고치지 않은 부품을 전체 출력하기.

## 완료 기준
- 책상 시제품: 시리얼 명령대로 펼 때 저항이 걸리고, 명령이 끊기면 0.2초 안에 풀리고, 비상 정지·약한 고리가 동작(10/29).
- 세기표·지연값이 `Hardware/Exo/`에 있고, 게임에서 펀치를 맞히면 책상 장치가 반응(11/05).
- 11/19에 착용형 투입 여부가 결정됨.
