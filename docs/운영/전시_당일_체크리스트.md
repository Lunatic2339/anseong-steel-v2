## 설치 순서 (전시 시작 1시간 전)

1. 공유기·랜선 연결 → 두 PC IP 확인(PC-A IP를 PC-B 운영자 화면에 넣음).
2. 두 PC에서 같은 빌드 실행(`-mode host` / `-mode client -ip <PC-A>`), 운영자 화면 상태 줄 "연결됨" 확인.
3. Quest Link 연결 → 헤드셋 안에서 조종석이 보이는지.
4. 외골격 USB 연결(`-exoLeft`, `-exoRight` 포트), 연결 안 되면 그냥 진행(게임은 외골격 없이도 끝까지 돈다).
5. 스태프 둘이 한 판 끝까지 → 결과판 → 두 스틱 1초로 재시작 확인.
6. 판 기록 CSV가 생기는지 확인(`persistentDataPath/logs/matches_*.csv`).
