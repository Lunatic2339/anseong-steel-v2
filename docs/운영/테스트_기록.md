# M6 외부인 테스트 기록

- 목표(07_milestones M6): **외부인 10쌍 이상 완주**, 큰 버그 0. 고칠 것은 버그와 수치(CSV)뿐, 새 기능은 없음. 한 판 5~10분.
- 판 숫자는 호스트 PC가 자동으로 남긴다: 에디터는 `Logs/Anseong/logs/matches_<날짜시각>.csv`, 빌드는 `persistentDataPath/logs/`. 열은 `time, won, seconds, block_percent, drones, best_combo, reboots`.
- 아래 표는 **사람이 보고 적는 것**(CSV에 안 나오는 것)만 쓴다. Claude에게 "테스트 기록 봐줘"라고 하면 CSV와 이 표를 같이 읽고 수치 조정안을 낸다.

## 한 쌍 순서 (약 15분)

1. 착용 전 30초 안내(윤주 안내문). "둘이 한 로봇의 팔을 하나씩 맡는다. 왼팔은 찾고 막고, 오른팔은 쏘고 벤다."
2. 외골격 착용(고건). 없으면 그냥 컨트롤러만.
3. 운영자 화면에서 호스트·클라이언트 시작 → B 메뉴 "판 → 판 시작"(또는 자동 시작).
4. 진행 중에는 말로 돕지 않는다. 막힌 곳만 시각과 함께 적는다.
5. 결과판 뒤 헤드셋 벗고 질문 3개(아래), 1분.
