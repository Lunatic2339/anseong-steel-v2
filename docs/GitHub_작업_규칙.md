# GitHub 작업 규칙 (팀원용)

레포: https://github.com/Lunatic2339/anseong-steel-v2
초대 메일(또는 GitHub 알림)에서 **Accept invitation**을 눌러야 푸시할 수 있습니다.

## 핵심 3줄

> 레포의 작업 기준 브랜치는 **`develop`**입니다(10/28부터). `main`은 검증된 버전만 모아 두는 안정(백업) 브랜치라 평소에는 신경 쓰지 않아도 됩니다.

1. **내 이름 브랜치 하나에서만 작업한다.** `main`·`develop`에는 직접 커밋·푸시하지 않는다.
2. **내 브랜치에 커밋·푸시까지만 한다.** PR도, 병합(Merge)도 하지 않는다.
3. **올렸으면 팀 단톡방에 한 줄 알린다.** 코드 담당(선우)이 중간중간 브랜치를 확인해 필요한 파일만 `develop`으로 가져간다.

## 브랜치: 내 이름 하나만

브랜치는 **자기 이름 하나**를 처음에 한 번 만들고 계속 씁니다. 일마다 새로 만들지 않습니다.

| 사람 | 브랜치 |
|---|---|
| 유진 | `yujin` |
| 성재 | `sungjae` |
| 윤주 | `yunju` |
| 고건 | `gogeon` |

## 처음 한 번

- **Claude Code**: "develop 최신으로 받고 거기서 `yujin` 브랜치 만들어줘." (자기 이름으로)
- **GitHub Desktop**: 위쪽 **Current branch** → **New branch** → 이름 `yujin` → 아래 기준 브랜치를 **develop**으로 고르고 Create branch → **Publish branch**.

## 매번

**Claude Code에 이렇게 말하면 됩니다**
1. 시작: "내 브랜치로 바꾸고 develop 최신 내용 받아줘."
2. 저장할 때: "지금까지 커밋하고 푸시해줘."
3. 팀 단톡방에 알리기(아래 양식).

**GitHub Desktop으로 직접 할 때**
1. 위쪽 **Current branch**가 내 이름인지 확인.
2. 위쪽 메뉴 **Branch → Update from develop** (다른 사람이 바꾼 최신 내용 받기). 메뉴에 `main`으로 보이면 **Branch → Merge into current branch…** → `develop` 선택.
3. 지시서에 적힌 폴더에 파일을 넣기(Unity가 만든 `.meta` 파일도 같이).
4. 왼쪽 아래에 한 줄 설명 → **Commit** → **Push origin**.
5. 팀 단톡방에 알리기(아래 양식).

**올렸을 때 팀 단톡방 양식**
```
[올림] 이름 / 지시서 번호(예: A-01 우선 1)
무엇: (예: Boss_PunchLeft.fbx, Boss_Knockback.fbx)
어디: (예: Assets/_Anseong/Art/Robot/Animation/Source/Mixamo/)  ← 넣을 곳은 docs/폴더_지도.md "2. 내 결과물은 어디에"
확인해 줄 것: (없으면 "없음")
```

**질문하거나 내 판단으로 바꾼 게 있으면**: 내 폴더 `작업_노트.md`에 적고 파일과 같이 커밋한 뒤 팀 단톡방에 `[질문]`·`[변경]`으로 알립니다. 자세한 순서는 [작업 노트](members/README.md#작업-노트-질문변경을-claude에게-묻기).

**Claude가 내 브랜치에 답을 올리면**: 작업 노트의 답은 Claude가 **내 이름 브랜치에 직접 커밋**합니다. 단톡방에 "답 올렸어요"가 오면 작업 전에 GitHub Desktop 위쪽 **Fetch origin → Pull origin**(Claude Code는 "내 브랜치 최신으로 받아줘")을 합니다. 받기 전에 작업 노트를 고쳤다면 먼저 커밋한 뒤 Pull 합니다.

- 다 끝나지 않았어도 중간중간 푸시해도 됩니다. 가져갈 준비가 된 것만 [올림]으로 알리면 됩니다.
- 가져간 뒤에는 코드 담당이 단톡방에 "가져갔어요"라고 답합니다. 그 뒤 작업 전에 2번(develop 최신 내용 받기)을 하면 됩니다.
- 실수로 다른 파일(프로젝트 설정 등)이 같이 올라가도 괜찮습니다. 필요한 파일만 골라서 가져갑니다.

## Unity 충돌 주의

- `Scenes/Main.unity`는 코드 담당(선우)만 수정한다. 나는 `Scenes/Sandbox/Sandbox_<이름>.unity`에서 작업하고 결과는 **프리팹**으로 넘긴다.
- 씬·프리팹은 두 사람이 동시에 고치면 합칠 수 없다. 남이 쓰는 프리팹을 고쳐야 하면 먼저 팀 단톡방에 말한다.
- 새 파일과 함께 생긴 `.meta` 파일은 반드시 같이 커밋한다.
- 파일 하나 50MB 이하. 빌드 결과·백업 폴더·캡처 영상은 올리지 않는다.
- 공개 레포라 비밀번호·토큰·Wi-Fi 정보는 절대 넣지 않는다.

막히면 팀 단톡방에 화면 캡처와 함께 물어보세요.
