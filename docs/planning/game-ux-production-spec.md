# VR 협동 메카 — 3·4안 병행 UX 및 AI 제작 명세

**이전 대안 기록:** 현재 기준은 [안성제철 3·4안 협동 및 10분 UX](anseong-steel-coop-10min.md)이다. 아래 장면·세계관·시간은 초기 대안이며 공통 제작 원칙 외에는 최신안과 구분한다.

작성: 2026-11-13 / 상태: 기획 초안 v0.2

후속 갱신: [10분 전투 구성](game-encounter-plan.md)에 전체 시간 배치와 적 종류·수량을 구체화했다. 아래 초기 장면 시간보다 최신 전투 구성의 시간을 우선하여 다음 상세 UX를 작성한다. 3·4안 병행 원칙은 유지한다.

## 1. 문서 사용 규칙

사용자가 확정한 것은 VR 협동 메카, 외계 기계생물과의 전투, 약 10분 전시, 실전형 튜토리얼, 3·4안 동등 병행 기획, 구현 전 상세 정의 우선이다. 제작 환경은 Meshy AI, ElevenLabs AI, Cascadeur, Higgsfield, Suno AI다.

이 문서의 이야기·입력·수치·에셋 수량은 검토 제안이다. 두 안 중 하나를 선택한 것으로 취급하지 않는다. 현재는 실제 제작·생성이 아닌 요구사항 정의 단계다. 사용자 확정: 전체 10분에 세계관·메카·역할 소개 시네마틱과 엔딩이 포함된다. 최신 시간표는 game-encounter-plan.md를 따르며 착용·교대 시간 포함 여부는 미정이다.

새 장면을 추가할 때 반드시 함께 작성할 항목: 이야기 목적 / VR 행동 / 3안 PC 행동 / 4안 PC 행동 / 상대가 보는 결과 / 성공·실패·재시도 / 필요한 제작물.

## 2. 공통 이야기와 역할

가제 ‘마지막 점화’. 피난 수송선의 이륙을 앞두고 외계 기계생물이 발전 시설을 점거했다. 정비 중이던 방어 메카와 지원 체계를 긴급 가동해 중계기를 복구하고, 발전로를 감싼 대형 개체를 제거한다.

첫 무전: “수송선 전력이 끊겼습니다. 두 분이 발전로까지 길을 열어야 합니다.”

| 구분 | VR | PC | 서로에게 필요한 이유 |
|---|---|---|---|
| 3안 | 지상 메카 조종사 | 원격 지원 드론 조종사 | 메카가 적의 장갑·대공 부위를 파괴하고, 드론이 높은 노드·사각의 위협을 처리 |
| 4안 | 지상 메카 조종사 | 시설 전술 관제사 | 메카가 물리적 장갑을 파괴하고, 관제사가 약점 발견·전력 교란·방어 구역을 선택 |

PC는 두 안 모두 별도 플레이어다. VR에게 모든 명령을 받아 실행하는 보조역으로 만들지 않는다. VR도 PC의 능력이 준비될 때까지 가만히 기다리지 않도록 일반 사격·방어를 계속 할 수 있다.

## 3. 공간과 시각 언어

- 공간: 격납고 → 짧은 정비 통로 → 중계기가 놓인 발전로 앞마당. 보스도 같은 앞마당에서 등장한다.
- 방향 기준: 발전로가 전방, 격납고가 후방. 안내에서 좌우는 메카 기준임을 표시한다.
- 인간 장비: 묵직한 산업용 판금, 직선 패널, 읽기 쉬운 기능 표시.
- 외계 기계생물: 겹친 검은 외피, 벌어지는 관절, 맥동하는 전력관. 생물처럼 움직이되 부위 기능이 읽혀야 한다.
- 기능 표식: 아군·연결은 청록, 위험은 주황, 약점은 밝은 백색 테두리와 표적 아이콘. 색만으로 구분하지 않고 모양과 짧은 글자를 병행한다.
- 공통 식별물: 메카 가슴의 원형 발전기, 드론의 두 측면 추진기, 적의 세 갈래 전력관. 선택한 외형을 모든 도구의 참조 기준으로 사용한다.
- 드론이 접근해야 하는 노드에는 실제 3D 공간상의 접근 경로가 있어야 한다. 4안에서는 동일 노드를 부위 도식과 지도에서 식별할 수 있어야 한다.

## 4. 입력과 화면 명세

### VR — 두 안 공통

| 행동 ID | 행동·입력 초안 | 성공 피드백 | 실패·오조작 대응 |
|---|---|---|---|
| V01 | 정면 기동 레버를 잡아 한 번 당김 | 조종석 점등, 부팅음, 손 진동 | 손 근처 레버 강조, 불필요한 추가 버튼 없음 |
| V02 | 오른손 방향으로 주포 조준, 트리거 발사 | 포구광, 탄착, 손 진동, 약점 명중 표시 | 장갑 명중은 튕김 표현으로 약점과 구별 |
| V03 | 왼손 방향으로 방패를 향하고 버튼 유지 | 막은 위치에 충돌광, 방패 상태 표시 | 못 막은 방향에 피해 표시, 즉시 재시도 가능 |
| V04 | 이동 가능 안내 뒤 레버로 거점 전진 | 경로 점등, 출발 예고, 다음 정지점 표시 | 진행 불가능할 때 레버에 이유 표시 |
| V05 | 주포 버튼 유지로 충전, 놓아 발사 | 조준점 충전 표시, 상승음, 완충 진동 | 조기 발사는 약한 사격, 다시 충전 가능 |

시선은 관찰에 사용하고 이동·몸통 회전에 강제로 연결하지 않는다. 조종석 전방에 목표 한 개와 위험 방향을 표시하고, 상세한 적 정보는 필요할 때만 띄운다. 화면 흔들림 없이도 무게감이 읽히도록 무장 부품·음향·진동을 설계한다. 이동 방식과 실제 편안함은 후속 검증 항목이다.

### 3안 PC — 비행과 공간 공략

| 행동 ID | 입력 초안 | 화면·피드백 |
|---|---|---|
| D01 | WASD로 이동, 마우스로 조준 | 수평을 유지하는 3인칭 카메라, 화면 중앙 조준점 |
| D02 | 클릭으로 경량 기관포 발사 | 명중 효과, 노드 손상 단계, 탄착음 |
| D03 | Space 상승 / Ctrl 하강 | 높이 눈금, 전투 가능 영역 표시 |
| D04 | 표적에 핑 키 사용 | VR HUD에 짧게 표적과 방향 표시 |
| D05 | 중계기 범위에서 상호작용 키 | 연결 진행 표시, 완료 즉시 이동 복귀 |

짧은 대시는 선택 확장안이다. 10분 기본 흐름은 대시 없이 성립하도록 한다. 1분 안에는 이동·사격만 가르치고, 상승·하강은 상부 노드가 처음 등장할 때 안내한다. 핑은 보조 수단이며 음성 대화나 핑 누락으로 필수 진행이 막히지 않는다.

### 4안 PC — 대상·위치·타이밍 판단

| 행동 ID | 입력 초안 | 화면·피드백 |
|---|---|---|
| T01 | 적 선택 후 스캔 버튼 | 적 부위 도식과 VR 약점 표식이 동시에 갱신 |
| T02 | 방어 구역 선택 후 방어막 버튼 | 해당 공간에 방어막, 막은 공격을 현장 영상과 지도에서 확인 |
| T03 | 적 선택 후 EMP 버튼 | 적의 예고 동작 중단, 코어/노드 상태 변화 표시 |
| T04 | 중계기 선택 후 연결 버튼 | 진행 표시, 복구한 전력 경로 점등 |

PC 화면 초안: 중앙 현장 화면, 한쪽 전장 지도, 하단 세 능력, 대상 선택 시 간단한 부위 도식. 현장 화면은 드론처럼 자유 조종하지 않고 메카 전방을 보여준다. 처음부터 여러 감시 카메라 전환을 요구하지 않는다.

사용 불가 상태에서는 ‘재사용 대기’, ‘범위 밖’, ‘대상 없음’을 각각 구별한다. 능력은 UI 버튼과 대응 숫자키 중 어느 쪽으로도 쓸 수 있도록 설계 제안한다. 스캔 결과는 잠깐 사라지는 암기 정보가 아니라 충분히 유지되는 표식이다.

## 5. 공통 적과 상호작용 규칙

에셋 후보는 소형 기생체, 중형 장갑 개체, 대형 보스 세 유형이다. 색상만 바꿔 새 적을 계속 추가하지 않고 행동을 단계적으로 공개한다.

| 적/오브젝트 | 공통 동작 | 3안의 해법 | 4안의 해법 |
|---|---|---|---|
| 출구 차단 조직 | 낮은 고정부와 높은 전력부로 문 봉쇄 | VR이 낮은 고정부, 드론이 높은 전력부 파괴 | PC가 약점 스캔, VR이 표시된 두 지점 파괴 |
| 소형 기생체 | 접근 후 투사체 발사, 일부는 메카 측면으로 접근 | 메카 정면 사격, 드론 측면 제거 | 메카 사격, PC 측면 방어막으로 피해 차단 |
| 중형 장갑 개체 | 공격 예고 → 정면 공격 → 회복, 장갑 뒤 노드 | VR 장갑 파괴 → 드론 노드 파괴 → VR 코어 공격 | VR 장갑 파괴 → PC EMP로 노드 교란 → VR 코어 공격 |
| 중계기 | 연결 중 적 공격에 노출 | 드론 연결 시작 후 이동·전투 가능 | PC 연결 시작 후 다른 능력 사용 가능 |
| 보스 | 정면 공격, 측면 위협, 전력 흡수, 코어 노출 | 장갑을 연 뒤 드론이 노드 파괴 | 장갑을 연 뒤 PC가 흡수 예고 중 EMP |

공통 상태: 장갑 보호 → 장갑 파괴 → 지원 역할 개입 → 코어 노출 → 회복 또는 처치. 3안은 위치와 조준, 4안은 대상과 타이밍을 요구한다. 동일한 상태 결과를 공유해도 입력의 재미는 서로 다르게 유지한다.

초기 연출 수치 제안: 첫 공격 예고 약 3초, 이후 약 2초. 첫 코어 노출 약 10초, 이후 약 7초. 수치는 확정 밸런스가 아니며 초보자의 인지 시간을 논의하기 위한 기준이다.

## 6. 장면별 10분 UX — 두 안 병렬 작성

### S00 · 0:00–0:40 · 긴급 기동

- 목적: 누가 누구이고 왜 싸우는지 알면서 첫 입력을 성공한다.
- VR: 어두운 조종석과 앞마당을 봄 → 레버 강조 → V01 → 계기판과 메카 팔에 전력 공급.
- 3안 PC: 메카를 옆에서 보는 드론 화면 → D01로 격납고 출구 표시점까지 이동.
- 4안 PC: 비활성 메카 도식 → 연결 버튼 → 현장 화면과 지도 켜짐.
- 상호 인지: VR에 ‘지원 연결 완료’, PC에 ‘조종사 탑승 확인’. 둘 다 준비되면 출구 차단 조직이 목표가 됨.
- 대사: “조종사, 기체를 가동하세요.” / 3안 “드론, 출구를 확인하세요.” / 4안 “관제사, 메카와 연결하세요.”
- 지연: 먼저 끝낸 플레이어는 주변을 관찰 가능. 뒤처진 역할에만 입력 그림을 다시 표시.
- 제작물: 조종석, 레버, 드론 또는 관제 화면, 부팅음, 기동 음성, 격납고 조명 변화.

### S01 · 0:40–1:25 · 출구 개방

- 목적: 실제 목표를 해결하며 조준·사격 또는 스캔을 익힘.
- VR: 차단 조직의 낮은 고정부를 V02로 파괴. 손 움직임과 조준점 관계를 학습.
- 3안 PC: 높은 전력부를 D02로 파괴. 시작 고도에서 쏠 수 있어 아직 상승 입력은 불필요.
- 4안 PC: 차단 조직을 T01로 스캔. VR 화면에 약점 두 곳과 파괴 순서 표시.
- 결과: 마지막 고정부가 파괴되면 문이 열리고 멀리 발전로와 수송선이 함께 보임.
- 실패: 시간제한 없는 표적. 4안 스캔 전 일반 사격도 약하게 손상되며, 스캔 후 확실한 약점 피드백 제공.
- 제작물: 분리 가능한 고정부·전력부, 파괴 전후 형태, 표적 표시, 스캔음, 문 개방음.

### S02 · 1:25–2:25 · 첫 방어

- 목적: 공격 예고를 읽고 VR 정면 방어와 PC 측면 지원을 구분.
- VR: 정면 기생체가 느린 투사체 발사 → V03으로 방어 → V02로 반격.
- 3안 PC: 다른 기생체가 메카 측면에 접근 → 이동하며 제거. VR은 창밖에서 동료 드론의 탄선을 확인.
- 4안 PC: 측면 공격 방향이 지도에 표시 → T02로 그 구역을 보호. VR은 해당 방향에 생긴 방어막 확인.
- 대사: “정면 공격, 방패를 올리세요.” / “지원 담당, 메카 왼쪽을 부탁합니다.”
- 실패: 첫 피격은 큰 손실 없이 피해 방향을 알려줌. 다음 공격에서 같은 행동을 다시 시도.
- 제작물: 기생체 이동·공격·사망, 공격 예고, 투사체, 방패 충돌, 측면 경고.

### S03 · 2:25–3:35 · 첫 합동 처치

- 목적: 상대가 만든 기회를 알아차리고 공동 처치 경험을 확실히 제공.
- VR: 중형 개체의 공격을 막으며 어깨 장갑을 파괴.
- 3안 PC: 상부 노드가 드러남 → 이때 상승·하강 안내 → D03으로 각도를 잡고 D02로 노드 파괴.
- 4안 PC: 노드를 T01로 확인 → 전력 충전 예고 시 T03으로 교란. 처음에는 예고 시간을 길게 제공.
- 공통 결과: 적이 휘청이고 코어가 열림 → VR이 코어를 사격해 처치. 두 화면에 지원 담당의 개방 기여 표시.
- 대사: “장갑이 열렸습니다. 지원 담당, 전력 노드를 끊으세요.” / “코어 노출! 조종사, 지금입니다.”
- 실패: 노드를 놓치면 적이 기본 공격 후 같은 기회를 다시 제공. 장갑 파괴는 유지하며 처음부터 반복하지 않음.
- 제작물: 중형 개체의 장갑 분리, 노드, 휘청임, 코어 개방, 드론 상승 표시 또는 EMP 효과.

### S04 · 3:35–4:15 · 전진과 중계기 연결

## 7. 실패·진행·안내의 공통 규칙

- 시간표는 목표 분량이며 동작 성공과 게임 상태로 진행한다. 종료 제약에 맞춰 반복 전투 수를 줄인다.
- 메카 무력화는 짧은 복구로 처리하고 전시 체험을 처음부터 다시 시작하지 않는다. 드론도 가까운 안전 지점에서 복귀한다.
- 한쪽이 준비하지 않았으면 다른 쪽은 관찰·조준·주변 방어를 할 수 있다. 협동 대기는 짧고 이유가 보여야 한다.
- 말하지 않아도 기본 진행이 가능하고, 대화하면 더 잘 협동하도록 표식·위험 방향을 양쪽에 전달한다.
- 음성 안내 우선순위: 즉시 위험 → 현재 필요한 새 행동 → 성공 확인 → 이야기. 동시에 여러 안내를 겹치지 않는다.
- 입력 이해 실패, 명중 실패, 협동 타이밍 실패를 구별해서 해당 힌트만 반복한다.
- 보스 연출과 충전포 사용에 새로운 메뉴 탐색이나 복잡한 조합키를 요구하지 않는다.

## 8. AI 제작 도구별 작업 배분

아래는 공식 기능 안내를 참고한 제작 제안이다. 생성물이 바로 게임에서 사용할 수 있는 완성품이라는 뜻은 아니다. 특히 모델 분리·리깅·음향 편집·엔진 연결은 별도 작업 명세에 남겨둔다. 현재 계정 요금제나 출력 설정은 확인하지 않았다.

Cascadeur의 AI·물리 보조가 모든 다족 생물이나 기계 리그에 그대로 적용된다고 가정하지 않는다. 적의 골격 형태를 정한 뒤 작업 적합성을 확인한다. 드론의 기본 이동과 포탑 조준은 게임 조작에 반응하는 동작이며, 전부 사전 애니메이션으로 제작할 대상은 아니다.

Higgsfield 결과는 영상·콘티다. 플레이어가 자유롭게 보는 조종석·보스의 실시간 3D 표현을 영상 생성으로 대체할 수 있다고 계산하지 않는다. Suno 소재 역시 자동으로 게임 상태에 반응하는 음악이 되는 것은 아니며, 반복·전환 규칙을 따로 정한다.

### 생성 전 공유할 기준 묶음

1. 외형 기준: 메카·드론·적·시설의 채택 이미지, 정면/측면 식별 요소, 크기 관계.
2. 기능 기준: 분리할 부위, 움직이는 관절, 노출되는 코어, 조작 가능한 소품.
3. 연출 기준: 장면 ID, 시작 상태, 행동, 종료 상태, 필요한 길이, 카메라 위치.
4. 음향 기준: 화자·말투·발음 사전, 무기 소리 구별, 음악의 공통 주제.
5. 제작물마다 공통(C), 3안(D), 4안(T)을 붙이고 장면 ID와 버전을 기록. 예: C_S03_CORE_OPEN_v01.

### 재생성을 줄이는 순서 — 제작 착수 전 정의

이야기와 역할 → 장면 행동과 결과 → 필요한 부위·동작 → 외형 기준 → 모델과 리그 → 동작 → 확정 대사·효과음 → 실제 에셋 참조 시네마틱 → 음악 편집과 통합 순으로 의존 관계를 정한다. 콘티는 초기에 저비용으로 만들 수 있지만 최종 시네마틱은 외형 채택 후 제작한다.

## 10. 제작 브리프 예시 — 두 안 동일 장면

대상: S03 첫 합동 처치.

- Meshy 브리프: 산업 시설의 2족 외계 장갑 개체. 어깨 장갑 뒤에 상부 노드, 가슴에 닫힌 코어. 장갑·노드·코어는 식별 가능해야 함. 장갑 분리 제작은 후처리 요구로 명시. 인간 장비와 실루엣 구분.
- Cascadeur 브리프: 공격 예고 → 공격 → 회복 → 어깨 피격 → 전력 차단으로 휘청임 → 코어 노출 자세. 3안 노드 파괴와 4안 EMP 모두 같은 휘청임·노출 동작에 연결. 약점이 플레이어 반대쪽으로 가려지지 않게 자세 설계.
- ElevenLabs 공통 대사: “장갑이 열렸습니다. 지원 담당, 전력 노드를 끊으세요.” / “코어 노출! 조종사, 지금입니다.” 3안 힌트는 “위로 올라가 노드를 조준하세요.”, 4안 힌트는 “충전 중인 적을 선택하고 EMP를 사용하세요.”
- Higgsfield 콘티: 공통 첫 컷은 메카 앞의 장갑 적. 3안 둘째 컷은 드론이 상부 노드로 접근, 4안 둘째 컷은 관제 화면에서 EMP 선택. 마지막 컷은 코어 노출과 메카 사격으로 공통. VR 시점을 위한 게임 카메라 요구와 홍보용 외부 카메라를 혼동하지 않음.
- Suno 브리프: 보컬 없는 산업 SF 전투 음악, 타격 순간과 무전이 들릴 공간 확보. 노출 성공 신호는 별도 짧은 효과음으로 처리. 두 안은 동일 음악 소재 사용.

## 11. 설계가 더 필요한 항목

- 메카의 이동 자유도와 착석 여부: 두 안 공통으로 결정.
- 주포·방패의 손 조작이 실제 메카 팔과 어떻게 연결되는지: 손 위치/방향, 포탑 한계, 가림 처리.
- 3안의 정확한 카메라·이동 좌표계·고도 범위, 4안의 지도 크기·현장 화면 비중.
- 적의 공격 종류·횟수, 체력·피해·노드 노출 시간, 능력 재사용 시간. 위 흐름을 기준으로 별도 수치표 작성 필요.
- 팀의 엔진·VR 기기·인원·기간에 따른 에셋 최종 분량. 현재 정보가 없어 확정하지 않음.
- 전시 10분에 착용·교대가 포함되는지와 현장 안내자의 역할.
- 모든 음성의 최종 대본, 모델별 부품표, 애니메이션별 시작/종료 자세, UI 화면별 와이어프레임은 다음 상세화 대상. 두 안을 항상 함께 작성.
