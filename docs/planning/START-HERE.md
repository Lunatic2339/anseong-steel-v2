# 안성제철 기획 — 작업 시작 문서

최종 갱신: 2026-11-14

이 폴더는 사용자와의 게임 기획 대화를 보존하는 로컬 작업 문서다. 대화 원문 전체를 그대로 복제한 기록은 아니며, 지금까지의 요구·결정·제안·변경 이유를 구조화한 기록이다. 새 대화나 작업 재개 시 이 문서부터 읽고 연결된 현재 기획을 확인한다.

## 1. 지금 지켜야 할 사용자 결정

1. 안성제철 세계관을 유지한다. 제철소와 작업 메카가 중심이다. 최신 요청에 따라 이번 3구역 배치는35m를 작업 기준으로 한다. 이전 약60m·레포65m를 고정하지 않는다. 세부 치수는 아직 제안이다.
2. VR을 활용하는 협동 게임이다. VR과 PC 모두 독립적인 재미와 서로를 도울 이유가 있어야 한다.
3. 3안(VR 메카 + PC 공중지원)과 4안(VR 메카 + PC 전술·시스템 지원)을 항상 같은 깊이로 함께 기획한다. 하나를 선택하거나 다른 하나를 보류한 상태가 아니다.
4. 최종 구성의 핵심 협동은 각 안 2~3개로 정리하되, 현재는 구간별 특수 협동 후보를 많이 만들어 비교·선택한다. 후보 수를2~3개로 제한하지 않는다.
5. 전시 콘텐츠는 시네마틱 포함 약 10분을 선호하지만 절대 상한이나 강제 종료 조건이 아니다. 학습·재미·자연스러운 흐름을 우선한다. 세계관·메카·역할을 시네마틱으로 설명한다. 착용·교대 포함 여부는 미정이다.
6. 실전형 튜토리얼을 지향한다. 무엇을 만들지 상세히 정의한 뒤 제작한다. 초기 기획 우선 원칙은 유지하되 최신 사용자 요청으로35m 전체3구역의 실제 Unity 배치를 진행했다.
7. 보스는 메카일 필요 없다. 외계 생물 등 외형 선택지를 AI 제작 환경을 활용해 검토한다.
8. 사용 도구: Meshy AI, ElevenLabs AI, Cascadeur, Higgsfield(시네마틱), Suno AI.
9. 매번 논의 결과를 컴퓨터의 문서에 반영하고, 채팅에서도 변경 내용과 실제 기획 내용을 설명한다. 파일 수정 사실만 말하고 끝내지 않는다.
10. 사용자 확정과 어시스턴트 제안을 구별한다. 사용자가 다음 논의를 이어갔다는 이유만으로 모든 제안을 확정 처리하지 않는다.
11. 선택지만 나열하지 말고 추천안·판단 근거·추천을 바꿀 조건을 함께 설명한다. 사건 골격과 맵을 함께 구체화한다.
12. 출시 가능한 수준의 품질을 목표로 진행마다 부족한 부분·제약을 자가진단하고, AI 활용을 전제로 해결책과 우선순위를 추천한다. 사용자가 매번 지적하기를 기다리지 않는다. 생성 결과와 게임 내 검증을 구별하고, 목표기기·실제 테스트 없이 품질/성능 달성을 단정하지 않는다.
13. 최신 사용자 우선순위(2026-11-14): 게임 기능 검증보다 맵 설계·맵 제작에 중점을 둔다. 기존 협동 검증판은 보존하고, 전체3구역의 공간·동선·시야와 시각 제작을 주 작업으로 전환한다. 필요한 크기/차폐/간섭 확인은 맵 제작 안에서 수행하되 협동 코드·정식 IK·네트워크 검증 완료를 맵 착수의 선행 조건으로 삼지 않는다.

## 3. 현재 제안의 요약 — 사용자 확정으로 취급하지 말 것

- 맵 후속 방향(11/14): 이미 피해 입어 불타는 제철소와 전투 중 변화하는 설비를 검토. 시작 전 파괴 흔적/전투 반응/플레이어 활용을 구분. 탱크 폭발·화재 진압 등G01–G08 추가. 상세 배치·채택은 미정.

- 안성제철소를 지키는 메카. 이번 배치는35m를 작업 기준으로 진행. 낮고 긴 4족 외계 생물 보스 ‘철식수’와 소형 ‘침식체’는 제안이다.
- 적 모델2종, 등장 개체 보스1+소형6. 보스 중심 전투. 단일 마당은 M-A로 보존하고3구역 연결형 M-C를 우선 추천(미채택).
- VR: 양팔 담당, 팔뚝 포 사격·방패·단순 주먹 타격·제한 이동. 검과 복잡한 펀치 콤보는 보류 제안.
- 3안 핵심 협동: 갑각 개방/사각 공략, 서로의 위협 제거, 유도/크레인 코일 낙하 공격.
- 4안 핵심 협동: 스캔/EMP 공격 기회 생성, 보호 대상·위험 행동 선택, 유도/크레인 원격 작동.
- 무장 상실은 주포 한 번으로 압축하고, 방패와 PC 역할은 끝까지 유지하는 제안.
- 기존 시간 참고안(강제 진행 기준 아님): 오프닝60초 → 기동40초 → 소형 교전60초 → 등장20초 → 첫 합동 공격80초 → 크레인70초 → 주포 상실20초 → 구조/근접전90초 → 마지막 공략120초 → 결말40초. 합계600초.
