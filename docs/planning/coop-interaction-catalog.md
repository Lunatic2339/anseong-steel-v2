# 안성제철 협동 인터랙션 후보집 — 56개 장면, 3·4안 병렬

작성: 2026-11-13 / 갱신: 2026-11-14 / v2 / 전부 미채택 제안

현재 총56개: 기존 진행6구간×8개=48개에 환경 사건 G01–G08을 추가했다. G는 새 시간 구간이 아니라 여러 단계에 배치 가능한 교차 후보다. 아래 초기48개 설명은 A–F에 해당한다.

35m 배치 연결: [상세 배치](map-layout-35m.md)의 I1~6은 기존 후보를 지도에 시험 배치한 사건 위치이며 신규 후보6개 추가나 최종 채택을 뜻하지 않는다. D01 크레인은Z3, G01 탱크는Z2서쪽 외곽. 탱크는 기본 보스 위치에서 폭발이 닿지 않아 별도 유도 경로가 필요하다. 작은 접촉 대상은 높이24m의 메카용 장치 또는 PC 조작 대상으로 조정한다.

## 사용 방법

사용자 요청: 특수 협동 인터랙션을 구간마다 많이 제안해 비교·선택한다. 이 문서는 6개 구간×8개=48개 장면 후보이며, 각 장면에 3안과4안의 대응을 함께 썼다. 96개의 독립 시스템을 모두 만들자는 뜻이 아니다. 후보를 고른 뒤 현재 상세 기획에 반영한다. 기존 크레인 장면 역시 D01이라는 후보이며 필수 채택 사항이 아니다.

초 단위 슬롯 대신 서사·학습 단계로 분류한다. 기동 → 첫 교전 → 첫 보스 협동 → 큰 환경 공격 → 위기/구조 → 피날레. 약10분은 선호 길이이며 후보의 개수나 연출을 기계적으로 제한하는 조건이 아니다. 최종 플레이에서 핵심 협동 관계를2~3개로 정리한다는 기존 방향과, 기획 후보를 많이 만든다는 요청은 구분한다.

표 읽기: VR 행동은 두 안 공통. PC3은 직접 비행·조준·접근을 사용하는 드론, PC4는 관측 화면에서 대상·위치·타이밍을 선택하는 관제다. 큰 질량을 움직이는 일은 메카/제철소 설비가 맡고 소형 드론이 보스나 코일을 힘으로 운반하지 않는다.

화면 원칙: VR은 손/방패/접촉 지점과 거대 물체를 조종석에서 본다. PC3은 자기 드론과 접근 경로, PC4는 대상·설비와 작동 결과를 현장 영상에서 본다. PC4가 단순 승인 버튼 역할에 머무는 후보는 위치·대상·시점 선택을 더 구체화하거나 제외한다.

작업 추가량 표기: ‘적음’은 기존 이동·사격·스캔·EMP·대상 선택을 주로 사용, ‘중간’은 새 소품/설비와 상호작용 상태 추가, ‘큼’은 붙잡기·줄·운반·특수 보스 자세·새 장치 등이 필요. 실제 견적이 아닌 상대적 기획 판단이다. AI 제작으로 아트 후보는 늘릴 수 있지만 게임 상태·타격·동기화 작업이 사라지지는 않는다.

1. 두 사람 모두 직접 조작하거나 판단하는 부분이 있는가? 한쪽이 누르기만/버티기만 하게 되는 시간은 얼마인가?

3. 상대의 행동 결과를 내 화면에서도 볼 수 있는가?
4. 말하면 더 잘 되지만 말하지 못하면 영구 진행 정지하는 구조는 아닌가?
5. 같은 협동을 다른 소품으로 포장한 것인가, 새로운 감정과 행동이 있는가?
6. 새 입력·상태·보스 동작이 얼마나 필요한가? AI로 생성할 외형과 게임 로직 작업을 구분했는가?
7. 실패해도 흥미로운 상태가 남는가? 한 번 놓친 시설 때문에 처음부터 다시 시작하지 않는가?

작업량별 후보 수는 실제 견적이 아니다. 제작할 수 있는 장면만 남기는 단계와 별개로, 지금은 선택 폭을 확보한다. 각 안의 강점이 다른 후보를 억지로 동등한 재미라고 평가하지 않는다. 예: E03은 드론 직접 귀환이3안의 강점이며4안은 다른 지원 설비 복구 경험이다.

## 후보 조합 예시 — 선택 완료 아님

- **공간 액션 중심:** A06 → B03 → C01 → D01 또는D04 → E02 → F01. 엄호·이동·사각 공략을 반복해 발전시킴.
- **산업 설비 중심:** A07 → B06 → C04 → D02 또는D03 → E08 → F03. 제철소를 조작하는4안과 현장에서 설비를 여는3안을 비교.
- **거대한 손의 감각 중심:** A04 → B03 → C02 → D07 → E01 → F06. 잡기·버티기·벌리기가 많아 동작/접촉 요구가 큼.
- **서로 구해주는 경험 중심:** A06 → B01 → C05 → D06 → E04 또는E05 → F08. 위험과 회복이 서로의 도움으로 연결됨.

한 구간에서 모든 후보를 넣지 않는다. 같은 메커니즘의 변형이 겹치면 대표 하나를 골라 깊게 만든다. 피날레는 앞에서 배운 행동의 확장이어야 한다. F02/F05/F06 같은 잡기·던지기·벌리기를 마지막에 처음 소개하는 구성은 피한다. 미선택 후보를 삭제하지 않고 유지한다.
