## 6. 확인한 것과 남은 것

Unity에서 장면 생성·컴파일·Windows 빌드를 수행하고 카메라16개의 이미지를 저장했다. 실행 파일 자동 시작 확인은 `MAP35_VIEWER_READY views=16 route=470`, 종료코드0을 기록한다. 조감/평면·K1·K3b·메카 진입 화면 등을 직접 보고 배치를 수정했다.

빌드 중 기존 Z1의 독립 XR 설정이 Editor 재시작 시 자동 변환되며 Manager 참조가 빠지는 문제를 발견했다. 설정 준비를 `Z1Build.PrepareXR`로 분리하고 per-target 컨테이너 안에 일반·매니저 설정을 생성하도록 보정했다. 자동 XR 시작은 계속 끄고 기존 협동 런타임·장면은 유지한다. 맵 제작에 필요한 빌드 설정 수정이며 전투·IK·네트워크 작업 확장이 아니다.

정적 검사에서 메카12×34.8×16 가정 외곽을 경로249개 위치에 놓았을 때 검사 대상 건물과 겹침이 없었다. 드론 주 경로는 반경1.5 구체의 건물 충돌 목록이 비었다. 이것은 실제 조작·연속 회전·펼친 팔·움직이는 보스·완성 에셋 통과의 보장이 아니다. 메카 검사는 보스 단계 형상·판·파편·소품을 제외하고, 드론 선택 D6 경로는 이 검사 대상이 아니다. 시선 검사는 작은 표적의 지정 점까지 선 하나를 쏜 결과이며 화면 전체의 가독성을 대신하지 않는다.

남은 공간/외형 과제:

- 세 구역을 연결했지만 제철소의 설비 밀도·도로 도색·조명·재질·손상 표현은 초기 수준이다. 특히 산 경계·강 표면·모듈 반복을 아트 단계에서 다듬는다.
- M5의 근접 보스는 화면을 크게 차지한다. M4 진입 구도를 별도로 보존하며 정식 보스 머리·갑각·메카 팔 형상에 맞춰 근접 카메라와 거리 조정이 필요하다.
- B04가 보스를 완전히 숨기지 않는다. 보스가 처음 보이는 순간은 통로 출구·연기·보스 자세를 함께 설계하되 무조건 연기로 가리지 않는다.
- 관제 전환 입력·선택 UI·확대는 후속 화면 설계 대상. 위치에 따라 시선 방향이 바뀌므로 전체 배치도와 방향 표시를 함께 설계한다.
- 탱크 폭발은 G01 선택 후보로 공간만 남겼다. 코일 명중 뒤 상태만 비교하며 빗나감·보스 사망 자세는 아직 시각화하지 않았다.
- 실제 HMD 편안함·VR 성능·두 사람 재미·최종 프레임·출시 품질은 이 뷰어로 확인하지 않았다.

## 7. 추천하는 바로 다음 맵 작업

**전체 배치를 유지한 채 반복 건물 모듈·주요 시설의 기본 외형을 갖추고, Z1 출구 한 장면을 목표 시각 품질로 올린다.** 다음 산출물은 건물별 에셋 목록(사용 시점·치수·움직이는 부위·확보 방식)과 Z1의 VR/드론/K1 동일 배치 전후 이미지다. 게임 시스템 개발을 먼저 확장하는 순서로 되돌리지 않는다.

정비고 문틀·벽/지붕·기둥·창고·배관·차량은 크기를 통일할 수 있는 모듈로 구성한다. Meshy는 침식물·특수 파손부·외계 잔해처럼 개성이 필요한 형상부터 후보를 만든다. 생성 모델을 통행/선택/접촉 규격으로 바로 간주하지 않고 형상을 다듬고 단순 충돌체를 별도로 둔다. 아직 Meshy 작업을 실제 실행하거나 무료 에셋을 확보한 상태는 아니다. 시네마틱·음성·음악은 정해진 맵 구도와 사건 순서에 연결해 다음 제작 명세로 이어간다.
