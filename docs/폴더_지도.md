# 폴더 지도

"이 파일 어디 있지?", "이건 어디에 쓰이지?", "내 결과물은 어디에 넣지?"가 궁금할 때 보는 파일입니다.

> 마지막 수정: 2026-10-17 (main 기준. **[M1-03 후]** 표시는 `claude/m1-cockpit-input-x0vygh` 브랜치에 있고 M1-03이 병합되면 main에 들어오는 것)
>
> 폴더나 중요한 파일을 추가·이동·삭제한 사람(또는 Claude 세션)이 이 파일도 같이 고칩니다.

## 1. 한눈에

```
anseong-steel-v2/
├─ README.md              처음 오신 팀원 안내 (여기부터)
├─ CLAUDE.md              Claude가 자동으로 읽는 규칙
├─ docs/                  문서 (사람이 읽는 것은 전부 여기)
│  ├─ members/<이름>/     조원별 지시서 원본(주제별 파일)  ← 제일 자주 봄
│  ├─ tasks/              작업 지시서 (번호별)
│  ├─ design/             기획 문서 00~06
│  ├─ etc/                참고 자료 (기록용)
│  ├─ AI_사용법.md        Claude·ChatGPT 쓰는 법
│  ├─ GitHub_작업_규칙.md  브랜치·올리기 규칙
│  └─ 폴더_지도.md         이 파일
├─ Assets/
│  ├─ _Anseong/           ★ 우리 게임의 모든 것
│  │  ├─ Art/             모델·애니메이션·재질 (아트 결과물)
│  │  ├─ Audio/           소리 (아직 없음)
│  │  ├─ Prefabs/         로봇 프리팹 (메뉴로 만듦)
│  │  ├─ Scenes/          Main 씬 + 각자 Sandbox 씬
│  │  ├─ Runtime/         게임 코드
│  │  ├─ Editor/          Unity 메뉴(에디터 도구) 코드
│  │  └─ Tests/           자동 테스트
│  └─ (Scenes, Settings, XR, XRI 등)  Unity 기본 파일. 건드리지 않음
├─ Packages/, ProjectSettings/        Unity 설정. 건드리지 않음
└─ Hardware/Exo/firmware/             외골격 ESP32 펌웨어 (아직 없음)
```

**레포에 없는 것**: `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `Build/`는 Unity가 각자 PC에서 만드는 폴더라 올라가지 않습니다(`.gitignore`). 지워도 Unity가 다시 만듭니다.

## 5. 무엇이 무엇과 연결되나 (자주 묻는 것)

- **로봇 모델을 바꾸면?** `Art/Robot/Source/`의 FBX → (자동) 임포트 설정 → **Build Player Robot Prefab** 메뉴 → `Prefabs/Robot_Player`·`Robot_Boss` → 씬들이 이 프리팹을 씀. **[M1-03 후]** 새 모델은 Robot Art Settings의 칸에 넣으면 됩니다(파일 경로를 코드에 적지 않음).
- **뼈 이름을 바꾸면 왜 깨지나?** 팔 IK와 애니메이션이 `mixamorig:` 뼈 이름으로 뼈를 찾습니다. 이름·개수·계층이 같아야 Mixamo 클립도 그대로 맞습니다. 기준: `design/04_art_spec.md`.
- **재질 슬롯 이름이 왜 정확해야 하나?** **[M1-03 후]** `MaterialSlotNames.cs`가 재질 이름(`ArmorMain`, `ArmorAccent`, `Metal`, `Dark`, `Glow`, `Trim`)으로 색을 바꿀 자리를 찾습니다. 글자가 다르면 그 부분은 색이 안 바뀝니다.
- **조종석 모델 기준은?** **[M1-03 후]** 원점 = 두 좌석 사이 바닥 중심, +Z 앞, +Y 위, 단위 m(사람 크기). 좌석은 원점에서 좌우 ±1.05m. Robot Art Settings의 조종석 칸에 넣음. 비우면 회색 상자.
- **애니메이션 클립은 어디서 쓰이나?** 지금은 `Idle`만 `Robot_Idle.controller`에서 씁니다. 보스 클립(`Boss_…`)은 M2 보스 상태기계가 씁니다. 목록은 `design/04_art_spec.md`의 "애니메이션 목록".
- **소리는?** 드라이브 `안성제철_소리` → 코드 담당이 다듬어 `Audio/`에 넣고 → 전투 코드(M1-05·M1-07)가 연결. 어떤 동작에 어떤 소리인지는 `design/06_feel_and_sound.md`.
- **외골격은?** 각 PC가 USB로 ESP32와 이야기합니다. 약속(명령 글자 `P`·`R`·`X`·`H`)은 `design/02_architecture.md`와 `tasks/H-01`. 펌웨어는 `Hardware/Exo/firmware/`.
